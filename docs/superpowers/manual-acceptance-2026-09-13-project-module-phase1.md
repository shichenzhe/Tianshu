## 走查清单

### 1. 空项目态

- **操作步骤**：新装（或清空 `project` 表）后从侧边栏「项目」进入 `/module/project`。
- **预期结果**（spec §6.1）：Hub 显示空状态引导，下方四张模版卡（产品需求全流程 / 市场调研 / Bug 跟踪 / 空白项目）正常展示、可点击发起创建。
- **Commit 区域**：44e9dca（ProjectHubView）、49ede45（内置四模版）。

### 2. 新建：模版切换覆盖确认

- **操作步骤**：新建弹窗内选一个模版 → 手动编辑 prompt → 再切换到另一模版，分别走「确认覆盖」与「取消」两条分支。
- **预期结果**（spec §6.2）：确认覆盖后 prompt 变为新模版内容；取消则回弹保留手动编辑的原文本。
- **Commit 区域**：8159c16（CreateProjectDialog 模版联动）。

### 3. 新建：能力挂载

- **操作步骤**：新建弹窗分别挂载专家 + 技能 + 连接器各若干（含取消移除），提交创建。
- **预期结果**（spec §6.2）：已选项以 Tag 展示且可点 X 移除；创建成功后详情配置面板能力区出现相同挂载项。
- **Commit 区域**：0cbc62c（PickerDialog 通用多选）、8159c16。

### 4. 新建：名称校验

- **操作步骤**：分别输入重名 / 空 / 超 15 字的名称提交。
- **预期结果**（spec §6.2 / §7）：重名显示内联错误（不弹 toast），空与超长触发对应校验提示，均阻断创建。
- **Commit 区域**：8159c16、16d582f（`PROJECT_NAME_EXISTS`）。

### 5. 详情：欢迎消息与项目指令

- **操作步骤**：选「产品需求全流程」模版创建项目进入详情，观察首条消息；再在输入框发一条消息（如「帮我拆解一个登录功能」），对比 AI 模块无项目会话的同类提问。
- **预期结果**（spec §5.1 / §5.2）：动态流首条为该模版 welcome 消息；项目内回答呈现需求管理专家的职责化风格（要点先行 / Markdown 结构），与无项目会话明显不同。
- **Commit 区域**：16d582f（create 内建 session + 欢迎消息）、e7951da（项目 systemPrompt + 挂载专家注入）。

### 6. 详情：PlusMenu 过滤与文件引用

- **操作步骤**：详情页输入框打开 PlusMenu 查看专家/技能列表；在资料库有文件的前提下用 `@` 引用一个文件发消息。
- **预期结果**（spec §5.3 / §5.4）：PlusMenu 仅显示已挂载的专家/技能；`@` 文件引用可正常选择并随消息生效。
- **Commit 区域**：22fd058（ChatPane 抽出 + PlusMenu 挂载过滤）。

### 7. 详情：Tab 占位与指令即时生效

- **操作步骤**：查看计划 / 任务 / 资产三个 Tab；在配置面板编辑项目指令并保存，再新发一条消息。
- **预期结果**（spec §6.3）：三个 Tab 显示占位内容（二三期范围）；指令保存后立即生效，新消息回答风格按新指令变化。
- **Commit 区域**：6481a4e（ProjectWorkspaceView + ConfigPanel）、e7951da。

### 8. 详情：失效挂载与定时任务入口

- **操作步骤**：先挂载一个专家，再到 AI 模块删除该专家源，回到项目配置面板；点击配置面板内定时任务入口。
- **预期结果**（spec §6.3 / §7）：失效项灰显并带「已失效」徽标；定时任务入口正常跳转到对应页面。
- **Commit 区域**：6481a4e（CapabilityRow 失效态）。

### 9. 删除项目：级联与重定向

- **操作步骤**：删除一个已挂载能力、有动态流消息的项目（确认二次确认弹窗）；删除后再访问该项目详情 URL。
- **预期结果**（spec §4.3 / §7）：二次确认后项目及成员 / 挂载 / 动态流会话级联删除；详情 404 兜底 toast 后重定向回 Hub。
- **Commit 区域**：16d582f（repo 级联删除）、6481a4e（ProjectWorkspaceView 的 PROJECT_NOT_FOUND 兜底）。

### 10. 会话隔离

- **操作步骤**：在项目里发过消息后切回 AI 模块查看任务树，再用全局消息搜索搜项目消息关键词。
- **预期结果**（spec §5.1）：AI 模块任务树不含项目会话；全局搜索搜不到项目消息。
- **Commit 区域**：e11a72b（会话隔离——任务树 / 标题搜索 / 全局消息搜索三处过滤）。

### 11. 中英文切换

- **操作步骤**：在项目 Hub / 新建弹窗 / 详情 / 配置面板各界面切换语言。
- **预期结果**（spec §8）：项目模块全部文案跟随切换，无硬编码文本、无缺失 key。
- **Commit 区域**：49ede45（project i18n 双语言）+ 各 UI commit。

### 12. 四主题切换

- **操作步骤**：蓝 / 红 / 绿 / 橙四主题下浏览项目模块各界面。
- **预期结果**（spec §8）：颜色全部跟随主题变量，无硬编码色残留。
- **Commit 区域**：各 UI commit（统一走主题 CSS 变量规范）。

## 边界行为与已知裁定（走查确认，非 bug）

### 13. 项目路由下全局快捷键「新建任务」

- **操作步骤**：停在 `/module/project` 下按全局「新建任务」快捷键。
- **预期结果**（已知裁定）：跳回 AI 模块并新建任务——一期不做项目路由上下文的新建分流。
- **Commit 区域**：7a57dac（GlobalSidebar 新建任务与任务树/快捷键同口径）。

### 14. 项目路由侧栏折叠入口

- **操作步骤**：在项目路由尝试折叠左侧栏。
- **预期结果**（已知裁定）：仅快捷键可折叠（顶栏折叠按钮只在 AI 路由展示）。
- **Commit 区域**：7a57dac。

### 15. 项目路由缓存过期时新建任务落点

- **操作步骤**：进入项目模块使会话缓存过期（或冷缓存）后按「新建任务」。
- **预期结果**（已知裁定）：任务落在第一个（默认）工作空间——目标空间按「选中任务所属 ∪ 第一个」推导，项目路由下缓存未预热时取默认值。
- **Commit 区域**：7a57dac（handleCreateSession 按需读缓存）。

### 16. 删除默认工作空间连带删项目会话

- **操作步骤**：在 AI 模块删除承载某项目动态流的默认工作空间后，访问该项目详情。
- **预期结果**（已知裁定）：项目动态流会话被连带删除，项目详情 404 兜底 toast 后重定向回 Hub（getDetail 要求 session 存在，项目本体行仍在 Hub 列表可见，但进入详情将持续 404——一期已知边界，不另做重建）。
- **Commit 区域**：6481a4e（ProjectWorkspaceView 的 PROJECT_NOT_FOUND 兜底）。

### 17. 失效挂载项显示 `#id` 名

- **操作步骤**：挂载某技能后删除其技能源，回到配置面板能力区查看该项。
- **预期结果**（已知裁定）：显示 `#id` 名（源已删、无名称可查）+ 「已失效」徽标，点 X 可移除。
- **Commit 区域**：6481a4e、16d582f（`itemName: source?.name ?? "#${itemId}"`）。
