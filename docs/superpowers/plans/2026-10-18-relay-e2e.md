# relay 端到端加密实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** relay 承载全帧端到端加密（X25519+HKDF+AES-GCM 信封+重放窗口），TOFU/指纹强制+降级兼容，relay 零改动零知识。

**Architecture:** 加密核心单份 `@tianshu/core`（纯 node:crypto）；三消费方（mirror RelayTransport/server-face relay-client/headless relay-client）在 envelope 编解码边界插信封层；密钥持久化 option 表；握手两帧明文。

**Tech Stack:** node:crypto（X25519/HKDF/AES-256-GCM）· 既有 relay/transport/option/i18n 管道。

**Spec:** `docs/superpowers/specs/2026-10-18-relay-e2e-design.md`

## Global Constraints

- 铁律不触碰；两仓风格；哨兵规程（并行会话活跃）；git add 精确。
- core 新模块零 Electron/零第三方（node:crypto only）；mirror alias 消费、headless 经 file: dist（改包后 sync:core）。
- nonce 计数器单调+64 窗口重放拒；握手帧明文外全部密文；指纹不匹配即断。
- 降级三态 auto（默认）/required/off 双端对称。
- 基线：mirror ~3690 过/1 外来预存红（library-repo）零新增；server 309。
