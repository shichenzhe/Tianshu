# 外观模块 — 手动验收清单（Electron GUI 走查）

> 适用分支：`worktree appearance-module`（4562b2d spec → 本清单共 9 个 commit：docs 2 个 + 功能 6 个 f4a8b9d → 4e606f7 + 本清单）；自动化验证：`npm run typecheck`/`lint` 零问题、`npm run test` 1172 全绿（外观新增 47：skin-cards 14 + skins 11 + skin-store 14 + appearance-settings 8）

## 走查清单

## 一、设置 → 外观页

### 1. 外观页初始态（预览卡 + 10 卡网格）

- **操作步骤**：启动应用（默认浅色状态），点头像菜单 →「设置」→「外观」Tab（原禁用占位项，本期解禁）。
- **预期结果**（spec §3.2）：上方主题预览大卡按当前皮肤变量渲染的模拟界面（窄侧栏条 + user/assistant 气泡 + 输入条）+ 右上「基础主题」类型胶囊；下方「全部皮肤」标题与 10 张缩略卡 5 列网格，「浅色」卡带选中态（`border-primary` + `ring-primary/30`）。
- **Commit 区域**：80a544e（外观页 + SettingsDialog 解禁）、7d8c1c6（预览卡/缩略卡）、5b098dd（元数据）。

### 2. 点深色 → 全应用即时暗（逐页走查）

- **操作步骤**：点「深色」卡后保持设置面板打开，逐页走查：AI 聊天（会话树/气泡/输入区/加号菜单）→ 项目动态流 → 资产 → 计划表格+看板 → 任务 Tab → 自动化 → 资料库 → 设置各页 → 登录页（注销后）。
- **预期结果**（spec §3.4/§2 深色实现）：各页背景/卡片/文字/边框/输入框即时切暗色变量集——无白底残留块、无深底深字不可读区域；预览卡同步变深；切换瞬时完成无 Loading（全内置裁定）。
- **Commit 区域**：f4a8b9d（`[data-mode="dark"]` 变量集 + body 底色）、4e606f7（13 文件硬编码色清理——登录页/密码弹窗/用户信息/自动化/资料库等，§3.4 专项核查）。

### 3. 八款精选逐一切换（壁纸渐变 + 角标 + 选中 ring）

- **操作步骤**：依次点「晨雾/涟漪/原野/海空/暖沙/暮色/松林/墨韵」八张精选卡，每款停留数秒观察 body 与左侧全局侧栏。
- **预期结果**（spec §3.1 皮肤表/§2 皮肤视觉）：每款即点即切且 body 叠加对应壁纸渐变、全局侧栏出现对应 SVG 图案/渐变——晨雾淡紫云纹、涟漪水纹同心圆、原野草地条带、海空天海分界线、暖沙沙丘弧线、暮色暖橙暮光、松林墨绿层叠、墨韵深蓝漩涡；mode 随表（前五款浅、后三款深）、hue 就近映射四色系（晨雾/涟漪/海空/墨韵→蓝、原野/松林→绿、暖沙/暮色→橙）；每款缩略图右上「精选皮肤」角标、选中 ring 随点击转移；切回基础款后壁纸层消失（`data-wallpaper` 移除无残留）。
- **Commit 区域**：f4a8b9d（八款壁纸变量 + body/侧栏消费点）、80a544e（即点即切）、5b098dd（十款元数据）。

## 二、皮肤状态与系统级

### 4. 顶栏 ThemeSelector 正交验证（深色下切红色）

- **操作步骤**：保持深色（或暮色）皮肤，用顶栏调色板下拉依次切红/绿/蓝/橙。
- **预期结果**（spec §3.3/§2 皮肤架构）：仅色相变——背景仍暗、壁纸仍在（`setHue` 不动 mode/wallpaper），按钮/链接/选中态/头像点/ring 等主色系换色相；外观页当前选中皮肤卡不变（hue 是正交维度）；暗色亮度公式保证新色相下暗底可读。
- **Commit 区域**：abf82b4（`setHue` 正交 + theme.store 兼容层）、f4a8b9d（`--theme-hue` 暗色亮度公式）。

### 5. 重启应用恢复皮肤（持久化）

- **操作步骤**：选「暮色」并用顶栏调色板切绿色，完全退出应用后重启观察首帧。
- **预期结果**（spec §2 持久化/§3.3 启动初始化）：启动即恢复暮色暗色 + 绿主色 + 墨绿壁纸（`initSkin` 渲染前落 DOM，首帧无白→暗闪变）；localStorage `tianshu-theme` 为 `{"state":{"skin":"dusk","hue":"green"},"version":1}`。
- **Commit 区域**：abf82b4（persist version 1 + `initSkin`）。

### 6. 旧 tianshu-theme 数据迁移（模拟旧 `{theme:"green"}`）

- **操作步骤**：DevTools console 执行 `localStorage.setItem("tianshu-theme", '{"state":{"theme":"green"},"version":0}')` 后重启应用；再试脏数据 `{"state":{"skin":"bogus"},"version":1}` 重启。
- **预期结果**（spec §4 异常表/§2 持久化）：旧结构迁移为浅色+绿 hue（界面浅色、主色绿，`migrate` 兼容 legacy `theme` 字段→hue）；未知皮肤 id 回落浅色且 console 仅 warn 一次（按 id 去重不刷屏），均无报错白屏。
- **Commit 区域**：abf82b4（`sanitizePersisted`/`migrate`/`merge` 三层归一）。

### 7. 深色对比度抽查

- **操作步骤**：深色皮肤下抽查正文段落、全局侧栏菜单项文字、muted 辅助文字（外观页「全部皮肤」标题、表单辅助文案）、AI 对话 assistant 气泡、任意 Tooltip。
- **预期结果**（spec §4 深色下文字对比度）：正文 `hsl(210 20% 94%)` 对暗底约 16:1、muted 文字 `hsl(215 10% 62%)` 约 6.3–6.9:1，均过 W3C AA（4.5:1）；气泡走 card/muted 变量同级达标；Tooltip 反转为浅底深字（暗色下浮层层次裁定）维持可读；绿 hue 主色按钮白字沿用亮色 green 低亮度口径（47%，与既有亮色主题一致，见 §2）。
- **Commit 区域**：f4a8b9d。

## 三、回归走查

### 8. 四色相 × 浅/深两模式主 UI 走查

- **操作步骤**：分别选「浅色」与「深色」基础款，每种模式下用顶栏调色板依次切蓝/红/绿/橙，走查 AI 聊天主页 + 项目计划表格/看板 + 外观页。
- **预期结果**（spec §3.3/§2）：四 hue 在两模式下主色组件（按钮/链接/选中态/头像点/看板色条/优先级徽标）全部跟随、无前一 hue 残留；暗色下各 hue 按亮度公式提亮（62%，绿特例 47%）保证暗底白字可读。
- **Commit 区域**：f4a8b9d、abf82b4、4e606f7。

### 9. 中英文切换（皮肤名 / 界面文案）

- **操作步骤**：语言切 en-US，打开外观页浏览预览卡/网格/胶囊/皮肤名与描述，再切回 zh-CN。
- **预期结果**（spec §5 i18n）：界面文案（外观/主题预览/全部皮肤/基础主题/精选皮肤/选中 sr-only）随语言全量切换无硬编码中文；皮肤名/描述走内置双语字段（浅色↔Light、晨雾↔Dawn Mist 等——品牌化静态数据裁定，非 i18n key）。
- **Commit 区域**：5b098dd（`appearance.*` i18n + 双语元数据）、7d8c1c6（`getSkinName` locale 分流）。

### 10. 移动窄窗口网格 2→3→5 列响应

- **操作步骤**：拖窄主窗口宽度依次跨过 xl（1280px）与 md（768px）断点（或 DevTools 响应式模拟）。
- **预期结果**（spec §3.2）：皮肤网格 窄窗 2 列 → 中窗 3 列 → 桌面 5 列（`grid-cols-2 md:grid-cols-3 xl:grid-cols-5`）；预览卡与缩略卡不溢出、设置面板无横向滚动。
- **Commit 区域**：80a544e。

## 附录：已知边界与裁定（走查确认，非 bug）

### A1. 壁纸为纯 CSS/SVG 纹理，品质按"氛围渐变+纹理"定位

- **操作步骤**：逐款凑近观察八款壁纸的视觉细节。
- **预期结果**（已知裁定，spec §2/§6 风险 2）：壁纸 = CSS 渐变 + SVG data-URI 图案，非 PRD 的位图插画——"插画感"有限为既定定位（PRD 本地化裁定）；底层始终有语义背景色兜底，SVG 渲染异常仅丢装饰层不破可用性（spec §4）。
- **Commit 区域**：f4a8b9d。

### A2. IP 联名皮肤去版权化（与 PRD 名目表差异）

- **操作步骤**：对照 PRD 名目表（张韶涵/和平精英/张靓颖/经典 QQ 等 IP 皮肤）。
- **预期结果**（已拍板裁定，spec §2 决策表）：应用内无任何 IP 名目与插画——10 款全部本地原创命名与视觉（晨雾/涟漪/原野/海空/暖沙/暮色/松林/墨韵）；与 PRD 名目表不一致为版权风险的既定裁定（无授权插画资源，保留 IP 名而无 IP 视觉是空壳），非缺陷。
- **Commit 区域**：4562b2d（spec 裁定）、5b098dd（名目落地）。

### A3. shiki 代码块深色下仍亮色高亮

- **操作步骤**：深色皮肤下打开含代码块的 AI 对话回复。
- **预期结果**（既有行为，本期范围外）：代码块仍 github-light 亮色高亮（浅底色块在暗色页面中形成亮色岛，代码可读但风格不融合）——CodeBlock 双主题输出已带 `--shiki-dark` CSS 变量但皮肤模块未消费（该注释写于外观模块之前）；消费该变量切暗色主题为后续增强项。
- **Commit 区域**：既有（`CodeBlock.tsx`，非本期改动）。

### A4. success/warning 状态色无语义 token（emerald/amber 保留）

- **操作步骤**：自动化运行历史看成功徽标、AI 输入区上下文用量环/数字。
- **预期结果**（范围外保留裁定）：成功/用量色为硬编码 emerald/amber（非主题语义变量，不随皮肤 hue 变化）；深色下可读性由显式 `dark:` 变体保证（Tailwind `@custom-variant dark` 已接 `data-mode`，随皮肤明暗生效）；spec 未定义 success/warning token，纳入语义体系为后续设计系统工作。
- **Commit 区域**：4e606f7（dark 变体接入 data-mode）、色值为既有。

### A5. 预览卡为 CSS 变量驱动缩略布局，非截图

- **操作步骤**：观察主题预览大卡的构成与当前皮肤的同步性。
- **预期结果**（已拍板裁定，spec §2 预览卡）：预览 = div 组合的模拟界面（侧栏条/气泡/输入条）按所选皮肤变量实时渲染——"实时预览"的本质是变量保真而非主界面截图，布局细节不逐一复刻真实组件形态；卡内变量与全应用一致性由特异度孪生规则锁定（`[data-mode="dark"][data-theme]` 0,2,0，见 skins.css 注释）。
- **Commit 区域**：7d8c1c6。

### A6. 网络皮肤下载与付费/限时语义不做

- **操作步骤**：对照 PRD 的"网络主题下载/永久有效/限时/VIP"条款寻找对应入口。
- **预期结果**（已拍板裁定，spec §2）：皮肤全内置、无下载入口（本地应用无下载场景，切换瞬时完成、无 Loading 骨架）；类型胶囊仅显示「基础主题/精选皮肤」两档类型，假付费语义（无账号体系）不做。
- **Commit 区域**：4562b2d（spec 裁定）、80a544e/7d8c1c6（类型胶囊落地）。
