# ui-drive 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:execing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 控制端远程驱动被控桌面端 UI（openSession/notify/openRoute 三动作），capability 双向协商补全桌面侧专属能力。

**Architecture:** 被控面路由表加三端点（窗口聚焦+渲染层事件）；协议包 DESKTOP_CAPABILITIES 加 ui-drive + ENDPOINTS 补全；控制端按钮门控。零新传输层。

**Tech Stack:** 既有管道（协议包/被控面路由表/IPC 白名单/i18n/Vitest）。

**Spec:** `docs/superpowers/specs/2026-10-17-ui-drive-design.md`

## Global Constraints

- 铁律不触碰；mirror 风格（双引号/i18n 双语禁硬编码/主题变量）；哨兵规程；git add 精确。
- openRoute 白名单 `/module/` 前缀双校验（主进程+渲染层）；openSession 归属校验。
- 测试基线：mirror vitest（3634+）/typecheck（含 witness）；server npm test（286）。

**Files:**

- Test: `tests/ai/server-face/routes.test.ts` 补三端点用例（mock 窗口/webContents：聚焦调用/payload/白名单拒/4040/主窗缺失降级——多窗口取主窗策略照 graph-executor notifyNodeStatus 先例）
