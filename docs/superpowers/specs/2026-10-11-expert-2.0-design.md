# 专家功能 2.0——对齐 WorkBuddy 专家板块实现（第一期）设计文档

日期：2026-10-11
状态：已与用户确认范围与方案（分两期 + spawn 子 agent 路线）
前置：`2026-09-30-expert-market-design.md`（专家市场第一版，本设计是其「后续迭代方向」的落地与扩展）

## 背景与目标

参照 WorkBuddy 桌面版（`/Applications/WorkBuddy.app` asar 提取的实现，非 PRD）
专家板块的真实实现，补齐天枢专家功能的能力缺口。WorkBuddy 的专家 =
`plugin.json`（displayName/profession/displayDescription/categoryId/avatar/tags×3/
quickPrompts×3/defaultInitPrompt/skills）+ `agents/*.md`（五段式人设）+ expert-manager
skill（AI 创建/修改/校验/注册/打包全生命周期）+ recommend-experts（会话内 AI 主动
推荐）+ Team 型多 agent 协作。

**已拍板决策**：

- **分两期交付**（用户确认）：第一期做增量能力（本 spec），第二期做专家团
  spawn 子 agent 运行时（单独立项另出 spec）。
- **专家团路线 = spawn 子 agent**（用户确认）：新增 dispatch 类工具，execute 内
  经 provider 域非流式调用 LLM（成员独立 systemPrompt），WorkBuddy 同款架构。
- **市场数据不扩容**：只补字段与分类重映射（WorkBuddy curated-experts 46+12 条
  不搬，天枢 ~30 条够用）。
- **头像保持 emoji**：无图像生成底座（WorkBuddy 用 ImageGen 生成 512×512 漫画
  头像，不适用）。

### 第一期范围（八块）

1. 专家模型增强（+4 列，12 分类对齐）
2. AI 创建闭环（`create_expert` 工具）
3. AI 修改专家（`update_expert` 工具）
4. 会话推荐提示词（quickPrompts chips）
5. 专家附带技能（引用式 skillNames）
6. 会话内 AI 主动推荐专家（推荐卡）
7. 专家导入/导出（JSON 文件）
8. 市场数据补全（quickPrompts + 分类重映射）

## 2. AI 创建闭环：`create_expert` 工具

照 `create-skill.ts` 先例，新建 `electron/domains/ai/agent/create-expert.ts`：

- **schema**（zod）：`name`(1-30)、`profession`(≤30)、`systemPrompt`(min 1)、
  `description`(≤120)、`tags`(≤3)、`icon`(单 emoji 字符，可选)、
  `quickPrompts`(≤3 条，每条 ≤200)、`skillNames`(≤3，可选)。
- **校验链纯函数** `validateCreateExpertParams`（可单测）：zod → name 非空 →
  icon 宽松 emoji 校验（`u` flag 正则 + 长度）→ quickPrompts/skillNames 条数。
- **`kind:"write"` 走统一审批**：审批卡（ToolCallCard）展示参数摘要，批准才
  落库；拒绝文案回喂模型循环继续。落库 `builtin:false`。
- **skillNames 过滤**：非已安装技能名静默剔除，结果文案提示
  「已忽略未安装技能：x」；全被剔除则该字段存 null。
- **systemPrompt 写作规范内嵌工具 description**：五段式（角色定义/核心能力/
  工作流程/输出规范/注意事项），对齐 WorkBuddy Agent MD 正文结构。
- **「专家带技能包」不建新机制**：AI 组合 `create_skill`（造技能）→
  `create_expert`（引用）即可复刻 WorkBuddy 随包语义（description 中说明此
  组合用法）。
- 创建引导模板 `chat:experts.createPrompt` 升级：指示 AI 追问收集信息后调用
  `create_expert`（替代「AI 出草稿文本 + 人工回表单」；人工表单路径保留）。

## 3. AI 修改专家：`update_expert` 工具

同文件扩展（`create-expert.ts` 内并列导出，模式同上）：

- **schema**：`name`(定位既有专家，精确匹配 user 维度)、其余字段全部可选
  （undefined = 不改；语义同表单 update：传入即覆盖）。
- 定位失败（专家不存在）返回错误文案；`builtin` 专家允许改（能力等同市场
  添加行，无种子数据故 builtin 恒 false，此分支仅为防御）。
- `kind:"write"` 走审批；skillNames 同样过滤未安装项。

## 4. 会话推荐提示词（quickPrompts）

- **数据流**：市场 `ExpertMarketItem` + `quickPrompts` 字段；「添加到我的专家」
  带入落库；AssistantDialog 表单 + 推荐提示词编辑行（≤3，动态增删，空行提交
  时剔除）。
- **聊天页新组件 `ExpertPromptChips`**（`src-react/domains/ai/chat/components/`）：
  - 展示条件：会话绑定专家 && 专家有 quickPrompts && 该会话**尚无 user 消息**。
  - 位置：输入区上方，横排胶囊（≤3），对齐 new-task `PromptChips` 视觉。
  - 点击 = **填入输入框**并聚焦（模板填入语义，用户可编辑后发送）。
  - 数据源：`["assistants"]` 缓存（ChatInput/ChatPane 已同源消费）。
- 我的专家卡片副标题优先级：`description` > `profession` > systemPrompt 截断。

## 5. 专家附带技能（引用式）

- **运行时**（`chat.service.ts` `assembleContext`）：`collectEnabledSkills` 之后、
  `buildModeSystem` 之前，`assistantRow.skillNames` 对应技能**并入** sessionSkills
  （并集去重；已卸载技能静略）。抽纯函数 `mergeExpertSkills(skills, skillNames)`
  供单测。对齐「预设≠围墙」语义：只并入推荐，不硬过滤。
- **UI**：AssistantDialog + 技能多选（数据源 `["skillRecords"]`，胶囊多选）；
  ExpertDetailDialog 与市场/我的卡片展示技能胶囊（`⚡` 前缀同消息引用 token
  视觉）。
- **市场数据**：条目 `skillNames` 仅指向天枢技能市场既有条目（slug 对齐），
  无对应则留空。

## 6. 会话内 AI 主动推荐专家（推荐卡）

WorkBuddy recommend-experts 语义移植（skill + search_plugins +
suggest_plugin_install 三件套 → 天枢单工具 + 目录注入）：

- **工具 `recommend_experts`**（`kind:"read"`，同 widget 先例免审批）：
  - 参数：`candidates`（市场 slug 数组，1-3 个）+ `reason`（一句话场景说明，
    卡片标题下展示）。
  - execute 仅返回确认文本；slug 无效剔除，全无效报错文案。
- **市场目录后端可用**：`marketplace.ts` 留在 src-react，electron 侧直接
  import（先例：widget-tool.ts import `src-react/.../group-blocks`）。
- **system prompt 注入**（`assembleContext`）：`assistantRow === null` &&
  `mode === "agent"` 时，system 追加「专家推荐指令段」——市场目录摘要
  （slug + 名称 + 一句话描述，~30 条 ≈ 1.2K token）+ 推荐规则（对齐
  WorkBuddy 红线：**仅在任务明显需要专业角色时推荐、每次响应至多一次、
  不得静默启用/替换**）。已绑专家不注入（零成本）。
- **渲染**：推荐卡为独立 block 类型 `expert-recommend`（非 widget iframe——
  结构化内容 + 交互按钮）：候选胶囊卡（头像/名称/profession/description）+
  「添加并启用」按钮 → `AssistantApi.create`（市场模板带入）+
  `SessionApi.setAssistant` 绑定当前会话 + invalidate；失败 toast（mapIpcError）。
  渲染入口挂 `MessageItem` 工具调用分发处（与 widget block 同位）。
- 导出 `RECOMMEND_TOOL_NAME` 常量（`group-blocks.ts`，同 WIDGET_TOOL_NAME 先例）。

## 7. 专家导入/导出（JSON 文件）

- **导出**：我的专家卡片菜单 +「导出」→ electron dialog 存 JSON 文件。内容 =
  `name/profession/description/tags/quickPrompts/skillNames/categoryId/icon/
  systemPrompt`（不含 id/builtin/sourceSlug）。
- **导入**：我的专家头部「导入」→ dialog 选 JSON → 解析校验（zod，同导出
  schema）→ 落库（重名自动加后缀 `-2`；skillNames 过滤未安装）→ toast 汇总。
  不做预览确认弹窗（导入可删，轻量）。
- IPC：`assistant:export`（主进程写文件）、`assistant:import`（主进程读文件+
  落库）；前端 api 对接。纯函数 `serializeExpert`/`parseExpertJson` 可单测。

## 8. 市场数据补全（`marketplace.ts`）

- 全部条目补 `quickPrompts`（每条 3 个中文推荐提示词，内容数据不走 i18n）。
- `category` 重映射为 12 分类 key（market-filter.ts 纯函数不动，常量表换）。
- 可选补 `skillNames`（仅当指向技能市场既有 slug）。
- 精选场景（6 张）不动。

## 9. 国际化

`chat` namespace `experts` 节补 key（zh-CN/en-US 同步）：表单标签（职业头衔/

## 12. 与 WorkBuddy 实现的显式偏差

| WorkBuddy | 本设计 | 原因 |
| --- | --- | --- |
| 专家 = 文件包（plugin.json + agents/*.md + 头像 + 注册 marketplace.json） | 专家 = DB 行（assistant 表） | 单机应用，无插件市场分发；AI 创建/修改经工具落库对等实现 |
| 专家随包携带技能文件目录 | 引用式 skillNames（指向已安装技能） | 无文件包概念；AI 可组合 create_skill+create_expert 达成随包效果 |
| ImageGen 生成 512×512 漫画头像 | emoji 头像 | 无图像生成底座 |
| search_plugins 按需语义搜索 | system 注入目录摘要（~1.2K token，未绑专家时） | 本地 30 条无需搜索往返 |
| suggest_plugin_install 卡片 | expert-recommend block + recommend_experts 工具 | widget 先例 + 结构化 block 更适合交互按钮 |
| package_expert 打包 + 分享码安装 | JSON 导入/导出 | 无分享链路 |
| 云同步/企业市场/付费 | 不做 | 单机 |
| 12 分类原样 | key 对齐、名称本地化、旧 10 分类重映射 | 天枢市场已有分类语义 |

## 13. 第二期预告：专家团（spawn 子 agent，另出 spec）

- 数据：`assistant` + `expertType`("agent"|"team")、`members`（JSON：
  id/name/profession/role(lead|member)/systemPrompt，主理人在列）。
- 运行时：`dispatch_member` 工具——execute 内经 provider 域非流式调用
  （成员 systemPrompt + 任务简报 + 上一阶段结论），abortSignal 透传，结果作
  工具结果回传主循环；第一版串行调度。
- 主理人 systemPrompt 由 SOP 模板生成（成员能力清单 + Phase 编排 + WorkBuddy
  team-spec 编排铁律：禁止代写成员产出/跳阶段/成员直连）。
- 参考（已存 `/tmp/wb-exp/`，写 spec 时可再从 asar 提取）：team-spec.md
  （花名命名/主理人 profession/SOP 并行串行）、agent-md-spec.md（成员 prompt
  六要素）、curated-experts.json 专家团条目（12 个，含成员结构描述）。
- 市场专家团条目补成员结构；专家团卡片/详情展示成员列表。
