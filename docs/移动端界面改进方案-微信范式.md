# 天枢移动端界面改进方案（微信范式）

> 目标：参照微信的布局与交互范式重构天枢移动端（apps/tianshu-mobile）界面，
> **现有功能一项不丢**，只做信息架构重排 + 视觉/交互微信化 + 基础组件沉淀。
>
> 状态：初稿（待评审） ｜ 日期：2026-10-25

---

## 1. 现状诊断

调研结论（详见各页面源码）：

| 维度     | 现状                                                                                  | 对照微信的差距                                               |
| -------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 导航     | 单层 Stack 平推，无底部 Tab；设置/连接/编排藏在首页顶部按钮                           | 微信是「底部 Tab + Tab 内 push 堆栈」，一级功能一屏直达      |
| 会话列表 | grouped 卡片小行：标题+置顶图标+时间+chevron；无头像、无最后消息摘要、无未读角标      | 微信行 = 圆形头像+昵称+单行摘要+时间+未读红点                |
| 聊天页   | 输入区上方 chips 行（权限/专家/模式/用量/模型）+ 全宽无气泡助手消息、无头像、无时间戳 | 微信 = 顶栏 ⋯ 收纳设置项，双气泡 + 头像，超 5 分钟插时间分隔 |
| 输入区   | 一体式大圆角输入条 + 「+」底部菜单                                                    | 交互已接近，面板改微信九宫格样式即可                         |
| 手势     | 会话左滑三操作、长按面板、下拉刷新、触觉反馈                                          | 已具备，全部保留                                             |
| 基础组件 | 无通用 ListItem/Avatar/Badge/Button，Pressable 就地拼装                               | 微信式的根基是统一基础组件                                   |

现有视觉体系（iOS grouped 风格、NativeWind 4、四主题色、明暗三档、Toast 毛玻璃）
**全部保留**，本方案不改主题机制，只改信息架构与组件形态。

## 2. 信息架构：底部四 Tab（微信四 Tab 映射）

```
┌─────────────────────────────┐
│  Stack（全局，slide_from_right） │
│  ├─ (tabs)                  │
│  │   ├─ 聊天   → 会话列表（tab 内 stack：session/[id] push） │
│  │   ├─ 主机   → 连接管理    │
│  │   ├─ 编排   → Graph/自动化 │
│  │   └─ 我的   → 设置        │
│  ├─ session/[id] 聊天详情（push，全屏） │
│  └─ smoke（开发页，深埋）     │
└─────────────────────────────┘
```

| 微信 Tab | 天枢 Tab | 内容来源                             | 顶栏                                                                      |
| -------- | -------- | ------------------------------------ | ------------------------------------------------------------------------- |
| 微信     | **聊天** | `src/app/index.tsx` 会话列表全量平移 | 大标题「聊天」+ 右上：连接状态点（点击弹切换）、放大镜搜索 |
| 通讯录   | **主机** | `src/app/connections.tsx` 全量平移   | 大标题「主机」+ 右上「+」添加连接                                         |
| 发现     | **编排** | `src/app/orchestration.tsx` 全量平移 | 大标题「编排」，Graphs/Automations 分段保留                               |
| 我       | **我的** | `src/app/settings.tsx` 重组（见 §6） | 无顶栏（微信「我」也无大标题栏）                                          |

技术实现：Expo Router `(tabs)` 目录 + `Tabs.Screen` 四枚，Tab 栏图标走现有
`AppIcon`（iOS SF Symbols），选中态用主题 `primary`；聊天 Tab 内嵌 stack 使
`session/[id]` 以微信式全屏 push 进入。

**入口迁移裁定**：

- 首页顶部的设置/编排按钮删除，由 Tab 承担（编排入口仍受 `graph` capability 控制，
  无能力时编排 Tab 显示不支持态，与现行为一致）。
- 新建会话入口在**各工作空间组头目录名右侧**（聊天冒泡+号样式；2026-10-25 走查裁定：原顶栏「+」
  创建归属不明），点击即在该空间下建会话并直入聊天页；未归属目录已整体移除（用户走查裁定：两端建会话必挂空间，该目录常态为空）。
- Smoke 开发页从会话列表页脚移入「我的 → 关于 → 开发者选项」。

## 3. 聊天 Tab：会话列表微信化

### 3.1 行结构

```
┌────────────────────────────────────────────┐
│ ┌────┐  会话标题               14:02       │
│ │ 头 │  最后一条消息摘要…    ┌──┐           │
│ │ 像 │  （单行截断）        │ 3│（未读角标）│
│ └────┘                      └──┘           │
└────────────────────────────────────────────┘
```

- **头像**：新增 `Avatar` 组件——标题首字符圆形色块，底色按会话 hash 从主题四色
  系取色；绑定专家时用专家图标。置顶行头像不变。
- **摘要**：最后一条消息纯文本单行截断；生成中显示「正在输入…」。
  数据依赖见 §8 分期。
- **时间**：`updatedAt` 相对时间（已有），移到右上角。
- **未读角标**：新增 `Badge` 组件，红底白字（>99 显示 99+）。P1（协议扩展）。
- 置顶分区置顶的交互保留（store 已有排序逻辑），置顶行底色用 `field` 灰。

### 3.2 分组与搜索（功能保留）

- workspace 分组**保留**（懒加载折叠交互不动），组头从组卡改为微信式灰字小组头；未归属目录不再渲染（未匹配会话仅搜索态兜底分组可见）。
- 顶栏放大镜按钮展开/收起搜索输入（微信式：输入框 + 取消）；归档筛选收进搜索面板——输入框下细分线上的「未归档/全部」选项，收起搜索即复位「未归档」；搜索态平铺结果不变。
- 下拉刷新、分页加载、骨架屏、空态/无连接引导全部保留。

### 3.3 手势（全部保留）

- 左滑三操作（置顶/归档/删除，ReanimatedSwipeable 实现不动）。
- 长按底部操作面板（`SessionActionsSheet` 视觉统一为 §7 `ActionSheet`）。
- 归档/删除的系统 `Alert` 二次确认保留（危险操作维持强确认）。

## 4. 聊天详情页微信化

### 4.1 顶栏

```
←  会话标题              文件夹（有产物时）
```

- 模型选择（`ModelPicker`）、模式（Ask/Agent/Plan）、工具权限、专家、
  上下文用量保留在输入区上方可见 chips 行，不收进「⋯」。
- 会话产物保留头部文件夹入口，仅有产物时显示，直接打开 `SessionFilesSheet`。
- 顶部保留连接状态轻提示（现头部信息不丢，具体形式实现期定）。

### 4.2 消息流

- **助手消息进气泡**：白色圆角气泡（`card` 色），内嵌现有 `MarkdownLite` 全套
  富内容（代码块/Mermaid/表格/思考面板/工具卡等组件原样保留，只是装进气泡容器）。
- **用户消息**：右侧圆角气泡，浅色用 `primary` subtle 底、深色用 `primaryActive` 底，
  替代现灰底。
- **头像**：助手消息左侧加主题色圆形头像（App Logo 风格）；用户消息右侧不带头像
  （同微信）。
- **时间分隔**：相邻消息间隔 >5 分钟插入居中小字时间戳。
- 流式淡入、`ToolCallCard` 六态、`ApprovalBanner` 队列 Banner 原位保留。

### 4.3 消息操作（保留 + 视觉统一）

长按用户消息：复制/编辑并重发；长按助手消息：复制/重新生成。
`MessageActionsSheet` 视觉统一为 §7 `ActionSheet`。

### 4.4 输入区

- 微信式底栏：「+」｜多行输入（高度限制/键盘抬升/编辑重发提示不动）｜
  发送/停止按钮（触觉反馈保留）。
- `PlusSheet` 改微信九宫格面板：引用工作区文件、拍照、相册、上传本地文件、
  引用技能——现有五项全保留，只改排列。
- **不虚构语音输入**（无此功能，微信麦克风位留空不引入）。

## 5. 主机 Tab（通讯录范式）

- 连接列表全量保留：直连/中继两类、新建/编辑（全屏 Modal）、测试、
  激活切换、删除（Alert 确认）、状态/端点/被控用户展示。
- 视觉统一为 `ListItem` 行 + `GroupSection` 分组卡；连接数少，不做字母索引（YAGNI）。

## 6. 编排 Tab（发现范式）

- Graphs/Automations 分段切换保留（iOS segmented 样式）。
- 卡片全部功能保留：列表/分页/下拉刷新、运行/中止、状态徽标 + `DetailSheet`、
  启用暂停 Switch、立即运行、长按删除确认；无连接/无 capability 引导保留。

## 7. 我的 Tab（我 范式）

```
┌─────────────────────────────┐
│ [头像] 主机名            ›  │   ← 当前连接卡片：名称+状态点+端点，
│        已连接 · http://…    │      点击进主机 Tab
├─────────────────────────────┤
│ 外观        语言/明暗/主题色  │   ← 现 settings 三组平移
│ 通知        总开关+审批+Graph │
│ 技能        列表/启停         │
│ MCP 连接器  列表/启停         │
│ 关于        版本/已知限制/开发者 │
└─────────────────────────────┘
```

现有设置项一项不丢，仅重组为 grouped 列表 + 顶部连接卡片。

## 11. 风险与注意

- **nativewind 必须在 mobile 本地树**：根 `npm install` 会毁本地 nativewind（恢复脚本
  `restore-local-nativewind.sh`），本期改动仅限 mobile 仓内，禁止根目录重装。
- **RN 动画值必须经 Animated 包装组件**（裸组件传动画值 Android 真机红屏）——
  气泡/面板动效遵守。
- Tab 化改动根 `_layout.tsx` 路由结构：需回归 push/pop 行为、深链、
  键盘与转场（`slide_from_right` 保留）。
- 两端主题色已同步（2026-10-25 起废除 mobile 绿/橙系统色分叉），任一侧改值须双向同步。
- 未读数为 P1 新增能力，不算「现有功能」，不纳入不丢失承诺。

## 12. 走查修订（2026-10-25）

- **chips 回可见行**：否决「⋯」收纳，模型/模式/权限/专家/用量恢复输入区上方可见行；产物文件恢复顶栏文件夹入口（有产物时显示）。
- **搜索按需展开**：常驻搜索框改为聊天顶栏放大镜按钮，点击展开；关键词为空时再点放大镜或「取消」均可收起，关键词非空时仅「取消」可清空并收起；搜索态分组平铺与防抖不变。
- **主题色两端同步**：移动端 green/orange 改用桌面色值，废除系统绿/系统橙分叉；blue/red 不动，subtle 继续走移动端明暗 tint-alpha 机制。
- **未归属目录移除**：组态列表只渲染真实工作空间（常态为空没必要存在）；未匹配会话仍在搜索态兜底分组呈现，不丢数据。
- **归档筛选进搜索**：常驻「未归档/全部」pill 收进搜索面板（细分线 + 居中选项），收起搜索即复位未归档；组态展开组随筛选即时重拉。
- **新建会话下放组头**：顶栏「+」下放到各工作空间组头，**目录名右侧、聊天冒泡+号样式**（MessageSquarePlus 主题色，用户走查二裁：左侧灰「+」不够醒目），点击即在该空间下建会话并直入聊天页；store `create` 同步支持 `workspaceId` 并按归属组定向插入缓存（不再全清——展开中的组不再瞬时误显「暂无会话」）。
