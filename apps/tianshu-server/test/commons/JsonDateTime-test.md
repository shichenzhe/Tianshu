# JsonDateTime 装饰器单元测试文档

## 概述

本文档描述了 `JsonDateTime` 装饰器的单元测试策略和测试用例覆盖范围。

## 测试文件位置

- 测试文件：`test/JsonDateTime.decorator.spec.ts`
- 源文件：`src/commons/codec/JsonDateTime.decorator.ts`

## 测试策略

### 测试目标

- 验证 `JsonDateTime` 装饰器能够正确解析多种日期格式
- 确保错误处理机制正常工作
- 验证边界情况和异常场景

### 测试方法

- 使用 `class-transformer` 的 `plainToInstance` 方法进行转换测试
- 采用 AAA（Arrange-Act-Assert）模式编写测试用例
- 使用 Jest 框架进行单元测试

## 测试用例覆盖

### 1. 字符串日期解析（7个测试用例）

#### 支持的日期格式

- `yyyy-MM-dd'T'HH:mm:ss` - ISO 日期时间格式
- `yyyy-MM-dd'T'HH:mm:ss.SSSZ` - 带毫秒和时区的 ISO 格式
- `yyyy-MM-dd HH:mm:ss` - 空格分隔的日期时间格式
- `yyyy-MM-dd` - 仅日期格式
- `yyyy-MM-dd HH:mm:ss.SSS` - 带毫秒的日期时间格式
- `yyyy-MM-dd HH:mm:ss.SSSZ` - 带毫秒和时区的日期时间格式
- `yyyy-MM-dd'T'HH:mm:ss'Z'` - 带 Z 后缀的 ISO 格式

#### 特殊处理

- **Z 后缀处理**：将 'Z' 替换为 '+0000'，符合 Java `DateUtils.parseDate` 的逻辑

### 2. 数字时间戳解析（2个测试用例）

- **有效时间戳**：正确解析毫秒级时间戳
- **无效时间戳**：对 NaN 值抛出错误

### 3. Date对象处理（1个测试用例）

- **Date对象直接返回**：验证已有的 Date 对象能正确处理

### 4. null和undefined处理（2个测试用例）

- **null值处理**：正确处理 null 值
- **undefined值处理**：正确处理 undefined 值

### 5. 错误处理（4个测试用例）

- **不支持的日期格式**：对无效格式字符串抛出错误
- **无效日期值**：对无效日期值抛出错误
- **不支持的值类型**：对布尔类型等不支持的类型抛出错误
- **对象类型**：对对象类型抛出错误

### 6. 边界情况（3个测试用例）

- **闰年日期**：正确处理闰年2月29日
- **1970年日期**：正确处理Unix纪元时间
- **未来日期**：正确处理2099年的日期

## 扩展测试

如需添加新的日期格式支持，请：

1. 在 `DATE_PATTERNS` 数组中添加相应的正则表达式
2. 在测试文件中添加对应的测试用例
3. 确保新格式的边界情况也被测试覆盖

## 注意事项

- 测试使用的是本地时区，在不同时区环境下运行可能会有差异
- 时间戳测试使用固定的毫秒值，确保测试结果的一致性
- 所有错误消息都应该包含原始输入值，便于调试
