产品需求文档：设置面板 - 外观模块

产品概述

1.1 背景
用户希望根据个人喜好自定义 tianshu 客户端的视觉主题。不同用户有不同的审美偏好和使用场景（如白天使用浅色主题、夜间使用深色主题），同时提供丰富的个性化皮肤选项可以增强产品的趣味性和用户粘性。

1.2 核心目标
主题切换： 提供浅色、深色及多种联名/精选皮肤，满足个性化审美需求。
实时预览： 选择主题后，预览区域即时展示当前主题效果，降低用户决策成本。
便捷管理： 主题以卡片式缩略图排列，一目了然，点击即可切换。

页面结构与布局

页面采用经典的 左右分栏布局：
左侧导航栏 (Sidebar)： 固定宽度，包含所有一级设置分类。当前选中"外观"项，以浅蓝色背景高亮。
右侧内容区 (Content)： 滚动区域，从上到下依次为：
    主题预览卡片（占据上半部分显著位置）
    全部主题选择区（卡片网格）

功能模块详解

3.1 主题预览区域 (Theme Preview)

位置： 右侧内容区顶部，占据大面积展示区域。

内容构成：
预览卡片： 一个圆角大卡片，展示当前选中主题在实际界面中的视觉效果。
    卡片内模拟了软件的主界面布局（左侧侧边栏 + 中间对话区域），让用户直观看到主题对整体 UI 的影响。
    预览卡片右上角显示一个深灰色胶囊标签，文字为"永久有效"（标识当前主题的属性，如付费主题可能显示"限时"等）。
交互： 预览区域为只读展示，不可直接操作。

3.2 全部主题选择区 (All Themes)

位置： 预览卡片下方，标题为"全部主题"。

布局： 主题缩略图以网格形式排列，每行展示 5 张卡片，支持滚动浏览更多主题。

选中状态：
当前选中的主题卡片周围显示黑色边框（或高亮边框），与未选中状态区分。
选中"涟漪"主题时，上方预览区域同步更新为该主题的预览效果。

交互逻辑：
点击切换： 点击任意主题卡片，立即切换应用主题，预览区域同步更新。
加载状态： 切换主题时，预览区域可显示 Loading 骨架屏，切换完成后展示新主题效果。
主题属性标识： 联名皮肤或限时皮肤可在卡片上附加角标（如"联名""限时""VIP"等）。

主题切换全局影响

切换主题后，以下界面元素应同步更新：
侧边栏背景色： 跟随主题色变化（浅色主题用浅灰，深色主题用深灰/黑）。
主内容区背景： 对话区域、设置面板等所有页面背景色跟随主题。
文字颜色： 浅色主题用深色文字，深色主题用浅色文字。
组件颜色： 按钮、输入框、分割线等组件的边框和填充色跟随主题。
图标颜色： 线性图标颜色适配主题背景。

异常与边界情况

主题加载失败： 若主题图片资源加载失败，显示默认主题（浅色），并在卡片上显示错误占位图。
网络主题： 若联名皮肤需要网络下载，切换时显示下载进度，下载失败时提示用户重试。
主题持久化： 用户选择的主题需本地存储，重新打开应用后自动恢复上次选择的主题。
主题兼容性： 确保所有内置页面（聊天、设置、自动化等）都能正确适配新主题，避免出现文字与背景同色的情况。
