# 记忆与进化模块设计（设置面板）

日期：2026-09-09
状态：已与用户逐节确认
前置：2026-09-09-personalization-design.md（本模块与其并存，不改动其既有行为）

## 1. 背景与目标

- **记忆可见**：用户可查看 AI 从对话中提炼的四类画像（工作背景/个人背景/当前关注/近期动态）。
- **记忆可控**：支持 AI 指令式增删、整段编辑、重置、导入。
- **记忆可迁移**：预置提示词让用户在外部 AI 生成个人画像后导入。
- **隐私透明**：说明文案披露运行机制；本期「隐私政策」为纯文案（非链接）。

## 2. 已确认的关键决策（D 编号）

- **D1 两套记忆并存**：本模块的画像记忆与既有 `personalization.memory`（用户手动长期记忆）是两个独立概念，均注入 system prompt，互不迁移。
- **D2 导入提示词改为四分类输出**：预置提示词要求外部 AI 按 工作背景/个人背景/当前关注/近期动态 输出，条目格式 `[YYYY-MM-DD] - 内容`；不做五分类映射。
- **D3 关闭开关 = 停止生成，记忆保留**：关闭后记忆转只读 + 底部提示条；不删除数据、无清空确认弹窗；空状态仅在「从未生成或已重置」时出现。「停止生成」与「删除数据」是两个独立动作（后者归重置按钮）。
- **D4 每晚定时 + 启动补跑**：运行期 02:00–04:00 窗口执行；启动时距上次整理 >24h 则延迟 90s 补跑。用 provider 的 `defaultModelId`，无可用模型静默跳过。
- **D5 编辑形态遵循 PRD 原文**：四板块为多行文本域 + 底部单输入框（纸飞机）；输入框内容是 **AI 指令**（如「删掉天气相关记忆」），由 AI 决定追加分类/匹配删除。编辑输入框与每晚整理共用一套「AI 应用记忆变更」机制。
- **D6 埋点本期不做**：PRD §6 埋点需求暂缓，待统一埋点基础设施。
- **D7 隐私政策本期为纯文案**，不带链接。
- **D8 单字段 markdown 存储**：记忆正文存 option 表单个 key 的 markdown 文本，不新建 Prisma 表、不升 DB 版本。

## 3. 数据模型

option 表（type="app"）新增 4 个 key：

| key                                    | 类型          | 说明                                        |
| -------------------------------------- | ------------- | ------------------------------------------- |
| `personalization.memoryProfile`        | markdown 文本 | 记忆正文，限长 8000（解析端截断保尾部最新） |
| `personalization.memoryEnabled`        | bool          | 生成开关，默认 true                         |
| `personalization.memoryLastCompiledAt` | ISO 时间      | 上次整理时间；缺省 = 从未整理               |
| `personalization.memoryLastError`      | 文本          | 最近一次整理失败原因；空 = 无失败           |

### 3.1 记忆 markdown 格式（全链路统一约定）

```markdown
## 工作背景

用户参与 Tianshu 项目，负责 UI 复刻…

## 个人背景

用户位于福建厦门…

## 当前关注

[2026-09-08] - Tianshu 项目 UI 界面复刻…

## 近期动态

[2026-09-08] - 开始推进 Tianshu 项目相关工作
[2026-09-07] - 查询厦门天气
```

- 分类固定四节，标题精确匹配 `## 工作背景` / `## 个人背景` / `## 当前关注` / `## 近期动态`；节顺序固定为上述顺序（拼接时规范化）。
- 条目行 `[YYYY-MM-DD] - 内容`；日期未知可省略。近期动态按时间倒序（新在上）。
- 存储格式 = AI 输出格式 = 导入粘贴格式，仅展示时切分。

### 3.2 system prompt 注入

`personalization.prompt.ts` 在【用户长期记忆】段之后、【用户自定义指令】之前追加：

```
【用户画像记忆】
以下是系统从对话中提炼的用户画像，请在对话中参考：
<memoryProfile 内容>
```

`memoryProfile` 为空则跳过该段。缓存友好约束不变（同 config → 逐字节相同输出）。

## 5. AI 整理管线

### 5.1 触发路径（共用 compiler）

| 路径     | 触发                     | 输入                |
| -------- | ------------------------ | ------------------- |
| 定时整理 | MemoryScheduler 窗口命中 | 近期对话 + 当前记忆 |
| 启动补跑 | MemoryScheduler 启动检查 | 同上                |
| 编辑指令 | 用户在编辑输入框发送     | 用户指令 + 当前记忆 |

### 5.2 MemoryScheduler 决策（30s tick）

```
tick():
  开关关 / 已有整理在途(inflight) → noop
  距上次尝试 <10 分钟（编译失败退避 RETRY_BACKOFF_MS）→ noop
  补跑标志待评估（90s 计时到点挂起）→ 评估一次即消费（置 false，无论结果）：
    距上次整理 >24h → catchUp → compile
    不满足 / 评估失败 → 等夜间窗口
  当前时间 ∈ [02:00, 04:00) && 当日未整理 → compile
compile():
  读记忆+近期对话 → 调模型 → 解析输出 → 写 memoryProfile + memoryLastCompiledAt
  失败 → 记录尝试时间（供 10 分钟退避），Log.warn，静默等待重试，不弹窗
```

- 进程级 inflight 互斥（定时与手动不并发）；应用退出 abort 在途请求。
- 「当日未整理」以本地日期与 `memoryLastCompiledAt` 比对。
- 修订 2026-09-10（终审 I1/M4）：新增失败退避行——编译失败后 10 分钟内不再尝试；catchUp 标志在 90s 补跑评估后即消费（未满足 24h 也不再阻塞夜间窗口分支，等当夜 02:00–04:00 窗口）。

### 5.3 compiler 细节

- **对话范围**：各 workspace 最近 7 天的 user/assistant 消息，总量保留最近 30k 字符（超出丢弃最旧），过滤工具调用噪音。**无可用对话材料时直接跳过**（不调模型、不更新 LastCompiledAt），避免新用户/重置后空调用。
- **模型**：`defaultModelId` 对应模型；无模型/无 key → 定时路径静默跳过，指令路径返回友好错误。
- **Prompt**（主进程常量，zh/en 两份）：
  - 系统：你是记忆管理器。给定当前记忆与新材料（对话摘要或用户指令），输出**完整的**新记忆 markdown：四分类固定标题与顺序、条目 `[YYYY-MM-DD] - 内容`、近期动态 ≤20 条倒序、单条 ≤500 字、总长 ≤8000。只输出 markdown，不要解释。
  - 用户：当前记忆 + 材料。
- **输出处理**：`memory-markdown.ts` 统一解析（标题校验、条目规范化、超限截断保尾部最新）；彻底失败（空/四标题未齐备，修订 2026-09-10 终审 I2）→ 定时路径保留原记忆 + 日志，指令路径报错。

### 5.4 编辑指令交互

发送 → 输入框/按钮 loading → IPC → AI 应用 → **直接落库并返回新记忆**，前端刷新展示（修订 2026-09-10 验收反馈：记忆文本只读渲染，修改仅经 AI 指令，指令结果直接持久化）。

## 6. 前端交互（MemoryGroup）

### 6.1 页面结构

```
大标题「记忆与进化」+ 说明文案（「隐私政策」纯文案）
[卡片] 生成对话记忆 —— 描述 + Toggle（默认 ON，即时生效）
[卡片] 管理记忆 —— 副标题「记忆每晚自动整理更新」
        头部按钮：重置(红边框) / 编辑 / 导入
        内容区：四分类板块（右侧滚动条）
```

### 6.2 状态

- **展示态**：markdown 切分填入四板块（标题深色粗体 14px、正文 12px 行高 1.5、近期动态逐条 `- ` 开头）；单条 >500 字折叠 + 「展开」按钮。
- **编辑态**：头部变 重置/取消/保存（导入隐藏）；四板块变 Textarea；底部输入框 + 纸飞机发送 AI 指令（loading 态）。「取消」丢弃修改恢复原内容；「保存」持久化 + 失效缓存。
- **开关关闭**：记忆只读 + 底部提示条「已关闭对话记忆生成，记忆内容将不再自动更新」；编辑态中关开关 → 退出编辑转只读（无确认弹窗）。
- **空状态**：仅「从未生成或已重置」——中央图标 + 「开启对话记忆后，AI 将自动为您整理使用偏好与背景信息」+ 「去开启」按钮（滚动聚焦上方开关）。

### 6.3 重置

确认弹窗：三行警告（清空不可恢复 / 开关开启则后续仍会生成 / 需彻底停用请关闭功能）+ 取消（白底灰边）+ 重置记忆（珊瑚红实心）。确认 → 清空 memoryProfile → 空状态 + Toast「记忆已重置」。开关与 LastCompiledAt 不变。

### 6.4 导入

弹窗两步：

1. **复制提示词**：序号 ① 标题「复制以下提示词到其他 AI 对话中」+「复制」按钮（成功短暂变「已复制」；失败提示「复制失败，请手动选择复制」）。预置提示词为 D2 四分类版，要求外部 AI 输出四节 markdown + 代码块包裹 + 末尾覆盖度说明（说明部分解析时忽略）。
2. **粘贴导入**：序号 ② 标题「将结果粘贴到下方，添加到 Tianshu 记忆」+ 多行输入框（占位「在此粘贴你的记忆」）+ 取消 / 导入按钮（有内容才可点）。

导入 = **合并追加**到现有记忆（非覆盖）：同分类条目追加、近期动态按日期重排倒序。解析失败（无任何四标题）→ 全部进工作背景 + Toast「未能识别分类标记，全部内容已存入工作背景」。成功 → 关弹窗 + Toast「记忆导入成功」。代码块围栏 ``` 剥离后解析。

## 7. 错误处理

| 场景             | 行为                                                                        |
| ---------------- | --------------------------------------------------------------------------- |
| AI 指令失败/超时 | Toast「记忆指令应用失败」，文本域保留原草稿                                 |
| 定时/补跑失败    | Log.warn 静默，等下一 tick/窗口 + 失败原因写入 memoryLastError 供设置页展示 |
| 无可用模型       | 指令路径 Toast 提示先配置模型；定时静默跳过                                 |
| 保存失败         | Toast `settings:error.saveFailed`                                           |
| 复制失败         | 按钮旁提示「复制失败，请手动选择复制」                                      |
| 解析失败         | 导入回退工作背景（§6.4）；AI 输出失败保原记忆（§5.3）                       |
