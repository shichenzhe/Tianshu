# 专家功能 2.0（第一期）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 对齐 WorkBuddy 专家板块实现，落地专家模型增强（+4 列）、AI 创建/修改闭环、会话推荐提示词、专家附带技能、会话内 AI 推荐卡、JSON 导入导出与市场数据补全。

**Architecture:** 数据层（assistant 表 +4 列）→ 工具层（create/update/recommend 三 agent 工具，照 create-skill/widget 先例）→ 运行时（chat.service 专家技能并入 + 未绑专家目录注入）→ 前端（表单/市场/卡片/chips/推荐卡）。市场数据留在 src-react，electron 直接 import（widget-tool 先例）。

**Tech Stack:** Electron 主进程 TypeScript + Prisma(better-sqlite3) + React 19 + TanStack Query + react-i18next + zod + Vitest。

**Spec:** `docs/superpowers/specs/2026-10-11-expert-2.0-design.md`（本计划从 spec 出发，执行者须同时读 spec）

```ts
import { z } from "zod";
import type { ToolDefinition } from "./file-tools";

const createSchema = z.object({
  name: z.string().min(1).max(30).describe("专家名称（30 字内）"),
  profession: z.string().max(30).optional().describe("职业头衔，如「软件架构师」"),

  description: z.string().max(120).optional().describe("能力介绍（40-120 字）"),
  tags: z.array(z.string()).max(3).optional().describe("擅长领域标签，最多 3 个"),
  icon: z.string().max(8).optional().describe("单个 emoji 头像"),
  quickPrompts: z.array(z.string().min(1).max(200)).max(3).optional()
    .describe("推荐提示词，最多 3 条，口语化可直接发送"),
  skillNames: z.array(z.string()).max(3).optional()
    .describe("附带技能名（已安装技能），最多 3 个；如需新技能先用 create_skill 创建再在此引用"),
```

`validateCreateExpertParams(args: unknown)`：zod safeParse → 失败取 `issues[0].message`；成功返回 `{ ok: true, data }`。

```ts
/**
 * recommend_experts 内置工具（WorkBuddy suggest_plugin_install 移植）：
 * 会话未绑专家时模型依据 system 目录段主动推荐候选，渲染层在消息流
 * 呈现专家推荐卡（ExpertRecommendCard）。无副作用（渲染层消费 args）
 * → kind:"read" 免审批，execute 仅返回确认文本回喂模型。纯 Node 实现。
 */
import { z } from "zod";
import { MARKET_EXPERTS } from "../../../../src-react/domains/ai/experts/data/marketplace";
import type { ToolDefinition } from "./file-tools";

export const RECOMMEND_TOOL_NAME = "recommend_experts";

const argsSchema = z.object({
  candidates: z.array(z.string()).min(1).max(3)
    .describe("市场专家 slug 数组（1-3 个，来自 system 目录段）"),
  reason: z.string().min(1).max(120)
    .describe("一句话推荐理由（卡片标题下展示）"),
});

export function makeRecommendExpertTool(): ToolDefinition<z.infer<typeof argsSchema>> {
  return {
    name: RECOMMEND_TOOL_NAME,
    description:
      "在聊天消息流中渲染专家推荐卡。仅当当前会话未绑定专家、且任务明显受益于专业角色时调用；每次回复至多调用一次；用户未采纳前不得重复推荐同一批候选；禁止代替用户启用专家。",
    parameters: argsSchema,
    kind: "read",
    execute: async (_ctx, args) => {
      const valid = args.candidates.filter((slug) =>
        MARKET_EXPERTS.some((e) => e.slug === slug),
      );
      if (valid.length === 0) {
        return "错误: 候选 slug 均不在专家目录中，请从 system 提供的目录里选择";
      }
      return `已渲染 ${valid.length} 位专家的推荐卡（用户可点击添加并启用）`;
    },
  };
}
```

```ts
export function mergeExpertSkills(
```
