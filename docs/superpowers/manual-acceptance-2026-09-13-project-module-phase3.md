## 走查清单

## 一、计划 Tab（表格 / 看板）

### 1. 添加事项（弹窗全字段）

- **操作步骤**：计划 Tab 右上「添加」，在弹窗中填标题、选状态/优先级、标签输入回车添加（既有标签出现候选 chips，点选追加）、填自定义字段（按字段定义渲染 text/number/date 三型输入），保存。
- **预期结果**（spec §3.6/§3.4）：表格即时新增该行并 toast「已保存」，任务 Tab 同步出现（createdById=我，双 key 失效）；空标题禁用提交（blur 内联「请输入标题」）、超 100 字禁用（「标题不能超过 100 字」）。
- **Commit 区域**：827d420（PlanItemDialog + 动态字段渲染）、eacc2f1（i18n）。

### 2. 表格行内改状态（走 move）与优先级

- **操作步骤**：对某行行内状态下拉切到「已完成」，再对另一行行内优先级下拉切到 P0。
- **预期结果**（spec §3.2/§3.4）：状态立即变更（乐观更新）且走 move 通道（sortOrder=目标列尾 max+1，切到看板可见该卡落在「已完成」列尾）；优先级走 update 通道、徽标即时变色（P0 红 / P1 主题色 / P2 弱化）；成功均无 toast（口径见附录 A5）。
- **Commit 区域**：8c7a568（行内 Select + move 通道裁定）。

### 3. 快速新增（回车；中文输入法回车确认不误建）

- **操作步骤**：表头上方快速新增行输入标题按回车；再用中文输入法输入拼音串、按回车确认候选词（组合态回车）。
- **预期结果**（spec §3.4）：回车即建（缺省待开始/P1）、输入框清空、双 key 失效同步任务 Tab；空标题回车忽略；输入法组合态回车不触发创建（`isComposing` 守卫），候选上屏后回车才创建。
- **Commit 区域**：8c7a568（快速新增行）、962e5fd（IME 守卫）。

### 4. 表头管理自定义字段（增/改名/删——值清理）

- **操作步骤**：点表头字段列尾「+」打开字段管理弹窗：新增 number 字段「预算」与 date 字段「里程碑」保存；重命名「预算」为「预算上限」保存；最后删除「里程碑」保存，回表格查各行该列。
- **预期结果**（spec §3.2/§3.4/§4）：动态列即时出现/更名（弹窗内事项编辑同步渲染新输入型）；删除字段后各行 customFields 该键值被同步清理（列消失），残留清理失败会 toast「清理字段值失败 N 条」汇总；空名/重名时保存按钮禁用（后端中文校验兜底）。
- **Commit 区域**：827d420（CustomFieldsEditor）、f1802c1（option 域定义 + 行内值同步清理）。

### 5. 筛选组合 + 搜索

- **操作步骤**：依次叠加标签多选 → 状态多选 → 优先级多选，再在搜索框输入标题片段。
- **预期结果**（spec §3.4）：维度内 OR、跨维度 AND 即时过滤（勾选不关菜单、按钮显示已选计数）；搜索标题不区分大小写包含、清空恢复全量；组合无匹配时保留表头与快速新增行、无数据行（裁定见附录 A6）。
- **Commit 区域**：8c7a568（FilterMenu/搜索）。

### 6. 切看板 URL 保 tab

- **操作步骤**：计划 Tab 点看板视图图标，观察地址栏；再切到「动态」Tab 又切回计划。
- **预期结果**（spec §3.4）：URL 为 `?tab=plan&view=kanban`（合并式写入保留 `?tab=`）；切走再切回仍为看板视图；手工输非法 `?view=bogus` 回落表格视图。
- **Commit 区域**：8c7a568（switchView 合并式 + ProjectWorkspaceView switchTab 同修）。

### 7. 看板拖拽跨列流转

- **操作步骤**：把一张卡拖到另一列（分别试：落在某卡上、落在列背景/列尾）。
- **预期结果**（spec §3.4/§2）：松手即落入目标列（落卡片=插到其后、落列背景=列尾），两列计数 Badge 同步，刷新/重进保持（move 通道持久化）；拖拽位移 ≤6px 仍是点击不误开编辑弹窗；move 失败时回滚原位 + toast。
- **Commit 区域**：962e5fd（dnd-kit 四态泳道 + 乐观回滚）。

### 8. 看板列内重排

- **操作步骤**：在同一列内把一张卡拖到另一卡下方或列尾，观察顺序并刷新验证持久化；再试「相邻下移一格」（拖 A 到紧邻其下的 B 上松手）。
- **预期结果**（spec §3.4/§2 列内顺序）：列内顺序即时变化且 sortOrder 持久化（重进/刷新保持）；已知边界——相邻整数序号间插入取均值可碰撞，相邻下移一格可能视觉不动（附录 A1），走查时手动确认实际行为并记录。
- **Commit 区域**：962e5fd（computeDrop/computeSortOrder 均值方案）。

### 9. 看板列头 + 预置状态新建

- **操作步骤**：点「进行中」列头的「+」，在弹出的新建弹窗直接保存。
- **预期结果**（spec §3.4）：弹窗状态 Select 预置「进行中」（非缺省待开始），保存后卡片直接落在该列；工具栏「添加」仍复位缺省态；编辑已有卡时预置被忽略（回填自身状态）。
- **Commit 区域**：962e5fd（defaultStatus + 列头 +）。

### 10. 卡片点击开编辑弹窗

- **操作步骤**：单击（不拖动）任一看板卡片。
- **预期结果**（spec §3.4/§3.6）：打开编辑弹窗并回填该卡标题/状态/优先级/标签/自定义字段；保存后看板卡片与任务 Tab 同步更新。
- **Commit 区域**：962e5fd（卡片 click=onEdit + PointerSensor 距离阈值区分）、827d420（编辑回填）。

## 二、任务 Tab

### 11. 新建本地任务

- **操作步骤**：项目详情 → 任务 Tab → 「新建本地任务」，填标题（可加标签/状态/优先级）保存。
- **预期结果**（spec §3.5/§3.6）：列表新增一行、来源 Badge「本地」；该事项不出现在任何项目的计划 Tab（projectId null 仅任务 Tab 可见）；弹窗不渲染自定义字段区（无项目上下文）。
- **Commit 区域**：7752a66（TasksPane 新建本地任务）、827d420（弹窗 projectId=null 分支）。

### 12. 任务列表来源标识（本地/项目名）

- **操作步骤**：任务 Tab 浏览混合本地任务与多个项目计划事项的聚合列表。
- **预期结果**（spec §3.5）：来源 Badge——本地行「本地」、项目行显示所属项目名（secondary）；行含状态徽标（四态着色）、优先级色点（P0 红/P1 主题/P2 灰）、相对时间；顶部灰字私密提示文案（PRD 原文）。
- **Commit 区域**：7752a66（来源 Badge + 项目名映射）。

### 13. assigned/created/来源筛选 + 搜索

- **操作步骤**：依次切换范围下拉（全部任务/指派给我的/我创建的）、来源下拉（全部来源/仅本地/仅项目）、搜索框输入标题片段。
- **预期结果**（spec §3.5/§2）：「我创建的」显示全部（UI 创建的事项 createdById 恒当前用户）；「指派给我的」按 assigneeId===me 谓词过滤——本期 UI 不落 assigneeId（处理人只读「我」为展示值、字段按 spec §2 预留），故单成员下切到该档恒为空态（裁定见附录 A9）；仅本地/仅项目切分正确；搜索包含过滤、清空恢复；无匹配显示空态引导（与真空态同节点，裁定见附录 A7）。
- **Commit 区域**：7752a66（三组筛选 + 搜索）。

### 14. 项目任务点击跳转项目计划 Tab

- **操作步骤**：点击一个项目来源的任务行。
- **预期结果**（spec §3.5）：跳转 `/module/project/<id>?tab=plan` 进入该项目计划 Tab 表格视图。
- **Commit 区域**：7752a66（行点击 navigate）。

### 15. 本地任务行点击编辑

- **操作步骤**：点击一个本地任务行。
- **预期结果**（spec §3.5/§3.6）：打开编辑弹窗（仅基础字段、无自定义字段区）回填该行内容，保存后列表与计划侧缓存同步。
- **Commit 区域**：7752a66（本地行 → 弹窗编辑）、827d420（编辑回填）。

## 三、系统级

### 16. 删除项目 → 计划事项清空、本地任务保留

- **操作步骤**：建临时项目 A 并加 2–3 条计划事项，同时确认存在本地任务；从 Hub 删除 A（二次确认）后进任一项目任务 Tab。
- **预期结果**（spec §3.1/§4）：A 的全部 planItem 随项目级联删除（计划 Tab 随项目消失不可达），本地任务（projectId null）不受影响全部保留。
- **Commit 区域**：f9eaa70（remove 级联 deleteMany）。

### 17. 删除项目后任务 Tab 缓存刷新无孤儿行

- **操作步骤**：删除项目 A 后（不重启应用）进入另一项目的任务 Tab，观察是否有 A 的任务行残留。
- **预期结果**（spec §3.5）：无 A 来源的孤儿行——项目删除只失效 `["projects"]`，`planItemsMine` 靠 TasksPane 挂载即重取（staleTime 0 + refetchOnMount）拿到新鲜 listMine（A 行已不在后端返回中）；A 的项目名映射同步消失，若有瞬态缓存窗口孤儿行来源 Badge 兜底显示通用「项目」文案不崩（附录 A8）。
- **Commit 区域**：7752a66（TasksPane 数据源 + 项目名映射）。

### 18. 中英文 / 主题回归

- **操作步骤**：计划表格/看板/事项弹窗/字段管理/任务 Tab 全界面切 en-US 语言，再切换 4 种主题（蓝/红/绿/橙）。
- **预期结果**（spec §5/§2）：`plan.*`/`tasks.*` 双语全量切换无硬编码中文（含空态/筛选/占位/校验文案）；优先级徽标与看板色条、头像点、hover 高亮均走主题语义色随主题联动。
- **Commit 区域**：eacc2f1（plan/tasks i18n 双语）、827d420/8c7a568/962e5fd/7752a66（各界面消费）。

## 附录：已知边界与裁定（走查确认，非 bug）

### A1. 均值序号碰撞——看板相邻下移一格可能视觉 no-op

- **操作步骤**：列内 sortOrder 相邻整数（如 1、2）时拖首卡下移一格（落到次卡上）。
- **预期结果**（已知裁定，T7 ruling）：插入均值 `floor((1+2)/2)=1` 与前项同值，展示按 id 兜底排序保持原序——视觉不动但落库无错、顺序确定性保持；move 通道为单条 sortOrder 无全列重编号，此为均值方案固有边界（如需精确插入需后续批量重编号通道）。
- **Commit 区域**：962e5fd。

### A2. 键盘不可拖拽（无 KeyboardSensor）

- **操作步骤**：Tab 聚焦看板卡片尝试纯键盘拖拽。
- **预期结果**（已知裁定，T7 实现选型）：仅 PointerSensor——键盘/辅助技术无法完成拖拽（点击开编辑仍可达）；补 KeyboardSensor 为后续增强项。
- **Commit 区域**：962e5fd。

### A3. 自定义字段值清理失败后重试 save 不再清

- **操作步骤**：制造单行清理失败（如手工锁库），收到「清理字段值失败 N 条」toast 后重试保存同字段集。
- **预期结果**（已知裁定，T3 Concern 1）：字段定义已替换完成，重试 save 无法再重算「消失名」——孤儿值需同名字段再建再删一轮才清掉；孤儿值在当前字段定义下不可见（表格/弹窗均不渲染），无功能影响。
- **Commit 区域**：f1802c1。

### A4. 行内自定义字段编辑降范围——编辑走弹窗

- **操作步骤**：表格自定义字段列尝试行内编辑。
- **预期结果**（已知裁定，T6 实现范围）：自定义列只读展示（缺值 `--`），值编辑统一走事项弹窗动态区（spec §3.6）；行内仅状态/优先级可编辑。
- **Commit 区域**：8c7a568、827d420。

### A5. 成功移动无 toast

- **操作步骤**：行内改状态/优先级、看板拖拽成功后观察。
- **预期结果**（已知裁定，T6 Concern 4）：成功不弹 toast——行内/拖拽即时视觉反馈即口径，避免噪音；仅失败 toast + 回滚。create/remove/保存仍有 toast。
- **Commit 区域**：8c7a568、962e5fd。

### A6. 计划表格筛选无匹配无专门提示

- **操作步骤**：构造筛选组合使计划表格零匹配。
- **预期结果**（已知裁定，T6 Concern 2）：保留表头与快速新增行、无数据行，未加 noMatch 专门文案（plan 命名空间无现成 key，避免为一行文案扩 key）；任务 Tab 无匹配则显示空态引导节点。
- **Commit 区域**：8c7a568。

### A7. 任务 Tab 无匹配与真空态同节点

- **操作步骤**：任务 Tab 筛选/搜索至零匹配。
- **预期结果**（已知裁定，T8 Concern）：显示 `tasks.empty` 空态引导（与真无任务同节点），轻量面板的可辩护简化。
- **Commit 区域**：7752a66。

### A8. 任务行 click 为 div onClick 无键盘焦点

- **操作步骤**：Tab 键尝试聚焦任务行。
- **预期结果**（已知裁定，T8 Concern，一期既有模式）：行点击走 div onClick 无键盘可达性（与 ProjectCard 同型既有 a11y 缺口，非本期引入范围）。
- **Commit 区域**：7752a66（沿用 ProjectCard 先例）。

### A9. 「指派给我的」档位（assigneeId 已随创建落库——曾为缺陷，已修复）

- **操作步骤**：任务 Tab 范围切到「指派给我的」。
- **预期结果**（修复后，spec §2 单成员语义）：创建事项（弹窗/快速新增）即指派给自己——`assigneeId = 创建人` 落库，「指派给我的」正常显示全部 UI 建立的事项（与「我创建的」等价，多成员协作落地前两者同集，非 bug）。
- **Commit 区域**：ddcdee9（创建路径落库修复）、7752a66（matchesScope 谓词）。
