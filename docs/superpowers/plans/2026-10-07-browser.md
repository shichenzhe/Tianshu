# 内置浏览器实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 参照 WorkBuddy browser-preview，为天枢提供应用内多标签浏览器（`/module/ai/browser`）。

**Architecture:** 前后端 DDD 域 `browser`：主进程对 `persist:browser-webview` partition 装两道 webRequest 门（NetworkGate blocklist + SSRF 封锁；剥 XFO/CSP frame-ancestors）+ 一个清数据 IPC；渲染层 Zustand 管 tab 状态，每 tab 常驻一个 `<webview>`（sandbox、禁弹窗、不拦导航）。

**Tech Stack:** Electron 44 webview、Zustand、React Query 不涉及、Vitest、react-i18next。

**Spec:** `docs/superpowers/specs/2026-10-07-browser-design.md`（先读 spec 再动手）

## Global Constraints

- 文案禁止硬编码，走 `t()`（i18n key 见 Task 5，zh-CN/en-US 同步加）
- 颜色/边框用主题变量（`hover:bg-primary-subtle`、`border-border/50` 等），禁止 `bg-blue-*` 等硬编码色
- Prettier：双引号、分号、tabWidth=2、printWidth=80、无尾随逗号
- webview 禁写 `allowpopups`（Electron 按属性存在性取值，不写即拒弹窗）
- 测试命令：`npx vitest run <file>`；全量 `npm run test`；类型 `npm run typecheck`
- commit 信息中文、conventional 前缀（照 `git log` 先例）
- **与 spec 的一个实现偏差**（spec §3.2）：`BrowserTab.input` 字段不进 store，地址栏编辑态放 `BrowserToolbar` 本地 state（编辑中的输入不被页面重定向打断，仅 url 真变化时回显）
- webview 事件（`did-navigate` 等）React 合成事件不支持，必须原生 `addEventListener`（照 `FilePreview.tsx:70-89` 先例）
- `did-fail-load` 的 `errorCode === -3`（ERR_ABORTED）不算失败；`-20`（ERR_BLOCKED_BY_CLIENT，主进程 webRequest cancel）为「安全策略拦截」文案（照 `FilePreview.tsx:77-81` 先例）

```typescript
// src-react/domains/ai/browser/lib/url-input.ts
/**
 * 地址栏 / 新标签页共用的输入解析（复刻 WorkBuddy new-tab-input 判定）：
 * 含空白→搜索词形态（false）；显式协议头 / localhost / 127.0.0.1 / 形如
 * a.b（含点且点后有内容）→ 网址（true）。搜索兜底刻意不做（spec 假设 2），
 * 非网址由调用方提示「仅支持直接访问网址」。
 */

/** 判定输入是否更像「网址」而非「搜索词」 */
export function looksLikeUrl(input: string): boolean {
  const trimmed = input.trim();
  if (!trimmed || /\s/.test(trimmed)) return false;
  if (/^[a-zA-Z][a-zA-Z\d+\-.]*:\/\//.test(trimmed)) return true;
  if (/^(localhost|127\.0\.0\.1)(:\d+)?(\/|$)/i.test(trimmed)) return true;
  return /^[^\s]+\.[^\s]{2,}/.test(trimmed);
}

/** 网址补 https:// 前缀返回；非网址/空输入返回 null（调用方提示） */
export function resolveAddressInput(input: string): string | null {
  const trimmed = input.trim();
  if (!trimmed || !looksLikeUrl(trimmed)) return null;
  if (/^[a-zA-Z][a-zA-Z\d+\-.]*:\/\//.test(trimmed)) return trimmed;
  return `https://${trimmed}`;
}
```

```typescript
// electron/domains/ai/browser/browser-session.ts
/**
 * 内置浏览器 session 守卫（spec §2）：persist:browser-webview partition 的
 * 请求门（NetworkGate blocklist + SSRF 封锁）与响应头剥离（X-Frame-Options
 * / CSP frame-ancestors——不剥则 GitHub 等设 XFO 的站点无法嵌入 webview）。
 * 纯函数 + 薄壳注册（electron mock 可测，照 renderer-guard.ts 先例）。
 */

/** 浏览器 webview 专用持久 partition（登录态跨重启，spec §3.3） */
export const BROWSER_WEBVIEW_PARTITION = "persist:browser-webview";

/** 云 metadata 主机（SSRF 封锁清单，对齐 WorkBuddy） */
const SSRF_HOSTS = new Set([
  "169.254.169.254",
  "metadata.google.internal",
  "metadata.azure.com",
]);

export function isSsrfHost(hostname: string): boolean {
  return SSRF_HOSTS.has(hostname.toLowerCase());
}

/** mainFrame/subFrame 剥 XFO 与 CSP frame-ancestors；其余资源原样放行 */
export function sanitizeEmbedHeaders(
  resourceType: string,
  responseHeaders: Record<string, string[]>,
): Record<string, string[]> {
  if (resourceType !== "mainFrame" && resourceType !== "subFrame") {
    return responseHeaders;
  }
  const cleaned: Record<string, string[]> = {};
  for (const key of Object.keys(responseHeaders)) {
    const lower = key.toLowerCase();
    if (lower === "x-frame-options") continue;
    if (
      lower === "content-security-policy" ||
      lower === "content-security-policy-report-only"
    ) {
      const values = responseHeaders[key];
      if (!values || values.length === 0) continue;
      const stripped = values
        .map((v) =>
          v
            .split(";")
            .map((part) => part.trim())
            .filter((part) => !/^frame-ancestors\b/i.test(part))
            .join("; "),
        )
        .filter((v) => v.length > 0);
      if (stripped.length > 0) cleaned[key] = stripped;
      continue;
    }
    cleaned[key] = responseHeaders[key];
  }
  return cleaned;
}

/** 清数据类型归一（fail-fast：非法类型抛错而非静默猜默认） */
export function readClearDataType(value: unknown): "cookies" | "cache" {
  if (value !== "cookies" && value !== "cache") {
    throw new Error(
      `browser data type must be 'cookies' or 'cache', got: ${String(value)}`,
    );
  }
  return value;
}

/** cache 类型清除的站点存储（cookies 归 cookies 类型单独清） */
export const CACHE_CLEAR_STORAGES = [
  "localstorage",
  "indexdb",
  "serviceworkers",
  "cachestorage",
  "shadercache",
  "websql",
  "filesystem",
];
```

```typescript
import { session } from "electron";
import { handleUser } from "../../../commons/ipc-user";
import { getNetworkGate } from "../../security/network-gate";

/** 装配 browser partition 两道门（Application 启动调一次） */
export function installBrowserSessionGuard(): void {
  const target = session.fromPartition(BROWSER_WEBVIEW_PARTITION);
  target.webRequest.onBeforeRequest(
    { urls: ["http://*/*", "https://*/*"] },
    (details, callback) => {
      try {
        if (isSsrfHost(new URL(details.url).hostname)) {
          callback({ cancel: true });
          return;
        }
      } catch {
        // 非法 URL 不在此拦，交给加载失败路径
      }
      const gate = getNetworkGate();
      const verdict = gate ? gate.judgeUrl(details.url) : { ok: true as const };
      if (!verdict.ok) {
        gate?.blockedAudit(verdict.host, verdict.rule, "browser");
        callback({ cancel: true });
        return;
      }
      callback({});
    },
  );
  target.webRequest.onHeadersReceived((details, callback) => {
    callback({
      responseHeaders: sanitizeEmbedHeaders(
        details.resourceType,
        details.responseHeaders ?? {},
      ),
    });
  });
}

/** browser:clearData（handleUser：剥 token，userId 无业务语义仅过鉴权） */
export function registerBrowserIpc(): void {
  handleUser("browser:clearData", async (_event, _userId, type: unknown) => {
    const dataType = readClearDataType(type);
    const target = session.fromPartition(BROWSER_WEBVIEW_PARTITION);
    if (dataType === "cookies") {
      await target.clearStorageData({ storages: ["cookies"] });
      return;
    }
    await target.clearStorageData({ storages: CACHE_CLEAR_STORAGES });
    await target.clearCache();
  });
}
```

```typescript
// src-react/domains/ai/browser/store/browser.store.ts
/**
 * 浏览器 tab 状态（内存态，spec 假设 1：重启回新标签页；登录态由
 * persist partition 保留）。url 为空串即新标签页形态。
 */
import { create } from "zustand";

export interface BrowserTab {
  id: string;
  /** 当前地址（did-navigate 同步）；空串 = 新标签页 */
  url: string;
  /** page-title-updated 同步；空串时 UI 以 url hostname 兜底 */
  title: string;
  /** page-favicon-updated 同步（dataUrl 或 http url） */
  favicon: string;
  canGoBack: boolean;
  canGoForward: boolean;
  isLoading: boolean;
}

function newTab(): BrowserTab {
  return {
    id: crypto.randomUUID(),
    url: "",
    title: "",
    favicon: "",
    canGoBack: false,
    canGoForward: false,
    isLoading: false,
  };
}

interface BrowserState {
  tabs: BrowserTab[];
  activeTabId: string;
  /** 新建 tab 并激活；返回新 tab id */
  addTab: () => string;
  /** 关 tab；关 active 时切相邻，关最后一个时重置为新标签页 */
  closeTab: (id: string) => void;
  setActive: (id: string) => void;
  /** webview 事件回写（url/title/favicon/导航可用性/加载态） */
  syncTab: (id: string, partial: Partial<BrowserTab>) => void;
}

export const useBrowserStore = create<BrowserState>((set) => ({
  tabs: [],
  activeTabId: "",
  addTab: () => {
    const tab = newTab();
    set((s) => ({ tabs: [...s.tabs, tab], activeTabId: tab.id }));
    return tab.id;
  },
  closeTab: (id) =>
    set((s) => {
      const idx = s.tabs.findIndex((t) => t.id === id);
      if (idx === -1) return s;
      const tabs = s.tabs.filter((t) => t.id !== id);
      if (tabs.length === 0) {
        const fresh = newTab();
        return { tabs: [fresh], activeTabId: fresh.id };
      }
      const activeTabId =
        s.activeTabId === id
          ? (tabs[Math.min(idx, tabs.length - 1)]?.id ?? tabs[0].id)
          : s.activeTabId;
      return { tabs, activeTabId };
    }),
  setActive: (id) => set({ activeTabId: id }),
  syncTab: (id, partial) =>
    set((s) => ({
      tabs: s.tabs.map((t) => (t.id === id ? { ...t, ...partial } : t)),
    })),
}));
```

- [ ] **Step 3: BrowserWebview（事件同步 + 态路由）**

```tsx
/**
 * 单 tab 内容区：url 空 → NewTabPage；有 url → <webview>（spec §3.3/3.4）。
 * 事件原生 addEventListener（React 合成事件不支持 webview 事件，照
 * FilePreview.tsx 先例）；webview 常驻不随 active 切换卸载（display 隐藏，
 * 保滚动/表单状态，spec §4.2）。
 */
import { useEffect, useRef, useState } from "react";
import { useTranslation } from "react-i18next";
import { RotateCw, ShieldAlert, TriangleAlert } from "lucide-react";
import { toast } from "sonner";
import type { BrowserTab } from "../store/browser.store";
import { classifyLoadError, webviewApi } from "../lib/webview-api";
import NewTabPage from "./NewTabPage";

interface BrowserWebviewProps {
  tab: BrowserTab;
  isActive: boolean;
  registerRef: (id: string, node: HTMLElement | null) => void;
  onSync: (partial: Partial<BrowserTab>) => void;
}

export default function BrowserWebview({
  tab,
  isActive,
  registerRef,
  onSync,
}: BrowserWebviewProps) {
  const { t } = useTranslation(["chat"]);
  const webviewRef = useRef<HTMLElement>(null);
  // "blocked"（主进程门拦截）/ "failed"（普通失败）分文案；导航成功即清除
  const [errorKind, setErrorKind] = useState<"blocked" | "failed" | null>(null);

  useEffect(() => {
    setErrorKind(null);
    const node = webviewRef.current;
    registerRef(tab.id, node);
    if (!node) {
      return;
    }
    const api = webviewApi(node);
    const onDidNavigate = (event: Event) => {
      const e = event as { url?: string; canGoBack?: boolean; canGoForward?: boolean };
      setErrorKind(null);
      onSync({
        url: typeof e.url === "string" ? e.url : tab.url,
        canGoBack: e.canGoBack === true,
        canGoForward: e.canGoForward === true,
      });
    };
    const onTitle = (event: Event) => {
      const title = (event as { title?: string }).title;
      if (typeof title === "string" && title.trim()) onSync({ title });
    };
    const onFavicon = (event: Event) => {
      const favicons = (event as { favicons?: string[] }).favicons;
      const first = Array.isArray(favicons) ? favicons[0] : "";
      if (typeof first === "string" && first) onSync({ favicon: first });
    };
    const onStartLoading = () => onSync({ isLoading: true });
    const onStopLoading = () => onSync({ isLoading: false });
    const onFail = (event: Event) => {
      const kind = classifyLoadError((event as { errorCode?: number }).errorCode ?? 0);
      if (kind !== "ignored") setErrorKind(kind);
    };
    node.addEventListener("did-navigate", onDidNavigate);
    node.addEventListener("did-navigate-in-page", onDidNavigate);
    node.addEventListener("page-title-updated", onTitle);
    node.addEventListener("page-favicon-updated", onFavicon);
    node.addEventListener("did-start-loading", onStartLoading);
    node.addEventListener("did-stop-loading", onStopLoading);
    node.addEventListener("did-fail-load", onFail);
    return () => {
      node.removeEventListener("did-navigate", onDidNavigate);
      node.removeEventListener("did-navigate-in-page", onDidNavigate);
      node.removeEventListener("page-title-updated", onTitle);
      node.removeEventListener("page-favicon-updated", onFavicon);
      node.removeEventListener("did-start-loading", onStartLoading);
      node.removeEventListener("did-stop-loading", onStopLoading);
      node.removeEventListener("did-fail-load", onFail);
    };
    // tab.id 变化 = webview 重挂（tab 新建/销毁），重绑事件
  }, [tab.id, tab.url]);

  if (tab.url === "") {
    return (
      <NewTabPage
        onSubmit={(url) => {
          onSync({ url });
        }}
      />
    );
  }

  return (
    <div
      className="relative h-full min-h-0"
      style={{ display: isActive ? "block" : "none" }}
    >
      {errorKind && (
        <div className="absolute inset-0 z-10 flex flex-col items-center justify-center gap-3 bg-background text-muted-foreground">
          {errorKind === "blocked" ? (
            <ShieldAlert className="h-8 w-8" />
          ) : (
            <TriangleAlert className="h-8 w-8" />
          )}
          <p className="text-xs">
            {errorKind === "blocked"
              ? t("chat:browser.blockedByPolicy")
              : t("chat:browser.loadFailed")}
          </p>
          <p className="max-w-[80%] truncate text-xs opacity-70">{tab.url}</p>
          <button
            type="button"
            onClick={() => {
              setErrorKind(null);
              webviewApi(webviewRef.current)?.reload();
            }}
            className="inline-flex items-center gap-1 rounded-md border border-border/50 px-2 py-1 text-xs hover:bg-primary-subtle hover:text-primary hover:border-primary/30"
          >
            <RotateCw className="h-3.5 w-3.5" />
            {t("chat:browser.retry")}
          </button>
        </div>
      )}
      {/* allowpopups 刻意不写（拒弹窗）；will-navigate 不拦（导航是本职） */}
      <webview
        ref={webviewRef}
        src={tab.url}
        partition="persist:browser-webview"
        webpreferences="contextIsolation=yes,sandbox=yes"
        className="h-full min-h-0 w-full"
      />
    </div>
  );
}
```

```tsx
/**
 * 导航工具栏：返回/前进/刷新（webview DOM 命令）+ 地址栏 + 清数据菜单。
 * 地址栏编辑态是组件本地 state（Global Constraints 的 spec 偏差：编辑输入
 * 不被页面重定向打断，仅 url 变化时经 useEffect 回显）。
 */
import { useEffect, useRef, useState } from "react";
import { useTranslation } from "react-i18next";
import { toast } from "sonner";
import {
  ArrowLeft,
  ArrowRight,
  ChevronDown,
  RotateCw,
  Trash2,
} from "lucide-react";
import { invoke } from "@/lib/ipc";
import { mapIpcError } from "@/domains/ai/chat/lib/error-message";
import type { BrowserTab } from "../store/browser.store";
import { resolveAddressInput } from "../lib/url-input";
import { webviewApi } from "../lib/webview-api";

interface BrowserToolbarProps {
  tab: BrowserTab;
  webviewNode: HTMLElement | null;
}

export default function BrowserToolbar({ tab, webviewNode }: BrowserToolbarProps) {
  const { t } = useTranslation(["chat"]);
  const [input, setInput] = useState(tab.url);
  const [menuOpen, setMenuOpen] = useState(false);
  const inputRef = useRef<HTMLInputElement>(null);

  // url 真变化时回显（重定向/页内导航）；本地编辑中不覆盖
  useEffect(() => {
    if (document.activeElement !== inputRef.current) setInput(tab.url);
  }, [tab.url]);

  const submit = () => {
    const url = resolveAddressInput(input);
    if (url === null) {
      toast.error(t("chat:browser.notUrlHint"));
      return;
    }
    if (url !== tab.url) {
      inputRef.current?.blur();
      // 经 store 驱动：NewTabPage 形态挂 webview，已挂 webview 变更 src 导航
      useBrowserStore.getState().syncTab(tab.id, { url });
    } else {
      webviewApi(webviewNode)?.reload();
    }
  };

  const clearData = (type: "cookies" | "cache") => {
    setMenuOpen(false);
    invoke("browser:clearData", type)
      .then(() => toast.success(t("chat:browser.clearSuccess")))
      .catch((e) => toast.error(mapIpcError(e)));
  };

  const navBtn =
    "rounded p-1 text-muted-foreground hover:bg-primary-subtle hover:text-primary disabled:opacity-40 disabled:hover:bg-transparent disabled:hover:text-muted-foreground";

  return (
    <div className="flex items-center gap-1 border-b border-border/50 px-2 py-1.5">
      <button
        type="button"
        className={navBtn}
        aria-label={t("chat:browser.back")}
        title={t("chat:browser.back")}
        disabled={!tab.canGoBack}
        onClick={() => webviewApi(webviewNode)?.goBack()}
      >
        <ArrowLeft className="h-4 w-4" />
      </button>
      <button
        type="button"
        className={navBtn}
        aria-label={t("chat:browser.forward")}
        title={t("chat:browser.forward")}
        disabled={!tab.canGoForward}
        onClick={() => webviewApi(webviewNode)?.goForward()}
      >
        <ArrowRight className="h-4 w-4" />
      </button>
      <button
        type="button"
        className={navBtn}
        aria-label={t("chat:browser.reload")}
        title={t("chat:browser.reload")}
        onClick={() => webviewApi(webviewNode)?.reload()}
      >
        <RotateCw className="h-4 w-4" />
      </button>
      <input
        ref={inputRef}
        value={input}
        onChange={(e) => setInput(e.target.value)}
        onKeyDown={(e) => {
          if (e.key === "Enter") submit();
        }}
        onBlur={() => setInput(tab.url)}
        placeholder={t("chat:browser.addressPlaceholder")}
        spellCheck={false}
        className="h-7 min-w-0 flex-1 rounded-md border border-border/50 bg-background px-2 text-xs outline-none focus:border-primary/30"
      />
      <div className="relative">
        <button
          type="button"
          className={navBtn}
          aria-label={t("chat:browser.clearCache")}
          title={t("chat:browser.clearCache")}
          onClick={() => setMenuOpen((v) => !v)}
        >
          <ChevronDown className="h-4 w-4" />
        </button>
        {menuOpen && (
          <>
            <div
              className="fixed inset-0 z-10"
              onClick={() => setMenuOpen(false)}
            />
            <div className="absolute right-0 top-full z-20 mt-1 w-56 rounded-lg border border-border/50 bg-background p-1 shadow-lg">
              <p className="px-2 py-1 text-[10px] text-muted-foreground">
                {t("chat:browser.clearedNote")}
              </p>
              <button
                type="button"
                className="flex w-full items-center gap-2 rounded-md px-2 py-1.5 text-xs hover:bg-primary-subtle hover:text-primary"
                onClick={() => clearData("cookies")}
              >
                <Trash2 className="h-3.5 w-3.5" />
                {t("chat:browser.clearCookies")}
              </button>
              <button
                type="button"
                className="flex w-full items-center gap-2 rounded-md px-2 py-1.5 text-xs hover:bg-primary-subtle hover:text-primary"
                onClick={() => clearData("cache")}
              >
                <Trash2 className="h-3.5 w-3.5" />
                {t("chat:browser.clearCache")}
              </button>
            </div>
          </>
        )}
      </div>
    </div>
  );
}
```

```tsx
/**
 * 内置浏览器主视图：tab 条 + 内容区（每 tab 常驻 webview）+ 导航工具栏
 *（spec §1）。webview ref map 供 toolbar 下发 DOM 导航命令。
 */
import { useCallback, useEffect, useRef } from "react";
import { useTranslation } from "react-i18next";
import { useBrowserStore } from "../store/browser.store";
import BrowserTabBar from "../components/BrowserTabBar";
import BrowserToolbar from "../components/BrowserToolbar";
import BrowserWebview from "../components/BrowserWebview";

function BrowserView() {
  const { t } = useTranslation(["chat"]);
  const tabs = useBrowserStore((s) => s.tabs);
  const activeTabId = useBrowserStore((s) => s.activeTabId);
  const addTab = useBrowserStore((s) => s.addTab);
  const syncTab = useBrowserStore((s) => s.syncTab);
  const webviewRefs = useRef<Map<string, HTMLElement>>(new Map());

  useEffect(() => {
    if (tabs.length === 0) addTab();
  }, [tabs.length, addTab]);

  const registerRef = useCallback((id: string, node: HTMLElement | null) => {
    if (node) webviewRefs.current.set(id, node);
    else webviewRefs.current.delete(id);
  }, []);

  const activeTab = tabs.find((t) => t.id === activeTabId);

  return (
    <div className="flex h-full min-h-0 flex-col" aria-label={t("chat:sidebar.browser")}>
      <BrowserTabBar />
      <div className="min-h-0 flex-1">
        {tabs.map((tab) => (
          <BrowserWebview
            key={tab.id}
            tab={tab}
            isActive={tab.id === activeTabId}
            registerRef={registerRef}
            onSync={(partial) => syncTab(tab.id, partial)}
          />
        ))}
      </div>
      {activeTab && (
        <BrowserToolbar
          tab={activeTab}
          webviewNode={webviewRefs.current.get(activeTabId) ?? null}
        />
      )}
    </div>
  );
}

export default BrowserView;
```

布局说明：工具栏在内容区下方（tab 条 → 内容 → 工具栏）。若走查时更顺手，把 `<BrowserToolbar>` 移到内容区上方（tab 条 → 工具栏 → 内容）只需移动一个 JSX 块——本计划按「上方」为最终形态：**把 `{activeTab && <BrowserToolbar …/>}` 移到 `<div className="min-h-0 flex-1">` 之前**（WorkBuddy 工具栏在内容上方，对齐）。
