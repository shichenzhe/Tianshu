## 1. 认识天枢

### 1.1 天枢是什么

天枢是一个**本地优先的 AI 桌面工作台**——把 AI 对话、AI 助手管理、自动化任务、资料管理、项目协作等能力装进一个桌面应用（Windows / macOS）。

「本地优先」的意思是：**你的所有数据（账号、对话记录、资料、配置）都保存在你自己电脑的数据库里，不依赖云端账号**。你接入哪家的 AI 模型、密钥填什么，只有你自己的电脑知道。

天枢本身**不自带 AI 大脑**。它是一个「驾驶舱」：你把各家 AI 服务商的密钥配置进来（第 6 章教你怎么配），它就能用这些模型替你干活——聊天、写文档、改代码、定时执行任务、操作文件等等。

### 1.2 天枢能为你做什么

| 你想做的事 | 对应功能 | 见章节 |
| --- | --- | --- |
| 和 AI 聊天、问问题、写文案 | 新建任务 / 对话 | 第 7、8 章 |
| 让 AI 读写你电脑上某个文件夹里的文件、帮你改代码 | 工作空间 + 文件工具 | 第 4、8 章 |
| 让 AI 执行命令行命令（装软件、跑脚本） | 终端工具（带安全审批） | 第 8、9 章 |
| 定时让 AI 干活（每天早上生成早报） | 自动化（定时任务） | 第 14 章 |
| 搭一条「取数 → 处理 → 发邮件」的自动流水线 | 工作流（流程编排） | 第 13 章 |
| 收集管理你自己的资料，让 AI 基于这些资料回答 | 资料库 | 第 11 章 |
| 给 AI 挂上外部能力（查股票、读邮件、操作网盘） | MCP 连接器 | 第 10 章 |
| 让 AI 越用越懂你（记住你的偏好和背景） | 记忆与进化 | 第 16 章 |
| 管理项目、任务、计划（看板/甘特/日历） | 项目与计划 | 第 18 章 |
| 在内置浏览器里查资料、模拟手机看页面 | 内置浏览器 | 第 12 章 |
| 看看 AI 帮我省/花了多少 token | 监控 | 第 15 章 |
| 出门在外用手机遥控家里的电脑继续干活 | 主机 + 移动端 | 第 20、21 章 |

### 1.3 一句话理解整体结构

打开天枢后，你大部分时间会停留在这个界面布局上：

```
┌──────────────────────────────────────────────────┐
│  顶栏（折叠侧栏 / 搜索 / 主机切换器 / 页面标题）        │
├──────────┬───────────────────────────────────────┤
│          │                                       │
│  侧边栏    │              主内容区                  │
│  功能入口  │   （新建任务 / 对话 / 资料库 / …）        │
│  任务列表  │                                       │
│  用户菜单  │                                       │
└──────────┴───────────────────────────────────────┘
```

侧边栏上半部分是**功能入口**（新建任务、项目、专家·技能·连接器……），中间是你的**任务/会话列表**，底部是你的**用户菜单**（改密码、设置、退出登录都在这里）。

## 2. 安装与首次启动

### 2.1 两种使用方式

| 方式 | 适合谁 | 说明 |
| --- | --- | --- |
| **安装包**（推荐普通用户） | 只想使用天枢的人 | 拿到 `.dmg`（macOS）或 `.exe`（Windows）安装包，双击安装即可 |
| **源码运行** | 想参与开发 / 改造天枢的人 | 需要 Node.js ≥ 22.12 环境，从仓库源码启动 |

### 2.2 用安装包安装

1. 拿到对应你电脑系统的安装包（macOS 为 `.dmg`，Windows 为 `.exe`）。
2. macOS：双击 `.dmg`，把「天枢」拖入「应用程序」文件夹，之后从启动台打开。
   Windows：双击 `.exe` 按提示完成安装。
3. 首次打开如果系统提示「来自身份不明的开发者」：
   - macOS：在「系统设置 → 隐私与安全性」里点「仍要打开」。
   - Windows：SmartScreen 提示时点「更多信息 → 仍要运行」。

> 💡 天枢支持**自动更新**：配置了更新源时，应用启动后会自动检查新版本，弹出「发现新版本，是否立即下载？」的提示，你也可以在 用户菜单 → 帮助 → 检查更新 手动检查。

### 2.3 从源码运行（开发者）

```bash
npm i -g node-gyp   # 前置：全局安装 node-gyp（编译本地依赖需要）
npm install         # 安装依赖（首次会比较久）
npm run dev         # 启动开发调试
```

首次启动会自动在本地创建 SQLite 数据库并完成建表，**无需手动安装数据库**。

> 💡 如果安装依赖报原生模块相关错误，运行 `npm run setup:native` 一键修复（会自动装齐 Electron 所需的二进制）。

### 2.4 首次启动会发生什么

- 应用窗口标题为「天枢」，首次启动因为没有账号，会停在**登录页**（见第 3 章）。
- 你的全部数据会存放在用户主目录下的 `~/.tianshu` 文件夹（Windows 为 `C:\Users\<你的用户名>\.tianshu`），开发模式与正式安装的数据互相隔离。想换位置？见 [17.3 存储页](#173-存储页数据目录与备份)。
- 天枢**同时只能开一个主窗口**（单实例），重复打开会聚焦到已有窗口。

## 3. 注册与登录

### 3.1 注册第一个账号

天枢的账号**存在你自己的电脑上**，不需要手机号、也不联网注册：

1. 在登录页点「**没有账号？立即注册**」。
2. 在弹出的「用户注册」对话框中填写：
   - **用户名**（必填）：登录用的名字；
   - **昵称（选填）**：展示用的名字；
   - **邮箱**（必填）：格式需要合法（含 `@`），但不会用来发验证邮件；
   - **密码**（必填）。
3. 点「注册」。成功后提示「**注册成功，请登录**」，用户名和密码会自动回填到登录表单。
4. 点「登录」进入应用。

> 💡 天枢支持**多账号**：一家人或一台电脑的多个使用者可以各注册各的账号，数据互相隔离、互不可见。切换账号的方法：用户菜单 → 退出登录 → 用另一个账号登录。
>
> ⚠️ 天枢的本地认证适用于「防止路人直接打开应用」的场景；密码在本地数据库中为明文存储，介意者请参阅仓库 README 的安全说明章节。

### 3.2 登录

- 输入用户名、密码，点「登录」或直接按回车。
- 勾选「**记住我（30天）**」后，登录状态保持 30 天（不勾选则关闭应用后需要重新登录）。它**不会保存你的密码**，只是延长登录有效期。
- 上次登录的用户名会自动回填。
- 登录成功后自动进入「**新建任务**」页。下次打开应用时，如果登录还在有效期内，会跳过登录页直达这里。

### 3.3 忘了密码怎么办

本地账号没有「找回密码」功能（没有联网邮箱验证）。如果是开发者自用场景，最直接的办法是注册一个新账号使用；原有账号的数据仍留在数据库中。

### 3.4 修改用户信息与密码

登录后，点侧边栏底部的**用户菜单**（你的用户名处）：

- **用户信息**：修改用户名、昵称、邮箱；
- **修改密码**：依次填「当前密码 / 新密码 / 确认新密码」（两次输入需一致）；
- **退出登录**：确认后回到登录页。

## 4. 先搞懂 7 个核心概念

第一次用天枢，下面几个词会反复出现。用日常比喻先混个脸熟，后面每个功能章节还有详细说明。

### ① 服务商（Provider）——AI 大脑的供应商

天枢自己不会思考，它替你调用外部 AI 服务。提供 AI 模型的公司（DeepSeek、OpenAI、Anthropic、Google，或你自己用 Ollama 部署的本地模型）就是「服务商」。你需要：**注册一家服务商 → 拿到 API Key（一串通行密钥）→ 填进天枢**。详见第 6 章。

### ② 模型（Model）——具体干活的那个「脑子」

一家服务商旗下通常有多个模型（擅长聊天的、擅长写代码的、便宜的、贵的……）。配置好服务商后，把要用的模型添加进来，发消息时选一个即可。模型可以在对话中途随时换。

### ③ 工作空间（Workspace）——AI 的「工位」

一个工作空间就是**一个任务文件夹**：里面收纳多个相关的对话（任务），并且可以**绑定一个你电脑上的真实文件夹**。绑定之后：

- AI 获得文件工具，能读取/新建/修改该文件夹里的文件（路径被严格限制在文件夹内，出不去）；
- 你在输入框里可以用 `@` 直接引用文件夹里的文件；
- 自动化任务、工作流也挂在某个工作空间下执行。

> 💡 比喻：工作空间 = 一个项目档案柜；会话 = 档案柜里的一份讨论记录；绑定的目录 = 档案柜对应的真实抽屉。

### ④ 会话 / 任务（Session / Task）——一次对话

「任务」和「会话」在天枢里指同一个东西：你从「新建任务」页发起的一次对话及其全部往来记录。任务可以置顶、归档、重命名、删除。侧边栏中间的树就是你的任务列表（按工作空间分组）。

### ⑤ 专家（Expert / 助手）——预设好性格和技能的 AI 角色

「专家」是提前写好人设（系统提示词）、标签、推荐提问的 AI 角色，比如「产品设计师」「法律顾问」。还可以组建「专家团」（多个成员协作，主理人负责调度）。选择一位专家开始对话，它就会按这个角色来回答。详见第 10 章。

### ⑥ 技能（Skill）——教给 AI 的「操作手册」

技能是一个文件夹 + 一份 `SKILL.md` 说明书，告诉 AI 在某类任务下按什么流程、用什么规范来做（类似你给新同事的操作手册）。技能可以自己写、从市场装、或让 AI 在对话中直接帮你创建。详见第 10 章。

### ⑦ 连接器（MCP）——给 AI 接外部能力

MCP（Model Context Protocol）是一种通用外挂标准：装一个「连接器」，AI 就多一批工具——查行情、读邮件、操作网盘、搜法规……详见第 10 章。

> 💡 一句话串联：你在某个**工作空间**里开了一个**任务**，选了一位**专家**和它的**技能**，还挂了几个**连接器**，背后由某个**服务商**的某个**模型**驱动——这就是天枢的完整工作画面。

- **中段**：当前页面的标题、Tab 与操作按钮（每页不同）。
- **窗口按钮**：macOS 是左上角红绿灯；Windows 是右上角自绘的最小化/最大化/关闭。

> 💡 顶栏还有「筛选时间」按钮，可按全部时间/今天/最近 7 天/最近 30 天过滤侧栏任务列表。

## 6. 第一次对话前必做：配置 AI 服务商

> 没有可用模型时，新建任务页会提示「还没有可用的模型，先添加一个服务商」并给出「**去配置**」按钮，点它直接到本页。本章是新手第一关，请完整走一遍。

### 6.1 进入配置页

左侧边栏 → **专家·技能·连接器** 上方没有直接入口？模型配置在：**用户菜单 → 模型管理**，或直接在浏览器地址般的顶栏导航中进入「AI 服务商」页（`/module/ai/providers`）。页面标题为「模型管理」。

页面为左右布局：左侧是你的**服务商列表**，右侧是选中服务商的详情与模型列表。第一次进来是空的，显示「**暂无服务商**——添加第一个服务商后即可开始对话」。

### 6.2 添加服务商（以 DeepSeek 为例）

天枢支持四类协议的服务商（外加 ComfyUI 用于生图）：

| 协议类型 | 谁在用 | 接口地址长什么样 |
| --- | --- | --- |
| **OpenAI 兼容** | DeepSeek、通义千问、月之暗面、各类中转站……绝大多数国内服务商 | `https://api.deepseek.com/v1` |
| **Anthropic** | Anthropic 官方（Claude 系列） | `https://api.anthropic.com` |
| **Gemini** | Google（Gemini 系列） | `https://generativelanguage.googleapis.com/v1beta` |
| **Ollama** | 本地部署的开源模型 | `http://localhost:11434` |
| **ComfyUI** | 本地 ComfyUI 出图服务 | `http://127.0.0.1:8188` |

完整步骤：

1. 点「**添加服务商**」。
2. **从模板选择服务商**（「快速开始」下拉）：模板会自动填好名称、协议类型与接口地址，你只需要填 API Key——这是最快的方式。内置 9 个模板：**DeepSeek、Kimi（月之暗面）、通义千问（Qwen）、智谱 GLM、OpenAI、Anthropic Claude、Google Gemini、Ollama（本地）、ComfyUI（本地）**。没有你家的模板就手动选「协议类型」并照上表填「接口地址」。
3. **API Key**：去服务商官网注册账号并创建 API Key（通常在「API Keys / 密钥管理」页面），复制粘贴到这里。
   > ⚠️ API Key 等同于你在这家服务商的扣费凭证，不要发给任何人。
4. （可选）**自定义请求头（JSON）**：某些中转服务需要额外请求头时才填。
5. （可选）**默认上下文窗口（token）**：留空使用全局默认 128K。本地部署或中转服务实际窗口较小时建议按服务商文档填写，可避免超长内容报错。
6. 「启用」开关保持打开，保存。

### 6.3 添加模型

服务商添加好后还只是「通了电线」，需要再把要用的模型加进来：

**方式一：从服务商拉取（推荐）**

1. 在服务商详情里点「**从服务商拉取模型**」。
2. 天枢会列出该账号可用的全部模型（可搜索、全选），勾选你想要的，点「**导入所选**」。
3. 拉取成功本身就代表连接可用（**拉取即连通测试**）；失败会提示原因（比如「认证失败，请检查 API Key」）。
4. 模型类型会按名称自动预判（名字含 embed 的标为「向量」、含 rerank 的标为「重排序」、tts 为「语音合成」等，其余为「对话模型」），预判错了可编辑纠正。

**方式二：手动添加**

点「手动添加模型」，填写：

| 字段 | 说明 |
| --- | --- |
| **模型 ID** | 服务商的模型名，必须一字不差（如 `deepseek-chat`） |
| **显示名** | 你在界面上看到的昵称，随意起 |
| **模型类型** | 对话模型 / 向量 / 语音合成 / 重排序 / 语音识别（普通聊天选「对话模型」；向量等类型供工作流检索节点使用） |
| 温度 / Top P / 最大输出 Tokens | 高级参数，留空用默认即可 |
| 输入（上下文窗口） | 提供了 32K / 64K / 128K / 256K 快捷档位；输出有 8K–64K 档位 |
| **能力**（对话模型） | 两个开关：「视觉输入」（能看图）、「工具调用」（能操作文件/命令等工具）。服务商没说明时按需手动标注，标错了会影响 AI 选模型 |
| **输入单价 / 输出单价**（对话模型） | 每百万 token 的价格（单位 USD）。填了之后监控页能显示成本；留空则按天枢内置的公开目录价折算（查不到价的模型显示「未知价」） |
| **备用模型**（对话模型） | 默认「不启用」。选了另一个模型后，主模型失败时天枢会自动切到它再试一次（见 8.2 的自动重试说明） |

保存后模型列表出现该模型。可随时「编辑」「删除」，或点「**测试**」验证这个模型能否真正对话（注意：向量等非对话模型只有 OpenAI 兼容协议支持测试）。

**测速——看哪个模型响应快**：每个对话模型行上还有「**测速**」按钮，点击后天枢真的发一条短消息给该模型，测出两个数：**首字延迟**（等第一个字要多久，毫秒）和**生成速度**（每秒吐多少 token）。结果显示在模型行上（如「812ms · 45 tok/s」，数字越小越快）。列表上方有「**按测速排序**」开关，点一下按首字延迟从快到慢重排（没测过速的排在最后），再点变回「默认排序」。

> 💡 同一家服务商的不同模型快慢可能差好几倍。发消息总觉得「等半天才开回」的话，给候选模型都测个速，挑首字延迟小的。

### 6.4 日常管理

- **启停**：服务商和模型都有「启用」开关，停用后选择列表里不再出现，配置保留。
- **测试连接**：服务商详情的「测试连接」验证地址与 Key 是否有效。
- **删除**：删除服务商会连带删除其下全部模型配置，有二次确认。
- 页面顶部汇总显示「共 N 个服务商 · N 个模型」。
- **没有全局「默认模型」的概念**：每次发消息在输入框的模型选择器里选即可，选择会随会话记住；没选时天枢自动挑一个可用的模型。想固定用某个模型，就在每个会话里选好它。
- 编辑服务商时 **API Key 留空表示保持原 Key 不变**（换 Key 才需要填新值）。
- **「加密降级」警示条**：保存密钥后，如果本页顶部出现黄色盾牌警示条，说明你这台电脑的系统密钥链（如 Linux 上的 keyring 服务）不可用，API 密钥的加密保护降级了——密钥仍是密文存储，但拿到数据库文件的人可以解开。按提示启用系统密钥链服务后重启应用即可恢复。
- 常见报错含义见 [23. 常见问题](#23-常见问题faq)。

### 6.5 用本地模型（Ollama）——数据不出你的电脑

1. 先在电脑上安装并运行 [Ollama](https://ollama.com)，用 `ollama pull <模型名>` 拉一个模型。
2. 天枢里添加服务商：协议选 **Ollama**，地址 `http://localhost:11434`，API Key 留空。
3. 「从服务商拉取模型」导入你已拉取的模型。

本地模型免费、隐私最好，但效果取决于模型大小与你的电脑配置。

## 7. 新建你的第一个任务

登录后默认落在「**新建任务**」页——这是天枢的发起台。页面中央一句问候「**天枢，我帮你**」，下面就是输入框。

### 7.1 页面从上到下

1. **场景 Tab**（三个胶囊）：**日常办公 / 代码开发 / 设计创意**。
   场景不是装饰——它会注入会话提示词影响 AI 的回答风格（比如代码开发场景会要求给出可直接运行的代码与准确命令），并决定下方出现哪些模板。
2. **模板胶囊行**：按场景出的快捷模板，点击即把预设提示词填入输入框，并把光标定位到 `[占位符]` 处等你替换：
   - 日常办公：文档处理、幻灯片、周报生成、邮件回复；
   - 代码开发：Python 脚本、前端组件、SQL 编写、Debug 排查；
   - 设计创意：文案策划、海报 Prompt、头脑风暴。
   你已启用的技能也会混排在这一行（⚡ 图标）。
3. **输入卡**：占位「描述你的任务，输入 @ 引用文件或技能……」。超过 1800 字显示字数（上限 2000，达到上限提示超长内容可能被截断）。
4. **配置栏**：「**选择工作空间**」下拉（见 7.3）。
5. **底部工具栏**：＋ 添加引用、权限胶囊、模型选择器、AI 润色、发送按钮（见 7.4）。

### 7.2 用 @ 引用文件或技能

在输入框里输入 **`@`**，弹出联想面板，分「工作空间文件 / 资料库」两组实时匹配（↑↓ 移动、Enter 选中、Esc 关闭）。选中后变成一个**引用标签**（不占正文）。也可以把本地文件**直接拖进输入卡**（文本文件限 512KB，二进制文件不支持）。

> 💡 没绑定目录的工作空间不能 @ 文件——先在侧边栏空间菜单里「绑定目录」。

### 7.3 选工作空间（新手第一次必做）

点「选择工作空间」下拉：顶部可搜索，点击即选中；底部两个入口：

- 「**+ 新建空间**」：起个名字建一个空的工作空间；
- 「**打开本地空间**」：选一个电脑上的文件夹——**以目录名建空间并自动绑定目录**，AI 从此获得操作该文件夹的能力。新手推荐这个：新建一个空文件夹（比如 `~/tianshu-work`），从这里打开它。

### 7.4 底部工具栏逐个讲

- **＋ 添加引用**：添加文件（本地选择器）/ 资料库 / 引用工作空间文件；「模式」「专家」「技能」子菜单；「连接器」跳到连接器管理页。
- **权限胶囊**：「默认权限 / 完全访问」二选一（详见 9.1）。
- **专家名徽章**：选了专家会显示在这里，点 × 移除。
- **模型选择器**：按服务商分组列出所有启用的对话模型，底部有「配置模型」直达服务商页。**没配模型时这里会提示「请先配置可用模型」且发送按钮置灰**。
- **AI 润色**（魔法棒图标）：让 AI 把你输入的内容润色成更专业的表达。
- **快速**菜单：总结全文 / 翻译成英文 / 扩写细节 / 列表化改写，以及「已启用技能」组。
- **发送任务**（圆形按钮）：置灰条件——正文为空 / 命中敏感词 / 未选工作空间 / 无可用模型 / 发送中。

### 7.5 三种会话模式

＋ 菜单 → 「模式」里选（也可在对话中途切换）：

| 模式 | 适合 | 行为 |
| --- | --- | --- |
| **默认**（Agent） | 绝大多数任务 | 完整能力：工具、技能、文件、命令全开 |
| **仅问答**（ASK） | 纯聊天、查知识 | 零工具零技能，AI 只用文字回答，绝不会动你的文件 |
| **计划**（PLAN） | 大工程、不敢让它直接动手 | AI **先输出完整计划**（步骤/涉及文件/命令），你明确确认后才开始执行 |

### 7.6 发送之后会发生什么

1. 天枢创建会话（带上你选的场景、专家、模式、模型、工作空间）；
2. 发送首条消息并跳转到**对话页**；
3. **任务标题自动生成**：先是截取你首条消息的前 20 字，随后由模型起一个不超过 20 字的标题（侧边栏看到的名字就是这么来的）；
4. 输入框的草稿自动清空；场景/工作空间/权限档会记住，下次发起不用重选。

发送失败（如网络问题）会停在落地页，草稿原样保留。

## 8. 对话界面详解

### 8.1 顶栏

从左到右：**项目面包屑**（项目会话显示「项目名 / 任务标题」，点击回项目）、工作空间路径 chip（绑定了目录时）、**搜索会话内容**（`⌘F`，输入后 Enter/Shift+Enter 在命中之间循环跳转，显示 n/m 计数）、**转办**按钮（项目任务会话专属）、**产物面板**开关（见 8.6）。

### 8.2 消息区：你会看到哪些东西

AI 干活的过程是「可视化」的，消息流里可能出现：

- **Markdown 正文**：表格、列表正常渲染；**代码块**带语法高亮和「复制代码 / 下载代码」按钮；
- **Mermaid 图表**：AI 输出 mermaid 代码会直接渲染成图，可复制/下载 PNG；
- **图片**：你发的图片点击放大，悬浮可「复制图片 / 另存为…」；
- **文件引用卡 / 技能引用卡**：引用的文件与技能渲染成卡片，点击内嵌预览全文；
- **深度思考面板**：「深度思考」折叠区，流式期间轮换显示「正在思考中… / 马上就好…」等问候语，完成后显示耗时；展开可看思考全文；
- **工具调用卡片**：AI 每用一次工具出一张卡——`🔧 工具名 + 状态`（待执行 / **待审批** / 执行中 / 完成 / 已拒绝 / 失败）+ 摘要（要改哪个文件、要跑什么命令）；点开看完整参数与输出（输出超过 100 行会截断）；审批交互见 9.2；
- **Agent 步骤行**：底部实时显示「第 N 步 · 工具名」或「回复中」；
- **可视化组件卡**：AI 能直接在消息里渲染**数据表、摘要卡、图表**（折线/柱状）和交互式组件（可复制/下载截图）；
- **工作流确认卡**：对话触发工作流时出现「执行确认」卡，展示参数让你点「确认执行」；
- **专家推荐卡**：「为你推荐」某位专家，可一键「添加并启用」；
- **成员报告折叠卡**（专家团专属）：主理人调度了哪些成员干活，消息流里就会出现 👥 折叠卡，一行摘要写「成员 ×× · 第 N 轮 → 交给它的任务」，点开能看这名成员的完整产出原文——想复盘「团队里谁说了什么」就看它；
- 每条 AI 回复尾部显示用量「x 输入 / y 输出 tokens」与所用模型名。

**消息操作**（hover 消息）：

- 你的消息：**编辑**（编辑后重发，其后内容删除并重新生成——慎用）、**存入记忆**（大脑图标，把这条消息的内容交给长期记忆管线归并保存，适合存「我的偏好/背景」这类以后每次对话都用得上的信息，详见 16.1）、复制；
- AI 消息：**重新生成**（同样会覆盖其后的内容）、复制。

> 💡 **发送失败会自动重试**：遇到网络繁忙、服务商限流、超时这类临时故障时，天枢会自动用同一个模型重试一次（约 1 秒后），大多数小抖动你根本感知不到。如果给模型配了「备用模型」（见 6.3），重试仍失败会自动切换备用模型再试一次；备用模型也失败时才报错，错误信息末尾会带 `[fallback retried]` 字样，提醒你这条是换过模型仍未成功的。

### 8.3 输入框全功能

- 占位「今天帮你做些什么？@ 引用资产文件... / 调用技能与指令」。
- **已启用技能**标签行：⚡技能名 ×，点 × 即时停用该技能。
- 空会话时显示绑定专家的推荐提示词胶囊，点击一键填入。
- **三种触发器**：
  - `@` 引用文件（工作空间文件 + 资料库两组联想）；
  - `/` 命令与技能（目前命令有 `/compact` 压缩会话上下文；技能列表紧随其后）；
  - 直接输入 `⚡技能名` 也可以。
- **粘贴附件**：直接 `⌘V` 粘贴截图或复制的文件（本地图片上限 10MB、远程主机 3MB、文本 512KB）。
- **＋ 菜单**：添加文件、专家、技能、连接器（跟新建任务页一致，**会话中途随时换专家/技能/模式/模型，下一轮即生效**）。
- **上下文用量环**（输入框右下）：环形进度（<50% 绿 / 50–80% 黄 / >80% 红），点开看明细——**系统提示词 / 工具及子智能体 / 对话消息 / 连接器及 MCP / 技能** 五类各占了多少；开了记忆功能的还会多一行**记忆占用**，专家团会话多一行**成员调度**（成员消耗不计入主窗口）。会话太长、最早的消息已经装不下时，明细里会出现黄色提示「已裁 N 条早期消息（超出窗口，不进入下次请求）」——意思是这些早期消息不再发给模型（不影响你在页面里查看）。太满时提示「文本过长，请截断或更换模型」，可用 `/compact` 压缩。
- **发送 / 停止**：Enter 发送（IME 输入中的回车不触发）、Shift+Enter 换行；生成期间发送钮变「停止」。

### 8.4 侧边栏：会话与工作空间管理

- **空间区头**：`+` 新建工作空间；每个空间 hover 出 `⋯` 菜单——**重命名 / 绑定目录… / 解绑目录 / 删除工作空间**（删除会连带删除其下全部会话）；`+` 在此空间新建任务。
- **会话行**：标题 + 时间；置顶图钉；未读角标（99+ 封顶）；流式中的绿点。
- **会话 ⋯ 菜单**：重命名 / 置顶 / **归档** / **绑定应用**（把会话圈进某个工作流应用）/ 打开文件夹（打开绑定目录）/ 分享任务（功能开发中）/ 批量操作 / 删除。
- **归档**：收进侧栏「已归档」分组，消息只读（顶部横幅提示，可「取消归档」恢复）；归档后 5 秒内可撤销。
- **批量操作**：全选 → 批量删除 / 批量归档。
- 列表过长时「展开更多（每次 +20）/ 收起（保留最近 5 条）」。

### 8.5 产物面板：看 AI 干了什么

点顶栏「**产物面板**」开关展开右侧面板，三个视图：

- **概览**：本次会话的产物文件与工作空间文件总览；
- **产物文件**：AI 在本会话**写入的文件**（正在写入的标「写入中」）；
- **工作空间文件**：被引用过的工作空间文件。

文件行 `…` 菜单：**预览 / 另存为副本… / 在 Finder 中显示 / 复制路径**。点文件在面板里开预览标签（还能「在新窗口打开」进文件窗口）。

面板顶部还有「**＋ 新标签页**」，除了产物还能开：

| 标签 | 用途 |
| --- | --- |
| **浏览器** | 会话专属浏览器，AI 可代你操作（见 12.4） |
| **工作空间** | 直接浏览绑定目录的文件树 |
| **终端** | 就地开一个命令行终端 |
| **变更** | 绑定目录是 git 仓库时，查看 AI 改了哪些文件（增/删/改 diff；不是 git 仓库会提示） |

面板可「放大」占满窗口。

### 8.6 归档、搜索与历史

- 顶栏放大镜打开**全局任务搜索**；旁边「筛选时间」按今天/最近 7 天/最近 30 天过滤；
- 历史消息向上滚动自动翻页加载；「回到底部」悬浮按钮；
- 执行过 `/compact` 的会话中会出现「上下文已压缩」的分隔提示——之后的对话照常，只是早期内容被压缩摘要了。

## 9. 权限与安全

> 本章回答一个问题：**让 AI 操作我的电脑，安全吗？** 天枢的设计原则是「默认保守、放权需知情」。

### 9.1 两种权限模式

每个会话有一个权限模式，在输入框附近切换（「权限模式」选择器）：

| 模式 | 行为 |
| --- | --- |
| **默认权限**（默认） | 文件写入与常用命令直接运行；**删除、高危命令等敏感操作会先弹窗询问你**，经你批准才执行 |
| **完全访问** | 免确认直接操作此电脑；极高危命令（如磁盘抹除、强推主干）仍会请求确认。**会话级内存态，重启应用后自动回到默认权限** |

切换到「完全访问」时会弹出全屏确认：

> 「确认允许完全访问？——开启完全访问后，除极高危命令外，所有操作将不再询问确认，直接操作您的电脑……包括以下内容：文件操作：读取、创建、修改、上传或删除此计算机上任意位置的文件。终端命令：运行命令、安装软件和更改系统设置。」

需要勾选「我已了解风险，并对自己的数据安全负责」才能点「允许完全访问」。

### 9.2 对话中的审批卡片

默认权限下，AI 要执行敏感操作时，消息流里会出现一张**审批卡片**，显示它想执行什么（命令原文 / 要改哪个文件），带三个按钮：

- **允许**：这次放行；
- **允许并记住**：放行并记住这个工具，本工作空间内以后不再询问（可在安全中心的「系统授权」撤销，见 9.3）；
- **拒绝**：拒绝执行，AI 会收到「已拒绝」的反馈并调整方案。

**「允许并记住」可以只记住一部分**。对命令和写文件类工具，这个按钮会变成两段式：主按钮直接给出一个**范围建议**，点它就只记住这个范围——

- 命令工具按命令开头记住：比如这次跑的是 `git status`，按钮显示「**始终允许（git \*）**」——以后只有 `git` 开头的命令免审，`rm`、`curl` 照样会来问你；
- 写/删文件类工具按目录记住：比如这次写的是 `src/app/main.ts`，建议「始终允许（src/\*\*）」——只免审这个目录，别的目录不放开。

旁边的下拉（**更多记住选项**）里还有「**始终允许整个工具**」——回到老语义，这个工具无论什么参数都不再问（范围大，慎选）。天枢对范围记忆做了安全收口：命令里带管道、重定向这类「链式新命令」的写法时不会命中前缀记忆，防止 `git *` 的授权被 `git push; rm -rf /` 这种命令钻空子。

无论什么权限模式，`rm -rf /`、fork 炸弹等**破坏性命令会被硬拦截**，与权限级别无关。

### 9.3 安全中心

入口：设置面板 → 左栏「**安全中心**」（或对话中权限选择器旁的入口）。这是天枢的安保中控台，分四大块：

**（1）沙箱安全（总开关 + 四个分项）**

- **沙箱安全**总开关：开启后，AI 的所有执行操作均受文件、命令、网络安全规则约束（保持开启！）。
- **文件安全**：管理文件读写黑白名单。优先级：内置敏感路径（SSH 密钥、云凭证等，不可删，读写命中即弹审批）＞ 用户白名单（命中路径写操作免审批）＞ 用户黑名单（命中路径读写都强制弹审批）。支持 `~/` 开头、绝对或工作空间相对路径。
- **命令安全**：管理 Shell 命令名单。优先级：程序黑名单（绝对禁止，含子进程检测）＞ 询问名单（命中先弹审批，「完全访问」下同样生效）＞ 放行名单（命中跳过审批直接执行）＞ 默认审批。例如把 `curl` 加进询问名单、把 `git push` 加进放行名单。
- **网络安全**：管理网络出入站。判定优先级：内置豁免（模型服务/本机）＞ 拒绝名单 ＞ 允许名单 ＞ 断网模式 ＞ 恶意域拦截。支持 `*.example.com` 子域通配。**断网模式**开启后，允许名单与内置豁免之外的全部网络请求被拒绝——适合跑不可信的任务。
- **运行时工具**：逐个关闭 AI 可用的内置工具（读取工作区内文件 / 写入文件 / 删除文件 / 执行 shell 命令 / 读取技能 / 创建技能 / 创建专家 / 调度团队成员 / 计划条目五件套……）。关闭后对本机所有 AI 会话与自动化即刻隐藏。

**（2）数据安全**

- **自动备份**：每次对话修改文件前自动创建备份（有总额上限，可打开备份目录）。
- **删除保护**：开启后文件删除移入回收站而非永久删除。
- **批量删除审批阈值**：单次删除文件数超过阈值（1–10000）时暂停并请求确认。

**（3）审计中心**：所有安全相关操作的留痕日志——拦截了什么危险命令、谁批准了什么、备份/删除记录……支持搜索、分页、导出 JSON/CSV、清空。

**（4）系统授权**：查看并收回 AI 当前被授予的权限——

- **活跃完全访问**：列出正在「完全访问」模式下运行的会话，可「一键收回全部」；
- **工作空间工具记忆**：列出你点过「允许并记住」产生的免审记录，可单条或全部撤销。每条记录显示：所在工作空间、记住的工具（范围记忆会带参数范围，如 `bash: git *`）、**最近使用时间**；列表上方汇总「共 N 条记忆，分布于 N 个工作空间」并按工作空间给出条数分布。**超过 90 天没用过的记忆会带上醒目的「90 天未用」徽标**，同时顶部提示「N 条记忆超过 90 天未使用，建议撤销清理」——放久了不用的授权就顺手撤掉，把口子收到最小。

> 💡 给新手的建议：保持沙箱开启 + 默认权限；不确定的操作一律「拒绝」再看 AI 的替代方案；定期看一眼审计中心和系统授权。

## 10. 专家·技能·连接器

入口：侧边栏 → **专家·技能·连接器**。页面顶部三个 Tab：**专家 / 技能 / 连接器**——这是给 AI「加 buff」的三个维度：

- **专家**：换一个「人」来回答（角色人设）；
- **技能**：给 AI 一套「操作手册」（做事方法）；
- **连接器**：给 AI 接外部工具（查行情、读邮件）。

### 10.1 专家

**专家市场**（默认视图）：

- 顶部「**我的专家 N**」入口进入自己的专家列表；
- 搜索框、**精选场景**（软件开发 / 内容创作 / 投资分析 / 法律咨询 / 企业运营 / 游戏开发）、类型切换（**专家** / **专家团**）、排序（综合 / 最热 / 最新）、12 个分类 pill（产品设计、技术工程、金融投资……）；
- 点卡片看详情：**试试这样问**（推荐提示词，一键填入输入框）、**提示词预览**（这个专家的系统提示词）、专家团的**团队成员**与**主理人**、附带技能；
- 底部按钮：「**添加到我的专家**」（收进自己的列表）/「**添加并对话**」（收下并直接开聊）/「**去对话**」（已添加过的直接开聊）。

**我的专家**：

- 每张卡可：**开对话**（新建一个绑定该专家的会话直达聊天页）、编辑、导出（生成可分享的 JSON）、删除（删除后不影响已有会话的历史消息；内置专家不可删）；
- 顶部「**导入**」（导入别人分享的专家 JSON）与「**创建专家**」。

**创建自己的专家**（两条路）：

1. **对话式创建（推荐新手）**：点「创建专家」，天枢会新开一个会话并预填引导语——你只需要像聊天一样回答 AI 的几个问题（专家方向与职业头衔、核心能力标签、推荐开场提问），AI 会调用工具直接把专家建好，你确认即可。
2. **表单创建**：「新建助手」对话框里填：
   - **名称**、**图标（emoji）**；
   - **类型**：「**单专家**」或「**专家团**」——专家团 = 多个成员协作（每名成员有花名、成员 id、职业头衔、人设），主理人负责编排调度；
   - **系统提示词**（必填）：这个专家的性格、能力与行为准则；
   - 描述、标签、职业头衔、分类；
   - **推荐提示词**：最多 3 条开场提问，用户可一键使用；
   - **附带技能**：从已安装技能里挑几个跟这个专家绑定；
   - 参数：温度 / Top P / 最大输出 Tokens（留空用默认）。

**在会话中选用专家**：聊天输入框 **＋** 菜单 → 「专家」（可搜索；选「不使用专家」即普通对话；底部「召唤更多专家」跳回管理页）。绑定后输入框上方会出现该专家的推荐提示词。

### 10.2 技能

技能视图分两块：「**发现**」（技能市场）和「**我安装的 N**」。

**安装技能的三条路**：

1. **查找技能**（市场安装）：精选技能、「换一换」、分类、搜索、加载更多；已安装的标「已安装」；重复安装会问你是否「覆盖安装」（替换文件，启用状态保留）。
2. **上传技能**（本地导入）：把技能的 **zip 压缩包或文件夹拖进导入框**。要求：**必须包含 `SKILL.md`，且文件头部 YAML 含 `name` 与 `description`**。导入前会自动安全预检，可选「非高风险自动安装」。
3. **创建技能**（对话式）：点后新开会话并预装 skill-creator 技能，你对 AI 说想要什么技能，它帮你写好 SKILL.md（需先有工作空间）。

**技能管理**：

- 卡片右上开关**启用/停用**——**只有已启用的技能才会出现在对话 ＋ 菜单里**；
- 「**批量管理**」：全选后批量开启 / 关闭 / 卸载（卸载会删除技能文件与记录，不可恢复）；
- 卡片上可以给技能打**场景标**：日常 / 编程 / 设计；
- 「**打开技能目录**」直接查看技能文件（想手工编写/修改技能文件的进阶用户用）；
- 技能分两级：**系统技能**（内置的 skill-creator、workflow-creator，不可卸载、只能禁用）与**用户技能**（市场装的、zip 导入的、AI 创建的，来源徽章分别显示「市场 / 本地」）。

> 💡 想自己写技能？技能就是一个文件夹，里面放一个带 frontmatter 的 `SKILL.md`（写清 name、description 和操作指南），放进技能目录即生效、免重启。

### 10.3 连接器（MCP）

连接器视图是一个**连接器市场 + 管理弹窗**的组合：

**市场**：24 张预置连接器卡（搜索「搜索连接器」），例如：通达信（股票行情与研报）、腾讯自选股、QQ 邮箱（自然语言收发邮件）、企业微信、飞书、钉钉、腾讯文档、腾讯会议、腾讯问卷、TAPD、天眼查、企查查、Tushare（金融数据）、北大法宝（法律法规检索）、百度网盘、微云、金山文档……点卡片上的「＋」会把该连接器的配置模板预填进管理弹窗。

**「自定义连接器」/「配置」**：打开「**MCP 服务管理**」弹窗，里面是一个 **JSON 编辑器**（与已安装服务实时同步，保存后生效）。两种传输类型的写法：

- **stdio 子进程**（本机命令行启动的服务）：

  ```json
  {
    "mcpServers": {
      "我的服务": { "command": "npx", "args": ["-y", "包名"], "env": { "KEY": "value" } }
    }
  }
  ```

- **HTTP 端点**（远程服务，streamable HTTP）：

  ```json
  {
    "mcpServers": {
      "我的服务": { "url": "https://host/mcp", "headers": { "Authorization": "Bearer 你的Token" } }
    }
  }
  ```

保存时自动校验（command 与 url 必须二选一、名称不能含连续下划线、args/env/headers 格式等），成功提示「保存成功（新增 N · 更新 N · 移除 N）」。

**管理与状态**：

- 每行显示名称、传输类型徽标（stdio 子进程 / HTTP 端点）、**状态**（已连接 / 连接中 / 错误 / 已停用）与**工具数**；
- 开关启停（停用即断开并注销工具）；「重连」按钮；删除有二次确认；
- 应用启动时会**自动连接全部启用的连接器**；
- 连接器提供的工具以 `mcp__服务名__工具名` 注册进对话；标注了「只读」的工具免审直接执行，写类工具照常走审批（见第 9 章）。

> ⚠️ 远程主机模式下，专家管理与技能管理为只读（提示「仅本机可用」）；连接器的新增与编辑也请在桌面端完成。

## 11. 资料库

### 11.1 资料库是什么

资料库是你的**个人资料中枢**：把你常用的文档、表格、图片、网页链接集中管理起来，在 AI 对话中随时引用，让 AI **基于你自己的资料**回答问题，而不是凭空编。AI 在会话里写出的文件（产物）也会自动汇总到这里。

> 💡 配置了可用的向量模型后（第 6 章，「向量」类型的模型），你上传或写入资料库的文本类资料会**自动建立语义索引**：AI 检索资料库时按「含义相关」找内容（问「去年营收的结论」能命中写着「营业收入同比…」的文档），而不只是匹配文件名；没配向量模型时自动退回按文件名查找，功能不受影响。

入口：侧边栏 → **资料库**。

### 11.2 页面布局

- **左栏**：搜索入口、「**最近**」（最近访问过的文件）、「**本地产物**」（AI 写出的文件，见 11.6）、「**我的资料**」文件夹树（可多级嵌套，可收起）。
- **主区**：文件列表（列：名称、类型、位置、最近访问；点列头可排序）。顶部有「全部 / 收藏」两个 Tab、类型筛选下拉（文档/表格/幻灯片/网页/图片/PDF/音频/视频/代码/文本/Markdown/压缩包/其他）和「**快速添加**」按钮。
- 点开一个文件进入**详情页**：内嵌预览（Markdown、表格可以直接编辑），显示类型/大小/添加时间/原路径，顶部有重命名、移动、删除、在 Finder 中显示等操作。

### 11.3 把资料放进来（五种方式）

1. **上传文件**：点「快速添加」→「上传文件」，可多选。
2. **上传文件夹**：整个目录结构原样搬进来。
3. **拖拽**：把文件从桌面/文件夹**拖到天枢窗口的任意位置**即可入库，自动归档——这是最快的方式。
4. **新建**：新建文档（Markdown）、新建表格（CSV）、新建文件夹。
5. **添加链接**：填「链接地址」+ 可选标题，收藏一个网址（点击时用外部浏览器打开）。

入库提示会告诉你结果：「已入库 3 个，1 个重名已自动编号，失败 0 个」。重复上传同名文件不会覆盖，会自动编号。

### 11.4 整理与查找

- **收藏**：点文件名前的空心 ♥，变红心即收藏；「收藏」Tab 里跨文件夹集中查看。
- **移动**：行尾 `…` 菜单 →「移动到…」，在弹窗的目录树里选目标位置。
- **搜索**：`⌘K / Ctrl+K` 唤起搜索面板，实时检索全部资料；空着时显示「最近浏览」。
- **删除**：有二次确认；删除文件夹会连带其中全部内容。
- 「在 Finder 中显示」可以直接在系统文件管理器里看到这个文件的真实存储位置。

### 11.5 在对话中引用资料

这是资料库的核心玩法：

1. 在对话输入框点 **＋** → 「**资料库**」，打开「引用资料库」选择器；
2. 逐层浏览或搜索，勾选想要的文件（可多选），点「**引用**」；
3. 文件以附件形式挂在输入框上，随消息一起发给 AI。AI 会先读取文件内容再回答。

> 💡 新建任务页的「添加引用」菜单同样可以引用资料库。工作流里还有专门的「资料库检索」节点（见 13.5）。

### 11.6 本地产物——AI 写的文件都去哪了

左栏「**本地产物**」视图按 **工作空间 → 任务** 两层汇总 AI 在会话中写入的全部文件，支持按文件名/任务/工作空间搜索。这里和「我的资料」是两个独立区域：本地产物是自动沉淀的，我的资料是你主动整理的。

### 11.7 快捷技巧

- 文件夹行 `…` 菜单 →「**添加到任务**」：一键跳去创建一个处理该文件夹内容的自动化任务（提示词自动预填「请处理资料库文件夹「xx」中的内容」）。

## 12. 内置浏览器

天枢自带一个多标签浏览器，不用离开应用就能查资料；更重要的是，**AI 可以替你操作它**。

入口：侧边栏 → **浏览器**。

### 12.1 基本使用

- **新标签页**：点标签栏末尾「+」；页面上点开的链接会自动开成新标签；悬停标签显示关闭按钮。
- **地址栏**：输入网址回车。只支持直接访问网址（不是搜索引擎，想搜索请输入搜索引擎的网址）。
- **导航**：后退 / 前进 / 刷新 三个标准按钮；地址栏下方有 2px 加载进度条。
- 页面加载失败会显示「页面加载失败」或「已被安全策略拦截」，可点「重试」。

### 12.2 「…」更多菜单

| 功能 | 说明 |
| --- | --- |
| **查找页面内容** | 页内查找条：输入即搜，显示「当前/总数」，Enter 下一个、Shift+Enter 上一个、Esc 关闭 |
| **缩放** | 25%–500%，点中间百分比回到 100% |
| **显示设备工具栏** | 开启设备模拟（见 12.3） |
| **截取屏幕截图** | 截当前页面并复制到剪贴板 |
| **清除浏览数据** | 清除 Cookie（登录态）/ 清除缓存与站点数据；清除后需刷新页面 |
| **在外部浏览器打开** | 把当前页交给系统默认浏览器 |

### 12.3 设备模拟

开启设备工具栏后，可以从四种预设里选：**手机 375×667 / 大屏手机 412×915 / 平板 768×1024 / 桌面 1440×900**，旁边有横竖屏**旋转**按钮。适合检查网页在手机上的显示效果。模拟状态跨导航保留。

### 12.4 让 AI 替你操作网页

在**对话界面右侧面板**（产物面板，见 8.5）里也可以打开浏览器标签。这个浏览器会和当前会话绑定，AI 随即获得四个网页操作工具：

- **读取页面快照**：AI「看到」页面上的可交互元素与正文；
- **导航**：让 AI 打开某个网址；
- **点击**：按快照里的序号点击元素；
- **输入**：往输入框里填文字（点击与输入属于写操作，默认权限下会先经你审批）。

典型用法：对 AI 说「打开 xx 网站，找到登录按钮，帮我看看页面上有哪些栏目」。

## 13. 工作流（流程编排）

### 13.1 工作流是什么

工作流是一张**可视化的自动流水线图**：把「取数 → AI 处理 → 写文件 / 发通知 / 发邮件」等步骤用节点连成一条线，一次搭建、反复运行。适合**有固定套路的重复性工作**（每天的日报、定期的数据汇总），比每次重新对话省事得多。

入口：侧边栏 → **工作流**。

> 💡 新手建议：先从「从模板新建」挑一个模板改参数跑通，再自己从空白画布搭。

### 13.2 列表页

每行显示工作流名称、节点数、描述，行内可：**运行**（试运行）、查看**运行记录**、**启停**开关、**删除**（二次确认；被定时任务引用的工作流不能删，会提示先解除引用）。点行进入编辑器。

工具栏：

- 「**新建工作流**」：从空白开始；
- 「**从模板新建**」：8 个内置模板——分支日报、调研成文、意图分流（售前/售后）、大表抽取·分片子图、大表抽取（分片循环）、代码流水线（bash→Python→Node）、ETL 销售报告（CSV→统计→邮件）等；
- 「**导入**」：导入别人分享的工作流 JSON（单图或批量包）；
- 「**批量管理**」：多选后「导出所选」，生成一个可分享的 JSON 文件。

### 13.3 编辑器：画布与节点

**画布**：节点是卡片，从上游节点的输出锚点**拖线**到下游节点的输入锚点即完成连线；`Delete`/`Backspace` 删除选中的节点或连线；左上角可缩放、有小地图；「自动整理布局」一键排齐。图末端有一个固定的「**END（结束）**」标记。

**添加节点**：点左上角「添加节点」，面板按五类分组，可搜索。全部 30 种节点：

| 分组 | 节点 | 用途（一句话） |
| --- | --- | --- |
| **模型** | 开始 | 定义整张图的输入变量，全图至多一个 |
| | AI 节点 | 调用大模型生成内容，可挂工具（按 agent 步骤执行） |
| | 图像生成 | 文本生成图像，输出文件路径 |
| **工具** | 代码节点 | 运行 bash / python / nodejs 脚本 |
| | HTTP | 调用外部接口，支持鉴权（Basic/Bearer/阿里云 ACS3 签名等）与文件上传 |
| | 邮件 | SMTP 发邮件 |
| | 资料库检索 | 按关键词检索你的资料库内容 |
| **流程控制** | 条件分支 | 按条件多路分流（画布上逐分支连线） |
| | 意图识别 | 用模型按语义分类分流（如售前/售后） |
| | 循环 | 列表逐项执行子工作流（数组/指定次数/无限+终止条件三模式，支持并发与中间变量） |
| | 子工作流 | 引用另一张工作流（可异步） |
| | 延时 | 等待 1–600 秒（轮询/节流） |
| | 聚合 | 等多个上游都完成后，把它们的输出拼成一份 |
| **数据处理** | JSON 解析 / JSON 序列化 | 从 JSON 里取字段 / 把文本安全转成 JSON 字面量 |
| | 向量化入库 / 语义检索 / 混合检索 / 重排 | RAG 四件套：把资料切块入库，按语义/全文/混合方式检索，再精排 |
| | 数据库 | SQL 查询 SQLite / PostgreSQL / MySQL / Oracle / SQL Server 五类数据库 |
| **输入输出** | 文件读取 / 文件写入 | 读工作空间文件 / 追加或覆盖写回工作空间 |
| | 文档提取 | PDF / Word 提取纯文本 |
| | 通知 | 发系统桌面通知（可同时推 IM webhook） |
| | Excel 读取 / 写入 | xlsx ↔ JSON 行数组 |
| | CSV 读取 / 写入 | CSV ↔ JSON 行数组 |
| | 变量 | 文本轻量转换（替换/截取/大小写/日期格式化等操作链） |
| | 聚合统计 | 行数组计数/求和/平均/分组统计 |

**属性面板**（右侧）：选中什么就编辑什么——

- 选中**画布空白**：「工作流属性」（名称、描述）；
- 选中**节点**：节点 ID（kebab-case 小写短横线，保存后不可改）、节点名称、按类型不同的字段表单，以及删除节点；
- 选中**连线**：可设置条件（仅上游是分支节点时，选择走哪个分支；默认「无条件」）。

### 13.4 变量：节点之间怎么传数据

工作流里用**双花括号占位符**在节点之间传递数据：

| 占位符 | 含义 |
| --- | --- |
| `{{input.变量名}}` | 开始节点里定义的输入变量（运行时由你填写） |
| `{{nodes.节点ID.output}}` | 上游某个节点的输出 |
| `{{date}}` / `{{weekday}}` / `{{time}}` | 运行时的日期 / 星期 / 时间 |

例如 AI 节点的提示词写「总结 {{nodes.read.output}} 这份文档」，就会把「read」节点的输出填进来再发给模型。

### 13.5 各节点的关键配置速览

- **开始节点**：声明输入变量，每个变量可设类型（文本/数值/布尔/枚举/日期）、是否必填、默认值。运行时会按类型出对应的表单控件。
- **AI 节点**：选模型、系统提示词（可选）、提示词、温度；「启用工具」后该节点可像 Agent 一样调工具（可设白名单、最大步数）；输出模式「文本」或「分支」（按模型输出走不同分支）；还有「**AI 润色**」按钮帮你优化提示词。可设重试次数与超时。
- **代码节点**：选语言（bash/python/nodejs），脚本里 `stdout` 的内容就是节点输出；支持占位符替换。超时默认 30 秒。
- **HTTP 节点**：方法/URL/请求头/查询参数/请求体（无/纯文本/表单/二进制文件）；鉴权支持 Basic、Bearer、自定义头、阿里云 ACS3 签名；可设重试（网络失败或非 2xx 时，0–5 次）。
- **文件写入**：限工作空间目录内，追加/覆盖两种模式——**挂到定时任务上运行时需要任务开启「允许完全访问」**（试运行不受限）。
- **循环节点**：适合「对一堆数据逐条处理」，可设并发数（1–5）、单项失败策略（中断/跳过）、项数上限（防失控保险丝）。
- **数据库节点**：SQL 支持参数化占位（`?` 或 `$1` 等），参数经驱动绑定防注入；SELECT 默认最多返回 1000 行（可调，ETL 大表可到 10 万）。
- **每个节点都有「测试节点」**：单独跑这一个节点（自动收集它引用的变量生成表单），不影响整图。

### 13.6 保存、校验与 JSON 模式

- **保存**：名称必填；有校验问题时禁止保存并提示「无法保存：还有 N 个校验问题待处理」。
- **校验问题面板**：如「节点 id 重复」「工作流须有唯一入口」「条件边取值不在分支选项内」……**点击问题条目会自动定位到出错的节点**。
- **画布 / JSON 源码**双模式：顶部切换。JSON 模式直接编辑整张图的源码（高级玩法，适合复制分享）；解析失败时不允许切回画布。
- **版本保护**：如果同一张图在别处被改过，保存时会提示「工作流已在其他位置被修改，已为你重新加载最新版本」。
- 「**导出 JSON**」把当前工作流导出成文件分享给别人。

### 13.7 试运行与运行历史

- **试运行**：点「试运行」（需先保存）。弹窗里按开始节点声明的变量出表单（枚举出下拉、布尔出开关、数值出数字框），再选一个工作空间，点运行。提示「已触发试运行，结束后在运行历史查看」。
- **运行历史**：每次运行一条记录（触发时间/触发方式/耗时/状态）。运行中的记录有「**中断运行**」按钮。点开一条记录可看**节点轨迹**：每个节点的状态、耗时、输入输出、错误详情，图像生成节点直接显示图片缩略图。

### 13.8 Webhook：让外部系统触发你的工作流

保存后的工作流可开启 **Webhook**：开启后天枢在本机起一个 HTTP 服务，**任何外部系统 POST 这个专属地址就能触发这张图**（比如让监控告警系统自动触发一个「分析日志」工作流）。可配置响应状态码、响应模板、异步模式（立即返回 202 + 轮询地址，适合长任务）、「允许完全访问」（放行代码/文件写入节点）。注意「重开换 token」后旧地址立即失效。

### 13.9 进阶：应用与数据源

- **应用管理**（用户菜单 → 应用管理）：把一组工作流打包成一个「应用」，会话绑定后，AI 在该会话只能看到/运行这个应用里的工作流——适合把「记账」「周报」这类成套流程圈起来。
- **数据源配置**（用户菜单 → 数据源配置）：保存 PostgreSQL 连接信息，工作流数据库节点经 `dataSourceId` 引用，凭据不进对话上下文。

## 14. 自动化（定时任务）

### 14.1 自动化是什么

自动化 = **到点自动执行**的 AI 任务：让 AI 每天早上 9 点给你生成早报、每周五汇总周报、每小时巡检一次目录……到点后天枢自动拉起一个会话（或运行一张工作流），并把每次运行记录留档。

入口：侧边栏 → **定时任务**。页面两个 Tab：「**定时任务**」「**运行记录**」。

### 14.2 任务列表与健康总览

列表顶部有健康度面板：**今日运行 / 成功率 / 失败 / 进行中 / 异常任务** 五个 KPI + 近 7 天成功/失败趋势小柱图 +「需要关注」清单（异常任务、失败运行，点击直达处理）。任务行显示名称、归属（本地 / 项目·xx）、执行频率摘要、状态徽标与启停开关。

筛选：全部 / 本地 / 项目 / 云端；全部 / 运行中 / 已暂停 / 异常 / 已过期。支持按名称搜索、批量管理（多选删除）。

### 14.3 创建一个定时任务

点「**添加自动化**」→「自定义创建」（或「从模版添加」直接用模板）：

1. **名称**：如「每日 AI 早报」。
2. **执行体**，二选一：
   - **Prompt**：写一段提示词描述要让 AI 做什么。输入卡和对话输入框一样支持 `@` 引用文件、插入技能、选择模型；还可以插入**变量**——`日期 {{date}}`、`星期 {{weekday}}`、`时间 {{time}}`，运行时会替换成当时的实际值（比如「总结 {{date}} 的新闻」）。
     - **模型参数**：精确（温度 0.2）/ 均衡（0.7）/ 创意（1.0）三档预设。
   - **工作流**：选一张已建好的工作流来执行（见第 13 章）。
3. **工作空间**：任务在哪个工作空间下执行（Prompt 型任务的产物会落在这里）。
4. **执行频率**（见 14.4 详解）。
5. **错过处理**：电脑关机错过了执行点，**跳过**还是**补执行一次**。选「补执行一次」时旁边会出现「**补跑上限**」数字框（1–10）：错过的触发点最多依次补跑几次，缺省 1 次——比如关机一晚错过了 5 个整点的任务，上限 1 就只补跑最近那一次，更早的直接跳过，避免开机后被连环补跑刷屏。任务卡片和频率摘要会明示这个配置（如「每天 09:00 · 错过补跑最多 1 次」）。
6. （可选）**事件触发**：除定时外，还可以「应用启动时」或「某任务/工作流完成（成功/失败/任意）时」额外触发。
7. 保存。

> ⚠️ 创建时会看到红字提示：「该任务默认以受限权限运行（写入类操作将被拒绝）；可在保存后进入任务详情页开启完全访问」——需要写文件的任务，记得去详情页开权限（见 14.6）。

### 14.4 执行频率怎么配（不用写 cron）

频率配置是表单化的，两种模式：

**「周期」模式**——预设频率下拉：

| 频率 | 需要再填什么 | 摘要示例 |
| --- | --- | --- |
| 单次 | 日期 + 时间 | 「2026-11-11 09:00 执行一次」 |
| 每天 | 时间 | 「每天 09:00」 |
| 每周 | 星期（可多选）+ 时间 | 「每 周一,周三 09:00」 |
| 双周 | 星期 + 起始日期 + 时间 | 「每两周 周五 18:00」 |
| 每月 | 几号 + 时间 | 「每月 1 日 09:00」 |
| 每年 | 月 / 日 + 时间 | 「每年 12 月 31 日 23:59」 |

**「间隔」模式**——每隔 N 分钟/小时执行一次（最小 5 分钟），可选「生效星期」（比如只在 工作日 每小时跑）。

两者都可设**有效期**：长期有效 / 自定义时间段（起止日期）。底部摘要栏实时显示人话版配置，如「每天 09:00 · 长期有效」。

### 14.5 模板市场

「从模版添加」进入模板市场，内置 8 个开箱即用模板（点「使用模版」后自动预填配置）：

- **每日 AI 新闻推送**：每天早 9 点生成三分类早报与趋势点评
- **每周工作周报**：每周一 18:00 汇总本周产出
- **双周代码回顾**：每两周盘点工作空间亮点与技术债
- **每月账单汇总**：每月 1 号汇总上月模型调用费用
- **跨年回顾提醒**：每年 12 月 31 日 23:59 生成年度回顾
- **工作空间巡检**：工作日每小时检查目录占用 TOP5 与最近变更
- **站会准备**：工作日 9:30 依据昨日产出准备站会三条

### 14.6 任务详情页

点击任务行进入详情（左配置 / 右运行历史）：

- **测试运行**：立即手动跑一次（有未保存修改会先自动保存）；
- **执行权限**：在这里可为任务开启「**完全访问**」（否则写文件类操作会被拒绝）；
- **执行频率**：点「修改」重配时间表；
- 工作流型任务显示「执行工作流」卡，可「查看工作流」直达编辑器；
- 右侧运行历史：筛选全部/成功/失败/运行中，失败行可展开看错误详情，点行可**跳回当时的会话**查看完整对话过程。

### 14.7 运行记录页（全局）

「运行记录」Tab 汇总所有任务的历次运行：触发时间 / 任务 / **触发方式**（定时、补执行、重试、手动、事件、子工作流、Webhook）/ 耗时 / 状态 / Token 消耗（「x 入 / y 出」；重试会标「第 N 次」）。

> 💡 **失败自动重试**：定时任务因网络繁忙、限流、超时这类临时故障失败时，天枢会自动重试——间隔逐次拉长（约 1 分钟 → 3 分钟），连同首次最多执行 3 轮；重试的运行在记录里以触发方式「重试」+「第 N 次」标注。密钥无效、模型不存在这类**配置类错误不会重试**（重试也没用），会直接标失败等你处理。

## 15. 监控（用量统计）

想知道 AI 帮你干了多少活、花了多少 token？入口：侧边栏 → **监控**。

- **场景筛选**：全部 / 对话 / 工作流 / 定时任务——分别看三类场景的消耗。
- **五个 KPI 卡**：今日输入 Token、今日输出 Token、今日 LLM 轮次、今日工具调用（含成功率）、**累计成本**。成本来自你在模型配置里填的单价（见 6.3）；没填单价的模型按天枢内置的公开目录价折算，折算不到的计入「未知价」。
- **近 7 天趋势图**：每天的 Token 总量与调用次数双柱图，悬停显示明细。
- **按模型分布表**：每个模型的轮次、输入/输出 Token、**成本**——一眼看出哪个模型是你干活主力、哪个最烧钱。
- **工具排行表**：每个工具的调用次数、成功率、平均耗时、被拒次数、失败次数（被拒/失败红色高亮）。
- **MCP 服务表**（用了连接器才出现）：把 MCP 连接器的工具调用**按连接器聚合**——每个连接器的调用次数、成功率、平均耗时、被拒/失败次数，哪个外部服务又慢又坑一目了然。

> 💡 主机页选中一台远程主机时，遥控区顶部还会显示一张「**用量监控**」摘要卡（该主机今日的输入/输出 Token、LLM 轮次、工具调用四个数，可随时刷新）——不用切到对方机器也能瞄一眼远端的消耗，见第 20 章。
>
> 数据来自每次 LLM 调用与工具调用的留痕，只统计你自己的账号。

## 16. 记忆与个性化

### 16.1 记忆与进化——让 AI 越用越懂你

入口：用户菜单 → **记忆与进化**（或设置面板 → 记忆与进化页）。

- **生成对话记忆**开关：开启后天枢会从你的对话中提取背景信息，生成关于你的个性化记忆（工作背景 / 个人背景 / 当前关注 / 近期动态 四个板块）。
- **记忆每晚自动整理**；也可点「**立即整理**」手动触发。状态栏显示「上次整理：xx」。
- **逐条管理记忆**：「管理记忆」卡里每条记忆一行，鼠标悬停会出现两个小按钮——**删除条目**（只删这一条，不用清空重来）和**查看来源会话**（跳回这条记忆是从哪次对话提炼出来的）。想批量改还是用 AI 指令（见下）。
- **编辑记忆**：用自然语言下指令即可，比如「记住我在厦门」「删掉天气相关记忆」。对话里也可以随时把某条消息直接「存入记忆」（见 8.2）。
- **导入记忆**：把你在其他 AI（如 ChatGPT）里积累的记忆搬过来——复制天枢给的提示词去那边对话，把结果粘贴回来导入。
- **导出记忆（JSON）/ 导入记忆（JSON）**：管理卡右上角的两个图标按钮，把记忆（含个性化画像与长期记忆）导出成一个 `tianshu-memory-日期.json` 文件，换电脑/换账号时导回来即可——导入按「合并追加」处理，不会覆盖现有记忆；文件格式不对会整体拒绝、原记忆不动。
- **重置**：清空全部记忆（不可恢复，有二次确认）。
- **记忆整理模型**：可指定用哪个模型整理记忆，默认自动选。
- 记忆会占用对话的上下文额度：对话输入框右下角的上下文用量环明细里有**记忆占用**一行，显示当前记忆吃了多少 token（见 8.3）。
- **多账号互不串记忆**：记忆跟着登录账号走（按账号分开存放）。一家人各用各的账号登录同一台电脑，各自是独立的一套画像，换账号登录不会看到也不会混入别人的记忆。

> ⚠️ 隐私提示：记忆完全保存在本地；关闭开关后记忆不再自动更新。

### 16.2 个性化——定制 AI 的性格与称呼

入口：设置面板 → **个性化**页。

- **回复风格**（8 选 1）：默认 / 专业严谨 / 亲和友善 / 直言不讳 / 天马行空 / 高效务实 / 毒舌吐槽 / 启发引导，每档附一句说明。
- **自定义指令**：全局生效的补充规则，自动拼进每次对话。例如「回答先给结论再展开；始终使用 Python 代码示例」。
- **称呼与身份**：「Tianshu 对你的称呼」（AI 叫你什么）、「Tianshu 的名字」（AI 自称，默认「天枢」）。
- **高级人设**：**人设 / 人格描述**（AI 的底层 System Prompt）与**长期记忆**（希望 AI 永远记住的信息，每轮自动携带）。
- **基础交互**：「加载欢迎语」（AI 响应较久时轮换显示问候语缓解等待焦虑）、「展示文件变更过程详情」（AI 执行文件操作时实时展开步骤）。

## 18. 项目与计划

### 18.1 项目是什么

如果说工作空间是「AI 的工位」，**项目就是人的协作容器**：把一个项目（一个产品、一次调研）的计划、任务、文件、AI 会话、定时任务装在一起，项目还能挂载专属的专家/技能/连接器，让项目里的每次 AI 对话都自动带上这套能力。

入口：侧边栏 → **项目**。页头副标题「多人协同，打造超级团队」。

> 📌 当前版本项目为**单成员**（创建者即成员，暂无邀请其他成员的入口），数据按账号隔离。

### 18.2 项目 hub（列表页）

- **我的项目**：卡片网格（名称 + 创建时间），支持搜索；悬停卡片右上 `…` 菜单可**重命名 / 删除**（删除会移除项目的动态流与全部挂载配置，不可撤销）。点卡片进入工作台。
- **从模版创建**：四个内置模版，点击即带预填内容打开新建弹窗——
  - **产品需求全流程**（从需求规划、PRD 到研发测试验收）
  - **市场调研**（竞品分析、行业洞察与调研报告）
  - **Bug 跟踪**（缺陷记录、分级与修复跟踪）
  - **空白项目**（从零自定义项目指令）
- **新建项目**弹窗三步：
  1. **项目名称**（必填，15 字以内，不能与现有项目重名）；
  2. **指令配置**：一段「项目指令」——定义 AI 在本项目中的角色、工作流与规范（选模版可快速填充；已有内容时切换模版会提示覆盖）；
  3. **能力挂载**：给项目挑选**连接器 / 专家 / 技能**（各分区点「添加」多选，选中项以标签展示，可移除）。

### 18.3 项目工作台

进入项目后：顶部三个 Tab——**计划 / 任务 / 资产**；右侧 320px「**项目配置**」面板（可收起）；底部一条贯穿的**快速发起条**（输入「今天帮你做些什么？@ 引用资产文件、项目待办或调用技能」，发送后跳转到会话页继续对话）。

**项目配置面板**（右侧）：

- **指令**：查看/编辑项目指令；
- **能力挂载**：随时增删连接器/专家/技能；已失效的挂载（比如技能被删了）灰显并标「已失效」，可逐个显式移除；出现失效项时面板会提示「N 项失效挂载」并给出「**清理失效挂载**」按钮，一键把失效项全部清掉。
- **成员**：当前显示创建者（「创建者」「我」徽章）；
- **定时任务**：项目专属自动化任务的入口（新建/前往自动化）；
- **项目资产空间**：项目文件存放位置。

**任务 Tab**：你的个人任务聚合清单（「仅自己可见，不同步到项目」）——范围筛选「我的任务 / 指派给我 / 我创建的」、来源筛选「本地任务 / 项目任务」、搜索；「新建本地任务」。点本地任务开编辑弹窗，点项目任务跳到该项目的计划视图。

**资产 Tab**：项目的文件仓库——面包屑导航、容量条（已用/配额）、排序与类型筛选、「上传」「新建文件夹」、拖拽上传；行操作：打开 / 在文件夹中显示 / 重命名 / 删除。计划项的附件就存在这里。

### 18.4 计划：五种视图

计划 Tab 顶部是**视图 Tab 栏**（可拖动排序、「＋ 添加视图」、Tab `…` 菜单重命名/删除；最后剩一个视图时不可删）。同一批计划数据，五种看法：

| 视图 | 长什么样 | 适合 |
| --- | --- | --- |
| **表格** | 类似 Excel：列＝标题/状态/处理人/优先级/标签/自定义字段；顶部快速新增行「输入标题，回车快速创建」；表头「管理字段」可加自定义列（文本/数字/日期） | 批量录入、字段多 |
| **看板** | 泳道列（按状态：待开始/进行中/已暂停/已完成；也可按优先级或处理人分组——「视图设置」里换）；卡片可**拖拽跨列**改状态；列头「＋」快速新增该列事项 | 看进度、拖拽流转 |
| **列表** | 待办清单式，按状态四组折叠，勾选框打勾完成；超期截止日红色 | 日常勾任务 |
| **甘特** | 时间轴条形图：粒度日/周/月/年可切，「今天」竖线定位；条形可**拖拽平移改期**、拖两端**拉伸调整时长**；无日期的任务灰显，点它去补日期 | 排期、看时间线 |
| **日历** | 月历视图：上/下月、「今天」；日格显示事项 chips（最多 3 个+N）；点空白格新建带该日期的事项；带农历/节日 | 看某天有什么 |

**筛选与排序**：「筛选」按钮可加多个条件（字段：标题/状态/处理人/来源/优先级/标签；操作符：是我 / 是以下任一 / 包含等；来源分「手动创建 / AI 生成 / 模版导入」），配好后可「**保存为新视图**」或「覆盖保存」，让常用筛选变成一键可达的视图 Tab。

### 18.5 计划项（一条待办）的字段

点任意事项（或各视图的「＋」）打开编辑弹窗：

- **标题**（必填，100 字以内）、**描述**（支持 Markdown 预览）；
- 属性胶囊：**状态**（待开始/进行中/已暂停/已完成）、**处理人**（默认指派自己，可选未指派）、**优先级**（P0–P3，缺省 P1）、**标签**（回车添加）、**开始日期 / 截止日期**；
- **自定义字段**：项目里定义的文本/数字/日期列；
- **附件**：回形针按钮 →「上传文件」或「**从资产挑选**」（存到项目资产的 attachments 目录）。挂载的文件后来被删除或改名时，附件会**灰显**并提示「文件已不存在（可能已被删除或改名）」，可重新上传或换一个；
- **AI 进展**：AI 写入的进展摘要（只读折叠区）；
- 右上角可全屏编辑。

### 18.6 计划 × AI：让 AI 帮你推进

这是项目模块最实用的部分，双向打通：

- **「推进（会话）」**（表格/列表行尾按钮）：一键为该事项开一个专属 AI 会话（已绑定的直接回到那个会话）——AI 带着项目上下文干活；
- **「AI 推进」**：把引导语预填到底部发起条：「请推进 #编号《标题》：结合项目上下文与此任务的进展记录，推进下一步工作，并更新任务状态与进展」；
- 会话顶部显示**项目面包屑**（项目名/任务标题，点击回项目）；任务会话的产物面板有**任务概览**（状态/优先级/日期 + AI 进展摘要 +「在项目中查看」）；
- **「转办为待办」**：把当前对话的成果一键转成项目里的一条待办（AI 自动生成交接摘要，失败可手填）。转办的同时，天枢会自动把这次工作的**交接摘要与产出物清单**追加写进项目资产空间里的 **`memory.md`（项目记忆）**文件——这个文件会作为项目上下文自动带入该项目之后的每次 AI 对话：新会话一开口就知道「之前定了什么、产出了什么」，不用你复述背景。在资产 Tab 里能找到并打开它，想手工删改整理也完全可以（AI 只在文件末尾追加，你写的内容不会被覆盖）。
- AI 也能反向写计划——它有五个计划工具（创建/更新状态/追加小结/列出/查看详情），**AI 生成的事项带 AI 徽标**，AI 进展摘要只有 AI 能写。

## 19. 文件窗口

文件窗口是一个**独立的文件浏览/编辑窗口**（无侧边栏），顶部多标签、右侧可挂一个 AI 对话面板——适合「边看文件边让 AI 改」的场景。

**三种打开方式**：

1. 会话里产物文件的预览工具行 →「**在新窗口打开**」；
2. 资料库文件预览 →「**在新窗口打开**」；
3. 侧边栏任务行菜单 →「**在文件窗口打开**」。

**能做什么**：

- **多标签**：「+」新建标签（新建 Markdown / 新建文本 / 打开文件… / 最近打开）；右键标签可关闭/关闭其他/关闭右侧/复制路径/移到新窗口；`⌘⇧[` / `⌘⇧]` 切换标签。
- **编辑与保存**：右上角显示保存状态（已保存/未保存/保存中）；支持「保存」「另存为副本」「在 Finder 中显示」；未保存关闭前会问你要不要「保存并关闭」；文件在磁盘上被外部修改时会出现冲突条（覆盖磁盘版本 / 重载）。
- **AI 对话面板**：右栏展开后，当前打开的文件会自动注入对话（「请先用 read_file 工具读取该文件，再处理我的请求」），并按文件类型给出快捷指令——Markdown：总结要点/检查错别字/润色/生成大纲；图片：描述内容/提取文字/分析图表/图片问答；PDF：总结/提取数据/梳理结构/答疑 等。

## 20. 主机与远程遥控（进阶）

### 20.1 这是什么场景

天枢支持「**一台电脑遥控另一台**」：

- **被控端**：跑着天枢核心能力的一端——可以是另一台装了天枢的电脑（开启「本机被控面」），也可以是部署在服务器上的无头服务端（tianshu-server，没有界面、纯后台）。
- **控制端**：你面前的这台电脑，通过「主机页」添加连接、遥控远端。

用途举例：家里 Mac 挂机跑长任务，人在公司用笔记本遥控继续聊；或在服务器上常驻一个无头端，7×24 跑定时任务。

### 20.2 添加连接

入口：侧边栏顶栏的**主机切换器** →「主机配置」，进入「主机」页 →「**添加连接**」。

**基本信息**：名称（给被控端起个名字）、连接模式二选一：

| 模式 | 填什么 | 适合 |
| --- | --- | --- |
| **直连（HTTP/SSE）** | 被控端地址（`http(s)://…`）、访问令牌（未启用鉴权可留空） | 同一局域网 / 有公网 IP |
| **中继（WebSocket）** | 中继服务器地址（`ws(s)://…`）、中继令牌、被控端标识 | 两端都不暴露端口，经中转服务器牵手（链路可端到端加密） |

保存前先点「**测试连接**」：成功显示「连接成功（实例名）」，失败给出原因（配置不合法/令牌无效/无法连通/连接超时）。

**中继的端到端加密**（可选但推荐）：链路可以加密成只有两端能读的密文，中继服务器也偷看不到内容。模式可选「自动（握手失败可降级明文）」或「强制加密（不降级，失败即断开）」。

**指纹怎么确认**：每个被控端都有一串 16 位**密钥指纹**（在它的 设置 → 对外服务 → 端到端加密卡 里，见 20.4），相当于它的「身份证号」。添加连接时「密钥指纹」一栏：

- **留空（推荐新手）**：首次连接成功后，主机页会出现一张红色警示的**指纹确认卡**，你核对卡上指纹与被控端设置卡显示的一致后，点「**核对无误，确认信任**」——不确认的话连接能用但会一直挂警示；确认后天枢记住这串指纹，之后每次连接自动比对，**指纹一旦变化立即报警断开**（防止有人冒充你的被控端）。
- **提前填入**：把被控端的指纹直接粘进来，效果同上（首连即校验，不匹配红色警示并断开）。

### 20.3 连接列表与遥控

连接列表每行显示：状态点（未连接/连接中/已连接/重连中/令牌失效/已关闭）、名称、加密徽标（已加密 🔒 / 未加密 ⚠ / **待确认指纹** / 指纹不匹配 🔴）、地址，5 秒自动刷新。此外行上可能出现两个**警示徽标**（悬停有说明）：

- **明文直连**：该连接用的是 `http://` 明文地址、且目标不在局域网内——访问令牌与数据全程不加密，建议给被控端启用 HTTPS；
- **建议升级**：对方天枢版本过旧（提示「被控端协议版本过低（v…），部分能力可能不可用或行为不一致，建议升级被控端」），升级对方的天枢即可消除。

选中一个**具备工作流能力的**连接后，右侧展开遥控面板，从上到下（不具备编排能力的连接走平铺列表，指纹卡与用量卡同样显示在列表上方）：

- **端到端加密指纹卡**（中继连接常显）：显示当前连接核对到的指纹与确认时间；若指纹尚未确认（首连），这里就是那张红色「待确认：首次连接的加密指纹」警示卡（见 20.2 的确认步骤），点「核对无误，确认信任」即完成信任；若出现「指纹不匹配（疑似中间人），已断开」，卡里会并列显示期望指纹与实际指纹——被控端确实换过密钥就去「编辑连接」更新指纹，否则不要信任当前链路。
- **用量监控卡**：远端今日的输入/输出 Token、LLM 轮次、工具调用四个数（见第 15 章）。
- **编排图**：列出远端的工作流，可「运行」「中止」，查看运行状态（未运行/排队中/运行中/已成功/已失败/已中止）；每张图可开 Webhook。注意：这里只遥控运行，图的编辑在被控端本地完成。
- **自动化任务**：列出远端定时任务，可「立即运行」、启停，显示下次执行时间。

远程会话（遥控远端聊天）通过顶栏**主机切换器**完成：切换到远程主机后，整个界面（新建任务、会话列表、聊天）就工作在远端数据上了——聊天、会话、模型配置、专家、技能、审批对远程主机全功能可用；切回「本机」即回本地数据。

### 20.4 本机被控面（让别人遥控这台电脑）

入口：设置面板 → **对外服务** → 「本机被控面」。

1. 打开「**启用被控面**」，天枢在这台电脑上开一个 HTTP/WS 服务。
2. 设置**端口**与**监听地址**：「仅本机（127.0.0.1）」安全但只有本机能连；「所有网卡（0.0.0.0）」允许局域网/外部连接（⚠️ 有安全风险，务必保管好令牌、不用时关闭）。
3. **访问令牌**：自动生成，复制给控制端填写；可「重新生成令牌」。
4. （可选）填**中继服务器地址 + 中继令牌**让外网也能连到这台机器。
5. **端到端加密卡**：展示密钥指纹/公钥。把指纹经可信渠道（当面念、发消息）告诉控制端，对方核对确认后才算建立信任（见 20.2 的指纹确认）。注意：关闭加密或重新生成密钥后指纹会变，控制端需要重新核对确认。

之后在控制端按 20.2 添加一条指向这台机器的连接即可。

## 21. 移动端

### 21.1 移动端是什么

天枢移动端（iOS / Android）是一个「**遥控器**」：所有数据和执行都在被控端（你的电脑或无头服务端）上，手机只负责连接、查看、发消息和**审批**。人不在电脑前也能盯着长任务、批准 AI 的敏感操作。

底部四个 Tab：**聊天 / 主机 / 自动化 / 我的**。

### 21.2 第一次连接（三步）

**第一步：在电脑端打开被控面**。桌面端 设置 → 对外服务 → 「本机被控面」：启用开关打开、监听地址选「所有网卡（0.0.0.0）」（仅本机的话手机连不上）、记下**端口（默认 18411）**和**访问令牌**。

**第二步：手机上添加连接**。主机 Tab → 右上「＋」，两种模式：

- **添加直连**：填名称、地址 `http://<电脑IP>:18411`、访问令牌（电脑上那串）。手机和电脑需在同一网络；
- **添加中继**：填中继地址（必须是 `wss://`，公网中继不允许明文）、中继令牌、目标实例 ID；也可用 AK 三要素（管理端地址 / AK ID / AK 密钥）；可选端到端加密与指纹校验。

**第三步：测试连接**。成功显示「连接成功（实例名）」及控制用户名；失败给出原因（配置不完整/令牌无效/无法连接/连接超时）。点连接卡「使用」激活。

> 💡 连接建立后双方协商「能力」：连的是**桌面端**时，项目、资料库、技能市场等入口全量可用；连的是**无头服务端**时，会出现编排图遥控等无头端专属能力。手机「我的」页里的入口按实际能力自动显示/隐藏。凭据保存在手机系统钥匙串里。

### 21.3 各页功能速览

- **聊天**：按工作空间分组的会话列表（组头「＋」新建）；顶栏连接状态点与搜索；筛选未归档/全部 + 时间筛选；长按会话：重命名/置顶/归档/删除。会话页与桌面端同构——流式消息、工具调用卡、思考面板、图表组件、**审批横幅**（「工具执行申请审批」：批准 / 允许并记住 / 拒绝；多项排队时显示「还有 N 项待审批」）；底部输入条：模型选择、模式 chip（智能体/问答/计划）、专家 chip、引用技能、**上传文件/拍照**（文本文件限 512KB）、上下文用量、「会话文件」面板（产物/工作空间文件）、压缩上下文、编辑并重发、消息内搜索。
- **主机**：连接卡列表（状态徽章：未连接/连接中/已连接/重连中/令牌无效/已断开；加密徽章：已加密/指纹不符/握手失败），使用/编辑/删除。
- **自动化**：分「编排图」「自动化任务」两段——编排图可运行/中止/删除；任务卡显示调度文案（如「每周 一、三 09:00」）、启停开关、「立即运行」；还能**新建自动化**（执行体选工作流或提示词+模型、调度、错过策略、权限模式、工作空间）；「运行历史」看状态筛选、耗时、Token、错误与**逐节点执行详情**。
- **项目**：项目/我的任务两段；项目工作台分「计划 / 资产 / 关于」——计划用已保存视图 + 按状态分组浏览、新建/编辑事项（含自定义字段与资产附件挂接）；资产浏览与图片预览；「关于」看项目指令、成员与挂载清单。
- **我的**：当前主机卡、语言、外观（跟随系统/浅色/深色）、主题色、**通知**（启用通知/审批请求/图运行结束——仅 app 在后台时提醒，app 被杀死后收不到）、以及按能力出现的入口：审批记忆、用量监控、服务商、资料库、项目、工作空间、技能启停、技能市场、记忆、备份、专家、连接器、关于。

### 21.4 移动端与桌面端的差异

移动端**做不了**（回桌面端做）：

- 连接器（MCP）的新增与编辑；
- 工作空间目录的绑定/解绑（只读显示「桌面端绑定」）；
- 编排图的**编辑**（只遥控运行；且遥控桌面端时无编排能力，编排遥控仅无头端支持）；
- 部分文件类型的预览（提示「该类型请在桌面端预览」）；
- 备份的**恢复**（手机可发起备份，恢复去桌面端）；
- 计划视图管理（新建视图/筛选器/甘特日历看板切换）与「推进（会话）/ AI 推进 / 转办为待办」；
- 安全中心/审计日志查看。

移动端**独有**：推送通知（审批请求、图运行结束——不用守着手机等审批）、拍照/相册输入。

> ⚠️ 已知限制：多个控制端同时遥控同一个会话可能出现消息串流。

## 23. 常见问题（FAQ）

### 开始使用

**Q：发送按钮是灰的，点不了？**
依次检查：① 正文是否为空；② 是否命中敏感词（提示「内容包含受限词」——改写措辞）；③ 是否选了工作空间（提示「请先选择工作空间」）；④ 是否配置了可用模型（提示「请先配置可用模型」——去第 6 章配置）。

**Q：忘记登录密码？**
本地账号无找回功能，注册一个新账号即可（见 3.3）。

**Q：必须绑卡/付费给天枢才能用吗？**
不用。天枢本身免费开源，你只需为自己选择的 AI 服务商付费（或用 Ollama 本地模型，完全免费）。

### 模型与对话

**Q：报「认证失败，请检查 API Key」？**
API Key 填错或已失效。去服务商官网重新生成，在「模型管理」→ 编辑连接里更新（编辑时留空表示保持原 Key）。

**Q：报「模型不存在，请检查模型 ID」？**
模型 ID 与服务商要求不一致（必须一字不差，如 `deepseek-chat` 不是 `DeepSeek Chat`）。用「从服务商拉取模型」导入最稳妥。

**Q：报「当前模型不支持图片输入」？**
所用模型不是多模态模型。在模型选择器里换一个支持视觉的模型，或移除图片附件。

**Q：报「该会话已有进行中的请求」？**
上一条还在生成。等它完成，或点「停止」按钮中止后再发。

**Q：报「请求过于频繁」？**
服务商限流了，稍等片刻再发；免费额度账户尤其常见。

**Q：上下文用量环变红了怎么办？**
会话太长了。输入 `/compact` 压缩上下文，或换上下文窗口更大的模型，或开个新任务。

**Q：AI 写的文件在哪？**
对话右栏「产物面板」直接看；资料库 → 「本地产物」按 工作空间→任务 汇总；磁盘上就在工作空间绑定的目录里。

### 权限与安全

**Q：AI 要执行的命令我不懂，批不批？**
看审批卡上的命令原文。拿不准就「拒绝」——AI 会另想办法（比如改用不需要该命令的方案）。绝对不要批准你看不懂的 `rm`、`sudo`、`curl | sh` 之类命令。

**Q：报「路径超出工作空间范围」？**
你（或 AI）试图访问绑定目录之外的文件。这是保护机制。把文件挪进绑定目录，或换绑更大范围的目录。

**Q：误开了「完全访问」怎么关？**
会话输入框旁的权限胶囊切回「默认权限」；或去 安全中心 → 系统授权 → 活跃完全访问 → 一键收回全部。重启应用后完全访问也会自动失效。

### 技能 / 连接器 / 工作流

**Q：装的技能在对话里看不到？**
技能必须**启用**后才出现在 ＋ 菜单与 `/` 联想里。去 专家·技能·连接器 → 技能 → 我安装的，打开开关。

**Q：MCP 连接器状态一直「错误」？**
stdio 型检查本机是否装了对应命令（如 npx）；HTTP 型检查地址与 Token 是否有效；点「重连」重试；悬停错误状态可看具体原因。

**Q：工作流保存不了 / 试运行不了？**
顶部「校验问题」面板会列出原因（如「工作流须有唯一入口」），点击问题条目自动定位到出错节点。全部解决后才能保存/试运行。

**Q：定时任务/工作流写文件被拒？**
定时任务默认受限权限。进任务详情页，在「执行权限」处开启完全访问（工作流试运行不受限）。

**Q：代码节点在安装包里跑不起来？**
代码节点依赖电脑上安装的 node（bash/python 同理需对应解释器）。安装解释器，或在代码节点里改用本机存在的命令名（如 python3）。

### 数据与维护

**Q：换电脑怎么迁移数据？**
设置 → 存储 → 数据备份：备份到本地档案（可加密）→ 新电脑恢复；或备份到主机后在新机申领恢复（邀请码机制，见 17.3）。

**Q：磁盘满了？**
设置 → 存储看占用；开「自动清理执行历史」并调低保留天数；安全中心可下调备份总上限。

**Q：桌面通知不弹？**
设置 → 通知 → 确认「已授权」；未授权点「去授权」跳系统设置开启；再点「测试通知」验证。

**Q：更新检查失败？**
多为网络问题（或未配置更新源）；检查 设置 → 通用 → 网络代理。

**Q：多台设备怎么同时用？**
一台开「本机被控面」，其他设备添加连接遥控（第 20 章）；注意多控制端遥控同一会话可能串流。

## 24. 你的数据存在哪里

- **数据根**：`~/.tianshu`（Windows：`C:\Users\<你的用户名>\.tianshu`），生产与开发数据分组隔离。数据库文件位于 `<数据根>/<分组>/database/local.db`，技能、资料库、日志等同在数据根下。可在 设置 → 存储 修改位置（重启生效）。
- **会话绑定的文件**：永远在你绑定的那个文件夹里，天枢不搬走它们；AI 写出的「产物」也落在工作空间目录或资料库。
- **备份**：设置 → 存储 → 数据备份，可加密导出到本地或上传主机。
- **彻底卸载**：卸载应用后，`~/.tianshu` 目录仍保留；想彻底清除请手动删除该目录。
