## 走查清单

### 1. 新建项目 → 资产 Tab 空态引导

- **操作步骤**：新建任一项目进入详情，切到「资产」Tab。
- **预期结果**（spec §3.2/§3.5）：面板显示空态引导，上传/新建文件夹两个按钮可用；后台已建 `userData/projects/<id>/assets/` 目录与「资产 · <项目名>」专属 workspace。
- **Commit 区域**：d039c3e（create 建空间+目录）、06976b5（详情页资产 Tab 接入）、652256b（面板骨架含空态）。

### 2. 上传（按钮多选）与部分失败汇总

- **操作步骤**：点「上传」在系统对话框多选若干文件确认（可混入一个读不到的源，如已拔出移动介质上的文件）。
- **预期结果**（spec §3.3/§3.5/§4）：列表即时出现新文件、容量条增长、成功 toast；失败文件汇总为「N 个文件上传失败」partial toast（成功侧记最终落盘名、失败侧记原始文件名）。
- **Commit 区域**：ea58a25（upload IPC）、3f8e501（上传交互+toast）。

### 3. 拖拽上传

- **操作步骤**：从 Finder 拖 2 个以上文件悬停资产 Tab 任意位置再松手。
- **预期结果**（spec §3.3/§3.5）：拖入即出现全面板覆盖层（显示文件计数，悬停期间不闪烁），松手后上传至当前所在文件夹并刷新列表。
- **Commit 区域**：ea58a25（webUtils 拖拽桥）、3f8e501（覆盖层+计数防闪烁）。

### 4. 新建文件夹重名序号

- **操作步骤**：新建文件夹「doc」后，再以同名「doc」创建一次。
- **预期结果**（spec §3.3/§4）：第二次自动落为「doc (2)」，toast 展示实际创建名（非法字符被清洗、清洗后为空则拒绝）。
- **Commit 区域**：e1aa679（createFolder 仓储）、3f8e501（交互+toast）。

### 5. 多级文件夹导航与面包屑

- **操作步骤**：进入「doc」内再嵌套建子文件夹并逐级进入、返回，期间任设一个类型筛选。
- **预期结果**（spec §3.5）：面包屑「根 › doc › …」随层级变化且各级可点跳转；文件夹不受类型筛选影响恒显示、恒排在文件前。
- **Commit 区域**：652256b（面包屑+列表）、3f8e501（筛选下文件夹恒显示修正）。

### 6. 重命名：未修改禁用与重名序号

- **操作步骤**：重命名弹窗中不改名尝试点确认，再改成与同层已有文件同名提交。
- **预期结果**（spec §3.3/§4）：未修改时确认按钮禁用；重名提交自动追加序号落盘（如 `报告 (2).pdf`）。
- **Commit 区域**：e1aa679（rename 仓储）、3f8e501（重命名弹窗交互）。

### 7. 删除文件/文件夹（二次确认）

- **操作步骤**：分别对一个文件和一个含内容的文件夹执行删除（走二次确认弹窗）。
- **预期结果**（spec §3.3/§4）：确认后列表与容量条立即刷新；非空文件夹弹窗明示将删除的文件数量。
- **Commit 区域**：e1aa679（delete 仓储）、3f8e501（AlertDialog 二次确认）。

### 8. 预览与 Finder 定位

- **操作步骤**：对同一文件分别点行内「预览」与「定位」。
- **预期结果**（spec §3.3）：预览以系统默认程序打开；定位在 Finder 中高亮该文件（Windows 为资源管理器）。
- **Commit 区域**：ea58a25（openFile/revealFile IPC）、3f8e501（行内操作）。

### 9. 排序 + 类型筛选 + 无匹配提示

- **操作步骤**：切换「名称/时间」排序（再点已激活键翻转方向），选一个类型筛选，再构造一个无匹配的类型组合。
- **预期结果**（spec §3.5）：默认名称升序、切换到时间键缺省最新在前；筛选即时生效，无匹配时列表区显示无匹配提示（非空白表格）。
- **Commit 区域**：652256b（排序/筛选）、3f8e501（时间缺省降序+无匹配提示修正）。

### 10. 容量条警示色与 5GB 软上限

- **操作步骤**：上传文件使已用达 80% 观察容量条，继续上传越过 5GB（可用大文件加速）。
- **预期结果**（spec §2/§3.5）：已用 ≥80% 容量条变警示色；越过 5GB 上传照常完成、仅弹警告 toast 不阻断（「升级」为本地版静态说明，无假入口）。
- **Commit 区域**：ea58a25（storage 递归统计）、652256b（容量条）、3f8e501（警示色+超限警告）。

### 11. 动态流 `@` 引用资产文件

- **操作步骤**：详情页动态流输入框键入 `@`，从联想列表选择一个已上传的资产文件发送。
- **预期结果**（spec §3.6）：联想列表即资产目录文件树（`file:listWorkspaceFiles` 定位资产空间）；发送后文件内容随消息注入模型，交互与资料库 `@` 完全一致（ChatInput 零改动）。
- **Commit 区域**：d039c3e（session 挂资产空间）、682553f（ActivityPane 按 `assetWorkspaceId` 直接解析）。

### 12. 旧项目自愈

- **操作步骤**：升级 v3 后首次打开一个一期创建的旧项目详情并切资产 Tab。
- **预期结果**（spec §3.2）：自动补齐资产目录 + 「资产 · <项目名>」workspace + 会话重绑该空间（幂等），资产 Tab 立即可用；重复打开无重复空间。
- **Commit 区域**：d039c3e（getDetail 自愈迁移）。

### 13. 删除项目 → 磁盘目录与资产空间清理

- **操作步骤**：删除一个已上传过资产的项目（二次确认），检查 `userData/projects/<id>/` 目录。
- **预期结果**（spec §3.2）：级联删除项目/会话/消息/挂载之外，资产 workspace 行与 `projects/<id>/` 整目录一并清理，Hub 列表不再显示该项目。
- **Commit 区域**：d039c3e（remove 扩展 rm recursive + 删资产空间行）。

### 14. 工具硬隔离

- **操作步骤**：给项目仅挂 1 个连接器（含 MCP 工具）发消息让它列/调工具；再挂 0 个连接器对比；最后回 AI 模块普通会话同样提问。
- **预期结果**（spec §3.7）：项目会话仅能调用所挂连接器的 MCP 工具、技能清单收窄到挂载集；挂 0 个连接器时无任何 MCP 工具可用（空数组 = 全隔离）；AI 模块会话工具集全量不受影响。
- **Commit 区域**：0e374f1（isolateProjectTools + collectToolDefinitions 白名单过滤）。

### 15. AI 模块回归：资产空间不泄漏

- **操作步骤**：浏览 AI 侧边栏空间树，打开自动化新建任务弹窗查看空间下拉（第 12 项的旧项目补齐资产空间后再看一遍）。
- **预期结果**（spec §3.2）：两处均不出现任何「资产 · <项目名>」空间；既有用户空间增删改照常。
- **Commit 区域**：d039c3e（workspace:list 过滤 projectId null）、682553f（25 消费点核查+补漏）。

## 边界行为与已知裁定（走查确认，非 bug）

### 16. `workspace:update/delete/bind` 裸 IPC 无资产防护

- **操作步骤**：常规 UI 全程无法触达（可跳过实测）。
- **预期结果**（已知裁定，T9 核查 Concerns 1）：三个通道按 id 操作不校验 `projectId`，渲染层所有 id 均来自已过滤列表故界面安全；但主进程通道若被直接以资产空间 id 调用可改动/删除资产空间——纵深防御（repo 层拒绝 `projectId` 非空行）留作后续小任务。
- **Commit 区域**：682553f（核查记录，未改）。

### 17. 删光用户空间但项目存在时默认空间不补建

- **操作步骤**：在 AI 模块删光所有用户空间（保留项目），观察 AI 侧边栏与新建任务。
- **预期结果**（已知裁定，T9 核查 Concerns 2）：`ensureDefaultWorkspace` 的 count() 含资产空间 → 不补建默认空间、AI 空间列表为空——一期既有同型边界（用户本就可删光空间），非二期引入。
- **Commit 区域**：一期既有（16d582f ensureDefaultWorkspace）。

### 18. enabled 但 error 态连接器仍进项目声明段

- **操作步骤**：挂载一个「已启用但连接失败」的连接器，在项目会话发消息查看 system 声明段。
- **预期结果**（已知裁定，T8 minor）：禁用连接器已不进声明（enabled 过滤已落地），但启用+连接失败的瞬态仍被声明（其工具实际不在 registry，声明瞬时偏宽、实际调用仍硬隔离）；可交 `manager.getStatuses` 收紧，暂留。
- **Commit 区域**：0e374f1（enabled 过滤落地）、声明收窄待后续。
