# 新建任务主工作台 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 `/module/ai/new` 新建任务落地页（场景导航 + 推荐胶囊 + 输入卡 + 工作空间/权限配置栏），发送后才创建 session 并进入 ChatView 流式输出。

**Architecture:** 新建 `src-react/domains/ai/new-task/` 前端域；后端加 `session.scenario` / `skillRecord.scenarios` 两列（DB v10）+ 三个新 IPC（`file:readExternalFile`、`chat:polish`、`skill:setScenarios`）+ system prompt 场景注入。ChatInput 零行为改动（仅迁出 `detectMention` 纯函数）。

**Tech Stack:** Electron 44 + React 19 + TypeScript 5.9 + Prisma/better-sqlite3 + Zustand + React Query + Vitest（含 @testing-library/jsdom）。

**Spec:** `docs/superpowers/specs/2026-09-17-new-task-design.md`

## Global Constraints

- 文件名 kebab-case；变量 camelCase；组件 PascalCase；CSS 禁硬编码主题色（只用 `*-primary*`/`border-border/50` 等变量类）；弹出层 `border-border/50 rounded-lg shadow-lg`。
- 用户可见文本一律 i18n：新增 `newTask` 命名空间（zh-CN + en-US 同步），JSX/逻辑中禁硬编码中文英文。
- 新 IPC 通道必须登记前端 `src-react/lib/ipc.ts` 的 `IPCChannel` 联合类型（L6-186），否则 `invoke` 类型报错。
- 后端 handler 注册模式：各 repo/service 类构造内 `registerIpcHandlers()`，`ipcMain.handle("通道", (_, p: 形状) => ...)`；前端 invoke 参数是展开位置参数。
- 测试放顶层 `tests/`（子目录 `ai/`），组件测试文件头加 `// @vitest-environment jsdom`；mock IPC 用 `vi.hoisted` + `vi.mock("@/lib/ipc")` 模式（参照 `tests/project/plan-item-api.test.ts`）。
- 运行命令：`npm run test`（vitest run）、`npm run typecheck`、`npm run lint`。数据库 schema 改动后需 `npx prisma generate`（Prisma Client 输出 `electron/generated/prisma`）。
- 提交信息格式沿用仓库惯例：`feat(新建任务): ...` / `test(新建任务): ...` / `docs(新建任务): ...`。

## Spec Deviations（执行时以此为准，spec 已同步修订）

1. **裁定 10 修订**：落地页输入卡**独立精简实现**（textarea + 引用 pill + 简化 `@` 联想面板），不从 ChatInput 抽镜像层/联想系统；仅将纯函数 `detectMention` 从 `ChatInput.tsx:126-149` 迁入 `chat/lib/inline-tokens.ts` 共用。ChatInput 其余零改动。
2. **裁定 6 数值修订**：50MB 上限改为复用现有注入上限——`readWorkspaceFile` 纯函数的 `READ_LIMIT = 512KB`（`electron/domains/ai/chat/workspace-files.ts:24`）。理由：外部文件与 `@文件` 走同一"读内容注入 prompt"链路，512KB 才是真实约束；超过即拒绝并 toast。

// electron/domains/ai/chat/scenario-prompt.ts
/**
 * 场景提示段（新建任务 spec §4.2）：session.scenario 非空且已知时
 * 追加到 system 末尾；文案给模型看，不进前端 i18n
 */
const SCENARIO_PROMPTS: Record<string, string> = {
  daily:
    "当前处于日常办公场景，请侧重文档撰写、信息整理、邮件与日程等办公任务的完成质量与格式规范。",
  coding:
    "当前处于代码开发场景，请给出可直接运行的代码、准确的命令与技术解释，遵循工程最佳实践。",
  design:
    "当前处于设计创意场景，请侧重创意的多样性与表达力，给出具体的文案或提示词产出。",
};

export function buildScenarioSystem(
  scenario: string | null | undefined,
  base: string | undefined,
): string | undefined {
  const section = scenario ? SCENARIO_PROMPTS[scenario] : undefined;
  if (!section) {
    return base;
  }
  return base ? `${base}\n\n${section}` : section;
}
```

private async setScenarios(name: string, scenarios: string[]): Promise<null> {
  const valid = ["daily", "coding", "design"];
  const filtered = [...new Set(scenarios.filter((s) => valid.includes(s)))];

    where: { name },
    data: { scenarios: JSON.stringify(filtered) },
  });

}

  workspaceId: number;
  text: string;
  style: "professional" | "concise" | "translate-en";
}): Promise<{ text: string }> {
  const STYLE_PROMPTS: Record<string, string> = {
    professional: "请将以下文本改写得更专业、正式，保留原意与结构，直接输出改写结果：",
    concise: "请将以下文本精简压缩，保留关键信息，直接输出精简结果：",
    "translate-en": "请将以下中文文本翻译成英文，直接输出译文：",
  };
  const workspace = await this.workspaces.getWorkspace(p.workspaceId);
  const modelRow = workspace?.defaultModelId
    ? await this.models.getModelById(workspace.defaultModelId)
    : await this.models.getFirstUsableModel();
  if (!modelRow) {
    throw new Error("未配置可用模型，请先在服务商设置中配置");
  }
  const providerRow = await this.providers.getProviderById(modelRow.providerId);
  const text = await this.titleModelText({
    type: providerRow.type,
    baseUrl: providerRow.baseUrl,
    apiKey: providerRow.apiKey ?? undefined,
    extraHeaders: providerRow.extraHeaders,
    modelId: modelRow.modelId,
    userText: `${STYLE_PROMPTS[p.style] ?? STYLE_PROMPTS.professional}\n${p.text}`,
  });
  return { text };
}

// src-react/domains/ai/new-task/lib/dispatch.ts
/** 发送编排（spec §3.2）：create(scenario) → [full: setPermission] → send → navigate */
import { toast } from "sonner";

import SessionApi from "../../api/session.api";
import ChatApi from "../../api/chat.api";
import { invoke } from "@/lib/ipc";
import SkillApi from "../../skills/api/skill.api";
import { readExternalFile } from "./attach";
import { checkSensitive } from "./sensitive-check";
import { useNewTaskStore } from "../store/new-task-store";

export interface DispatchParams {
  navigate: (to: string, options?: { replace?: boolean }) => void;
}

export async function dispatchNewTask({ navigate }: DispatchParams): Promise<void> {
  const { content, scenario, workspaceId, accessMode, pending } =
    useNewTaskStore.getState();
  if (workspaceId === null) {
    throw new Error("no-workspace");
  }
  const hit = checkSensitive(content);
  if (hit) {
    throw new Error(`sensitive:${hit}`);
  }
  const files = await Promise.all(
    pending.map(async (ref) => {
      if (ref.kind === "skill") {
        const result = await SkillApi.readSkill(ref.ref);
        return { path: ref.ref, content: result.content, kind: "skill" as const };
      }
      if (ref.kind === "localFile") {
        const result = await readExternalFile(ref.ref);
        return {
          path: ref.ref,
          content: result.kind === "text" ? result.content ?? "" : `[图片 ${ref.label}]`,
          kind: "localFile" as const,
        };
      }
      const result = await invoke<{ content: string } | { error: string }>(
        "file:readWorkspaceFile",
        workspaceId,
        ref.ref,
      );
      if ("error" in result) {
        throw new Error(`read-failed:${ref.ref}`);
      }
      return { path: ref.ref, content: result.content, kind: "file" as const };
    }),
  );
  const created = await SessionApi.create({ workspaceId, scenario });
  if (accessMode === "full") {
    await ChatApi.setPermission(created.id, "full");
  }
  await ChatApi.send({ sessionId: created.id, content: buildInjectedContent(content, files) });
  useNewTaskStore.getState().resetDraft();
  navigate(`/module/ai?session=${created.id}`, { replace: true });
}
```

（`buildInjectedContent` 按实现注记提取/复用；toast 不在此层——调用方（NewTaskView 的 onSubmit）catch 后 `toast.error(mapIpcError(e))`，敏感词/无空间错误映射为对应 i18n 文案。）
